## What you'll need

Before you start, make sure you have:

- [x] An account on the platform (free plans work fine)
- [x] A repository or local project you'd like to deploy
- [x] A few minutes of uninterrupted time

<Callout kind="info">
  If you're evaluating the platform for your team rather than yourself, jump to [Core concepts](/demo-docs/documentation/core-concepts/core-concepts) first — it'll save time when you set things up properly.
</Callout>
