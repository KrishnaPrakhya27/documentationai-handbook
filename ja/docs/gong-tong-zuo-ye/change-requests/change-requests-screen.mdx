変更リクエスト画面では、サイト全体の進行中の変更リクエストを表示・管理できます。開いて確認したり、マージしたり、GitBook Agent と一緒に更新作業を進めたり、すべて1か所で行えます。開くには **変更リクエスト**、 **全般** サイトのサイドバーから。

### 変更リクエスト画面の操作

サイト内のすべての変更リクエストは、変更リクエスト画面に表示されます。ステータスで絞り込んだり、GitBook Agent が作成した変更リクエストのみを表示するように絞り込んだりできます。

変更リクエストをクリックすると、拡張表示で開きます。そこから変更リクエストを確認、編集、マージしたり、GitBook Agent と一緒に作業を続けたりできます。拡張表示には、参加者とレビュー担当者、説明、変更の差分表示も表示されます。

エディタで差分を確認するには、 **編集** 右上隅のをクリックして変更リクエストのスペースを開き、次に **変更** タブへ。差分ナビゲーションコントロールが表示されます。

エディタで差分を確認するには、 **編集** 右上隅のをクリックして変更リクエストのスペースを開き、次に **変更** タブへ。エディタ下部のフローティング差分ナビゲーターを使えば、変更されたブロックを順に移動したり、差分のある次のページへ進んだり、最後の変更から利用可能なレビュー操作でレビューを完了したりできます。

### 変更リクエストのレビュー

誰かがレビューを依頼すると、変更リクエスト画面から直接コンテンツを編集したりフィードバックを残したりできます。

さらに変更を依頼したり、変更リクエストを承認してマージ準備が整ったことを示したりできます。

レビューの多くは変更リクエストのコメント欄で行われ、共同編集者は特定のコンテンツブロックや変更リクエスト全体について議論できます。さらに、 [GitBook Agent](/ja/docs/gitbook-agent/review-change-requests-with-gitbook-agent) 変更リクエストのレビューを依頼することもできます。GitBook Agent は、チームと一緒に変更を確認し、計画し、作業を継続できます。
