<Callout kind="info">
  のみ [組織の管理者](/ja/docs/gong-tong-zuo-ye/member-management/roles#admin) 翻訳を作成してアクセスできます。なぜなら、それは [課金対象の機能です](#pricing).
</Callout>

自動翻訳を使えば、最小限の手作業で、ドキュメントを複数の言語で最新の状態に保ちやすくなります。あるセクションを別のセクションの翻訳として作成し、残りは GitBook Agent に任せられます。

## 翻訳の仕組み

- <strong>翻訳セクションを作成する:</strong> 既存のセクションの翻訳として新しいセクションを設定します。ソースセクションと対象言語を選択してください。
- <strong>継続的な更新:</strong> ソースコンテンツに変更を加えるたびに、翻訳ワークフローは **変更されたページに対してのみ実行されます**.
- <strong>自動同期:</strong> 変更がマージされると、翻訳ワークフローは **自動的に実行されます** そしてソースと同期されるため、翻訳済みセクションには常に最新の更新が反映されます。

<Callout kind="info">
  自動翻訳されたセクションのページスラッグは、ページに固定スラッグが設定されていない限り変更される場合があります。言語間で URL を安定させるには、翻訳する前に固定スラッグを設定してください。スラッグを更新する方法については、 [URL のスラッグを変更するにはどうすればよいですか？](https://app.gitbook.com/s/Ua3kTfM3iWAoECzM0u90/published-documentation/custom-domains/how-can-i-change-the-slug-in-the-url)
</Callout>

## 自動翻訳を設定する

セクションを新しい言語に翻訳するには、サイドバーの組織に戻り、 **ホーム** に戻って **翻訳** から、 **翻訳を作成**.

次の場所で **翻訳を作成** モーダルで、次を選択します:

- **ソース** — 翻訳したいセクション
- **元の** 言語
- **To** 言語

クリックして **作成** 翻訳ワークフローを開始します。これらのオプションは、セクションを組織内の複製された翻訳済みセクションに翻訳するために使用されます。

サーバー側の **翻訳** この画面には、設定済みの翻訳ワークフローも一覧表示され、ステータス、ソース、実行履歴、翻訳されたページ数と単語数が含まれます。ソースコンテンツが更新されるたびに、ワークフローは再実行されます。

### 詳細設定

クリックして **詳細な手順を表示** の **翻訳を作成** これらのオプションを設定するモーダル。

<strong>カスタム AI 指示:</strong> 口調、文体、その他の好みに合わせて AI を導くための詳細な指示を追加します。これにより、翻訳がブランドや対象読者に合うようになります。

<Callout kind="info">
  翻訳ワークフローにカスタム指示を追加すると便利ですが、特定のケースでは制限があります。

  カスタム指示は、翻訳済みセクションに新しい要素を作成したり、追加テキストを加えたり、ソースコンテンツの構造を変更したりするためには使用できません。
</Callout>

<strong>用語集サポート:</strong> 特定の用語をどのように翻訳するかを制御するために用語集を定義します。これにより、対応しているすべての言語で用語の一貫性が保たれます。

用語集の用語は、制御したいソース言語の表現と一致している必要があります。GitBook は翻訳実行中にそれらを適用し、用語の一貫性を保ちます。

たとえば、ソース言語が英語で、用語集に `SSO` → `SSO` 、 `Git Sync` → `Git Sync`が含まれている場合、「Set up SSO with Git Sync」のような文では、翻訳結果でもそれらの用語は変更されません。

<Callout kind="alert">
  **用語集を変更すると、コンテンツ全体の再翻訳が実行されます**。現時点では回避策はありません。どのページに用語集のキーワードが含まれているかを確実に検出できないため、すべてのページを再翻訳するのが最も安全な方法です。そのため、用語集の更新には時間とコストがかかる場合があります。
</Callout>

## バリアントに翻訳を追加する

翻訳を作成した後は、公開済みの docs サイトに [バリアント](/ja/docs/saitowosuru/site-structure/variants)として追加できるようになります。これにより、メインの docs サイトを表示しているときに、右上隅で言語を切り替えられるようになります。

<Callout kind="info">
  ユーザーに最適な体験を提供するため、設定時にバリアントの既定言語を設定できます。

  バリアントを設定する際は、翻訳済みセクションの言語を追加するのがベストプラクティスです。
</Callout>

翻訳用の新しいバリアントを設定するには、次から構造エディターを開きます **サイト構造**、 **全般** サイトのサイドバーから。

## 料金

翻訳は有料アドオンです。翻訳の請求は、メインのサブスクリプションと同じ月次または年次サイクルで行われます。

- 月額料金: 月あたり最大 50,000 語の翻訳まで月額 $25
- 年額料金: 月あたり最大 50,000 語の翻訳まで年額 $250
- 追加 1,000 語ごとに $0.20

月間上限は毎月の初めにリセットされます。$0.20 の料金は、年額サブスクリプションを含め、追加の 1,000 語ごとに適用されます。

「月額」は料金と語数上限を指し、請求サイクルを指すものではありません。

最初の翻訳では、すべての単語が請求対象になります。その後は、 **ページ** 新規または更新された単語を含むページのみが課金対象となります。たとえば、後でドキュメントを編集した場合、新しい単語が含まれるページだけが語数上限にカウントされ、文書全体に対して再請求されることはありません。

<Callout kind="alert">
  複数の翻訳で大きなページを扱う場合は注意してください。翻訳語数には、変更が含まれるページ内のすべての単語が含まれるため、大きなページで数語だけ変更しても、そのページ全体が再翻訳されます。
</Callout>

## よくある質問

<Expandable title="なぜ自動翻訳を使うのですか？">
  - <strong>手間のかからない多言語ドキュメント:</strong> 手動翻訳作業なしで世界中のユーザーに届けられます。
  - <strong>賢い更新:</strong> 変更されたページのみが再翻訳され、時間とリソースを節約できます。
  - <strong>完全なコントロール:</strong> 詳細な指示と用語集の管理で翻訳をカスタマイズできます。
</Expandable>

<Expandable title="翻訳を編集できますか？">
  現在、翻訳は編集できません。

  翻訳はソースコンテンツの純粋な変換として行われるため、翻訳結果に加えられた編集内容を新しい翻訳と照合することはできません。

  これを回避するには、次の手順をおすすめします:

  - AI に使用させたい特定の翻訳を定義するために、用語集を使用します
  - 出力を調整するためにカスタム指示を使用します
</Expandable>

<Expandable title="いくつの翻訳を作成する必要がありますか？">
  作成するのは **言語ごとに 1 つの翻訳ワークフロー** 1 つのソースコンテンツにつきです。複数のワークフローを作成すると、組織内で追加の重複コストが発生します。
</Expandable>

<Expandable title="現在の制限にはどのようなものがありますか？">
  - 翻訳では、バリアント内の UI 要素は自動的にローカライズされません。次を開いてください **カスタマイズ**、 **ツール** サイトのサイドバーで、 [インターフェースをローカライズするには](/ja/docs/saitowosuru/customization/extra-configuration#localize-user-interface) の [特定のバリアント](/ja/docs/saitowosuru/customization#customizing-sites-with-multiple-sections-or-variants).

    - これには、お知らせバナーなどのユーザー入力によるカスタマイズが含まれます。
  - 翻訳では、ヒントや AI によって翻訳されたことを示すバナーのような追加コンテンツをページに加えることはできません。これを示したい場合は、翻訳済みセクションに追加ページを作成するか、 [お知らせバナー](/ja/docs/saitowosuru/customization/layout-and-structure#announcement-premium-and-ultimate) をサイトバリアントに追加することを検討してください。
  - 用語集を変更すると、すべてのページの再翻訳が完全に実行されるため、処理時間とコストが増える可能性があります。現時点では、用語集の使用状況に基づく部分的な再翻訳はできません。
</Expandable>

始め方でサポートが必要な場合や、自動翻訳の設定について詳しく知りたい場合は、 サポートチームにお問い合わせください.
