GitBook Agent は、あなたと並走する AI チームメイトです。ドキュメントを正確で、完全で、最新の状態に保つのを助けます。GitBook Agent は GitBook に深く統合されています。使うのに新しいワークフローは必要ありません。

<Callout kind="info">
  AI アシスタントを使ってローカルでドキュメントを編集しているなら、 [GitBook の skill.md ファイル](/ja/docs/docs-as-code/ai-coding-assistants-and-skillmd).
</Callout>

### GitBook Agent で何ができますか？

GitBook Agent でできること：

- <strong>プロンプトに基づいてドキュメントを書く：</strong> ページを更新したり、製品名を変更したり、必要なその他の変更を GitBook Agent に依頼できます。
- <strong>コンテンツを GitBook に取り込む：</strong> PDF や Microsoft Word 文書などのファイルを GitBook Agent のチャットサイドバーに添付します。GitBook Agent は内容を抽出して、あなたのセクション内のページに整形します。
- <strong>大きな変更を計画して実装する：</strong> 必要なことを説明してください。GitBook Agent は変更リクエストを作成し、編集内容を説明し、フィードバックに応答し、あなたが一緒に作成した計画を実行します。
- <strong>スタイルガイドに従う：</strong> チームのライティングルールを [スタイルガイド](/ja/docs/kontentsuwo/styleguide)、GitBook Agent はコンテンツの作成やレビューの際にそれを唯一の正しい情報源として扱います。
- <strong>サイト固有のカスタム指示に従う：</strong> リンクの追加方法や避けるべきブロックタイプなど、GitBook Agent にサイト固有の指示を与えられます。
- <strong>ドキュメントを翻訳する：</strong> 翻訳したいコンテンツを選び、言語を選択すると、GitBook Agent がドキュメントをローカライズします。
- <strong>コメントから呼び出す：</strong> ページ上の任意のブロックにコメントを追加し、 `@gitbook`と入力して、必要なことを GitBook Agent に伝えてください。
- <strong>変更リクエストをレビューする：</strong> 変更リクエストで GitBook Agent をレビュアーとして追加します。ドキュメントのリンターとして機能し、スタイルガイドの問題を指摘し、エラーを提案または修正できます。

GitBook Agent は、サポート会話、チケット、接続済みツールのスレッドなど、あなたのチームが製品や顧客のニーズを理解するために使っているシグナルにも接続できます。

このコンテキストがあれば、GitBook Agent はギャップを特定し、更新を提案し、ドキュメントの変更を自動で生成できます。

ドキュメントが製品とともに進化すると、顧客は必要なときに適切な情報を得られます。

### スタイルガイドとカスタム指示を追加する

GitBook Agent は、チームのスタイルガイドやサイト固有の指示で設定できます。

GitBook Agent は、そのサイト向けのコンテンツを作成または編集するたびに、このコンテキストを使用します。

スタイルガイドまたはカスタム指示を追加するには、サイトの **設定**、 **全般** をサイトのサイドバーで開き、】【t\_577c0d39】. Here you can enable the Assistant and customize its instructions, welcome message, and suggested questions. **エージェント**を開いてください。カスタム指示フィールドに指示を追加します。

この画面は変更リクエストからも開けます。GitBook Agent のチャットウィンドウを開き、次に **操作メニュー** <Image src="https://test-dai.imgix.net/org-4afef969-21f9-40f3-b5b8-b06c8b6cf68f/doc-22a3b060-9539-4176-97e4-49120e02f5d1/4fa265378c13a520-spaces-NkEGS7hzeqa35sMXQZ4X-uploads-89MTSo5XRpPMVr1T0rxS-actions.svg?rasterize-bypass=true" alt="" /> に戻って **GitBook Agent を設定する** <Image src="https://test-dai.imgix.net/org-4afef969-21f9-40f3-b5b8-b06c8b6cf68f/doc-22a3b060-9539-4176-97e4-49120e02f5d1/ba76c24cf90e5026-spaces-NkEGS7hzeqa35sMXQZ4X-uploads-wkBqgOPry9HAcW4cxJk0-settings.svg?rasterize-bypass=true" alt="" />.

#### カスタム指示の例

GitBook Agent の設定に追加できるカスタム指示の例を以下に示します。

```
あなたは Stripe のテクニカルライターです。明快で直接的な言葉を使い、華美さより正確さを優先してください。ガイドでは、必ず 1 文の要約で概念を導入し、内容を構造化されたセクションに分けてください。クイックスタートでは、必ずステッパーを使い、各ステップは行動を先に、簡潔にしてください。
```

### FAQ

<Expandable title="GitBook Agent は私のデータをどのように使用しますか？">
  お客様のデータをプライバシーに配慮して保護するため、当社のデータ保護方針に従っています。

  GitBook Agent は、AI モデルの学習にあなたのデータを使用しません。GitBook Agent を提供する目的に限り、あなたが GitBook Agent に追加した情報を OpenAI と共有します。詳細は OpenAI のプライバシーポリシーをご覧ください。
</Expandable>

<Expandable title="GitBook Agent の料金はいくらですか？">
  GitBook Agent はベータ版の間、すべてのプランで無料です。Pro を利用しておらず、トライアルでもない場合、無料利用には週 10 件のメッセージが含まれます。

  [翻訳](/ja/docs/gitbook-agent/translations) 月額の追加オプションとして別料金です。詳しくは [料金セクション](/ja/docs/gitbook-agent/translations#pricing) で詳細を確認してください。
</Expandable>

<Expandable title="GitBook Agent の出力のデフォルトのトーンは変更できますか？">
  はい。GitBook Agent のデフォルトの個性やトーンは上書きできます。

  より詳細な出力や、特定のスタイル・トーンを希望する場合は、サイトレベルの指示または変更リクエスト内のプロンプトで GitBook Agent に伝えてください。
</Expandable>
