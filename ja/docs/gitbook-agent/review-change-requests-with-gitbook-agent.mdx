〜に加えて [コンテンツを作成する](/ja/docs/gitbook-agent/write-and-edit-with-ai)、GitBook Agent は変更リクエストをレビューして、エラーをすばやく見つけて修正したり、改善案を提案したり、そのほかさまざまなことができます。

Agent はドキュメント全体のコンテキストを理解し、さらに [チームのスタイルガイド](/ja/docs/gitbook-agent/overview#add-a-style-guide-and-custom-instructions) を追加して、チームのスタイルに沿いながら変更をレビューできるようにします。

### GitBook Agent で変更リクエストをレビューする

GitBook Agent にレビューを依頼できるのは、任意の [開いている変更リクエスト](/ja/docs/gong-tong-zuo-ye/change-requests/change-requests-screen) あなたのサイト内で。

開いている変更リクエストを表示しているときに、GitBook Agent をレビュー担当者として追加できます。レビュー担当者として追加されると、GitBook Agent は変更内容を確認し、公開済みサイトとスタイルガイドのコンテキストをもとに、正確さ、わかりやすさ、そのほかの観点からレビューします。

自分で変更を確認したい場合は、エディタで変更リクエストを開き、 **変更** タブに切り替えます。エディタ下部のフローティング差分ナビゲーターでは、変更されたブロック間を移動したり、差分のある次のページへ進んだり、利用可能なレビューアクションで最後の変更からレビューを完了したりできます。

必要に応じて追加の変更を提案してくれます — そして Agent にそれを実装させたい場合は、次のいずれかで指示できます [チャットウィンドウから](/ja/docs/gitbook-agent/write-and-edit-with-ai#open-gitbook-agent-chat-window-in-any-change-request) または [コメントでタグ付けする](/ja/docs/gitbook-agent/write-and-edit-with-ai#tag-gitbook-agent-in-a-comment).

変更に満足したら、 [変更リクエストをマージして](/ja/docs/gong-tong-zuo-ye/change-requests#merge) 変更を公開できます。

### GitBook Agent で変更リクエストを更新する

GitBook Agent は、チームのもう一人のメンバーのようにあなたと一緒に作業します。 [変更リクエスト内で](/ja/docs/gong-tong-zuo-ye/change-requests/change-requests-in-a-space)、 [GitBook Agent のチャットウィンドウを開いて](/ja/docs/gitbook-agent/write-and-edit-with-ai#open-gitbook-agent-chat-window-in-any-change-request) 共同作業を始められます。

次のようなことを依頼できます：

- 新しいコンテンツを書いたり、既存のセクションを拡張したりする
- タイプミスやスペルミスを修正する
- わかりにくい、または古くなった説明を書き直す
- ページを正確性、わかりやすさ、完全性の観点でレビューする
- コード例を生成または更新する
- 不足しているドキュメントやワークフローの抜けを特定する。

詳しくはこちら： [GitBook Agent を使った執筆についてはこちら](/ja/docs/gitbook-agent/write-and-edit-with-ai).
