#### クイックガイド

<Expandable title="GitBook Agent で最初のドラフトを作成するにはどうすればよいですか？">
  GitBook Agent は、範囲を定めた依頼をドラフト変更に変換できます。

  このガイドでは、コンテキストの追加、ドラフトのレビュー、内容の調整について説明します。
</Expandable>

<Expandable title="GitBook Agent で変更リクエストをレビューするにはどうすればよいですか？">
  GitBook Agent は、ドキュメントの変更をレビューし、マージ前に問題を特定できます。

  このガイドでは、レビューの依頼、フィードバックへの対応、変更の承認について説明します。
</Expandable>

<Expandable title="ドキュメントの抜け漏れを自動で見つけて修正するにはどうすればよいですか？">
  GitBook Agent は、古くなったドキュメントや不完全なドキュメントを特定し、修正案を作成できます。

  このガイドでは、改善の実行、提案された変更のレビュー、更新の公開について説明します。
</Expandable>

<Expandable title="GitBook Agent でドキュメントを翻訳するにはどうすればよいですか？">
  GitBook Agent はコンテンツを翻訳し、翻訳版を元のソースと整合した状態に保てます。

  このガイドでは、翻訳の作成、ローカライズされたコンテンツのレビュー、更新の管理について説明します。
</Expandable>
