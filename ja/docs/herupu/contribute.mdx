GitBook のドキュメントへの貢献に時間を割いていただき、ありがとうございます。すべての貢献はチームによってレビューされます。

このドキュメントは GitBook で公開されており、Git Sync を使用してサイトを最新の状態に保つために `public-docs` GitHub 上のリポジトリです。レビューされ、承認され、リポジトリにマージされた変更は自動的にデプロイされます。

#### 貢献する内容

- 修正 — 不正確な手順、古いスクリーンショット、壊れたリンク、誤字脱字。
- 明確化 — 技術的には正しいものの、追いにくいセクション。
- 不足している詳細 — ページで扱っていないエッジケースやエラーメッセージ。

ドキュメントではなく GitBook 自体の問題については、「バグを報告する」をご覧ください。

#### 変更を送信する方法

1. に対してプルリクエストを開いてください `public-docs` リポジトリ。
2. 何を変更したか、なぜ変更したかを説明してください。編集中の公開ページへのリンクを付けてください。
3. ドキュメントチームのメンバーがレビューします。承認されマージされたら、変更は自動的にデプロイされます。
