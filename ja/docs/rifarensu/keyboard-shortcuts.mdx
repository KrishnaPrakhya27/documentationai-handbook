ショートカットキーを使うと、コンテンツの移動や編集を簡単かつ素早く行えます。

## 公開済みのドキュメントでは

| 説明 | Mac | Windows |
| --- | --- | --- |
| 〜を開き、 **質問または検索** パネル | <kbd>⌘</kbd>+<kbd>K</kbd> | <kbd>Ctrl</kbd>+<kbd>K</kbd> |
| 〜を開き、 **GitBook Assistant** チャットウィンドウ | <kbd>⌘</kbd>+<kbd>I</kbd> | <kbd>Ctrl</kbd>+<kbd>I</kbd> |
| ～を閉じる **質問または検索** または **GitBook Assistant** パネル | <kbd>Esc</kbd> | <kbd>Esc</kbd> |

## GitBookアプリでは

| 説明 | Mac | Windows |
| --- | --- | --- |
| コピー | <kbd>⌘</kbd>+<kbd>C</kbd> | <kbd>Ctrl</kbd>+<kbd>C</kbd> |
| 貼り付け | <kbd>⌘</kbd>+<kbd>V</kbd> | <kbd>Ctrl</kbd>+<kbd>V</kbd> |
| 書式なしのテキストとして貼り付け | <kbd>⌘</kbd>+<kbd>Shift</kbd>+<kbd>V</kbd> | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>V</kbd> |
| 元に戻す | <kbd>⌘</kbd>+<kbd>Z</kbd> | <kbd>Ctrl</kbd>+<kbd>Z</kbd> |
| やり直し | <kbd>⌘</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> |
| 選択したブロックを複製 | <kbd>⌘</kbd> \+ <kbd>D</kbd> | <kbd>Ctrl</kbd> \+ <kbd>D</kbd> |
| コンテンツブロック（コード、タブ、表、引用など）を終了 | <kbd>⌘</kbd>+<kbd>Enter</kbd> | <kbd>Ctrl</kbd>+<kbd>Enter</kbd> |
| ブロック挿入パレットを開く。 | <kbd>/</kbd> | <kbd>/</kbd> |
| ブロック変更パレットを開く。 | <kbd>⌘</kbd>+<kbd>/</kbd> | <kbd>Ctrl</kbd>+<kbd>/</kbd> |
| 太字の切り替え | <kbd>⌘</kbd>+<kbd>B</kbd> | <kbd>Ctrl</kbd>+<kbd>B</kbd> |
| 斜体の切り替え | <kbd>⌘</kbd>+<kbd>I</kbd> | <kbd>Ctrl</kbd>+<kbd>I</kbd> |
| 取り消し線の切り替え | <kbd>⌘</kbd>+<kbd>Shift</kbd>+<kbd>S</kbd> | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>S</kbd> |
| インラインコードの切り替え | <kbd>⌘</kbd>+<kbd>E</kbd> | <kbd>Ctrl</kbd>+<kbd>E</kbd> |
| リンクを挿入または切り替え | <kbd>⌘</kbd>+<kbd>K</kbd> （エディタ内） | <kbd>Ctrl</kbd>+<kbd>K</kbd> （エディタ内） |
| ブロック全体を選択 | <kbd>Esc</kbd> | <kbd>Esc</kbd> |
| ダイアログまたは検索パネルを閉じる | <kbd>Esc</kbd> （ナビゲーション） | <kbd>Esc</kbd> （ナビゲーション） |
| 質問または検索パネルを開く | <kbd>⌘</kbd>+<kbd>K</kbd> （エディタ外） | <kbd>Ctrl</kbd>+<kbd>K</kbd> （エディタ外） |

### ブロック固有のショートカット

#### 段落と見出しブロック

| 説明 | Mac | Windows |
| --- | --- | --- |
| 段落内でソフト改行を挿入 | <kbd>Shift</kbd> \+ <kbd>Enter</kbd> | <kbd>Shift</kbd> \+ <kbd>Enter</kbd> |
| 段落に変換 | <kbd>⌘</kbd> \+ <kbd>⌥</kbd> \+ <kbd>0</kbd> | <kbd>Ctrl</kbd> \+ <kbd>Alt</kbd> \+ <kbd>0</kbd> |
| 見出し1に変換 | <kbd>⌘</kbd> \+ <kbd>⌥</kbd> \+ <kbd>1</kbd> | <kbd>Ctrl</kbd> \+ <kbd>Alt</kbd> \+ <kbd>1</kbd> |
| 見出し2に変換 | <kbd>⌘</kbd> \+ <kbd>⌥</kbd> \+ <kbd>2</kbd> | <kbd>Ctrl</kbd> \+ <kbd>Alt</kbd> \+ <kbd>2</kbd> |
| 見出し3に変換 | <kbd>⌘</kbd> \+ <kbd>⌥</kbd> \+ <kbd>3</kbd> | <kbd>Ctrl</kbd> \+ <kbd>Alt</kbd> \+ <kbd>3</kbd> |

#### 表ブロック

| 説明 | Mac | Windows |
| --- | --- | --- |
| 下に行を挿入 | <kbd>⌥</kbd> \+ <kbd>Shift</kbd> \+ <kbd>Enter</kbd> | <kbd>Alt</kbd> \+ <kbd>Shift</kbd> \+ <kbd>Enter</kbd> |
| 上に行を挿入 | <kbd>⌥</kbd> \+ <kbd>Enter</kbd> | <kbd>Alt</kbd> \+ <kbd>Enter</kbd> |
| 次の行へ移動 | <kbd>Enter</kbd> | <kbd>Enter</kbd> |
| テキストセル内に改行を挿入 | <kbd>Shift</kbd> \+ <kbd>Enter</kbd> | <kbd>Shift</kbd> \+ <kbd>Enter</kbd> |
| 行を削除 | <kbd>⌘</kbd> \+ <kbd>-</kbd> | <kbd>Ctrl</kbd> \+ <kbd>-</kbd> |

#### リストとコードブロック

| 説明 | Mac | Windows |
| --- | --- | --- |
| インデントレベルを上げる | <kbd>Tab</kbd> | <kbd>Tab</kbd> |
| インデントレベルを下げる | <kbd>Shift</kbd> \+ <kbd>Tab</kbd> | <kbd>Shift</kbd> \+ <kbd>Tab</kbd> |
