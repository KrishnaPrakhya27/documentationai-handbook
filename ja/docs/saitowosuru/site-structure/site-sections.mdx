セクションを使うと、ドキュメントを 1 つのサイトに集約できます。個別の製品を整理するために使用してください。また、内容を調整して異なる対象者に提供することもできます。

セクションをグループ化すると、ナビゲーションバーにドロップダウンを作成できます。グループを追加すると、サイトに階層構造ができます。

### セクション、それともバリアント？

各セクションにはそれぞれ独自のコンテンツが入ります。明確に分かれたドキュメント領域にはセクションを使用してください。これらは製品、対象者、トピックを表せます。

同じコンテンツの別バージョンには、 [コンテンツのバリアント](/ja/docs/saitowosuru/site-structure/variants)を使用します。バリアントにはローカライズ版や過去の製品バージョンが含まれます。

### セクションを追加

セクションを追加するには：

1. サイトのサイドバーで、 **サイト構造**.
2. 表の下で、 **新しいセクション**.
3. 追加するコンテンツを選択します。

セクションは表に表示されます。また、公開済みサイトではタブとしても表示されます。

### セクショングループを作成

セクショングループを作成すると、1 つの見出しの下にナビゲーションのドロップダウンが作成されます。グループ化されたセクションには任意で説明を付けられます。説明はセクションタイトルの下に表示されます。

グループを作成するには：

1. の横の **新しいセクション**をクリックし、
2. 選択します **新しいセクショングループ**.
3. グループ名を入力します。
4. クリック **セクションを追加**.
5. 既存のセクションを追加するか、新しいコンテンツを選択します。

サイトが複数の言語をサポートしている場合は、グループタイトル、セクションタイトル、説明を翻訳してください。詳しくは [多言語セクション](/ja/docs/saitowosuru/site-structure/multilingual-sections).

### セクションを編集

セクションを編集するには：

1. セクションの表の行で、 **編集**.
2. 名前、アイコン、またはスラッグを変更します。
3. クリック **保存**.

セクションを削除するには、 **削除** を左下隅でクリックします。

<Callout kind="info">
  セクションのスラッグを変更すると、正規 URL が変わります。GitBook は古い URL からリダイレクトを作成します。また、 [リダイレクトを手動で作成する](/ja/docs/gong-kai/site-redirects).
</Callout>

### セクションを非表示にする

**サイトナビゲーションに表示** は、セクションをサイトの上部ナビゲーションに表示するかどうかを制御します。セクションを非表示にすると、公開済みナビゲーションから削除されます。セクションやそのコンテンツが削除されるわけではありません。

セクションを非表示にするには：

1. サイトのサイドバーで、 **サイト構造**.
2. セクションの表の行で、 **編集**.
3. オフにする **サイトナビゲーションに表示**.
4. クリック **保存**.

この設定はセクションの表示/非表示を制御します。 **ページを非表示**とは異なり、これはセクションの目次からページを非表示にします。訪問者には、公開済みサイトのナビゲーションで非表示のセクションは表示されません。

### セクションの順序を変更

セクションは、 **サイト構造** 表と同じ順序で表示されます。セクションの順序を変更するには、ドラッグハンドルを上下にドラッグします。セクションのコンテンツも一緒に移動します。新しい順序はすぐにサイトに反映されます。

キーボードを使うには：

1. スペースキーを押して **Space** を押してセクションを選択します。
2. 矢印キーを押してセクションを移動します。
3. スペースキーを押して **Space** を押して確定します。

### ホームセクションを設定

ホームセクションは、訪問者がサイトを開いたときに表示されます。サイトのルート URL で読み込まれます。ほかのセクションには、ルート URL にスラッグが追加されます。

ホームセクションを設定するには：

1. セクションの表の行で、 **操作** メニューを開きます。
2. クリック **ホームに設定**.

### ホームバリアントを設定

セクションに複数のバリアントがある場合、訪問者が最初に開くバリアントを選択します。

ホームバリアントを設定するには：

1. 開く **サイト設定**.
2. クリック **構造**.
3. 更新するセクションをクリックします。
4. 訪問者が最初に開くバリアントを見つけます。
5. クリック **ホームに設定**.

### セクションを削除

セクションを削除するには：

1. サイトのサイドバーで、 **サイト構造**.
2. セクションの **操作** メニューを開きます。
3. クリック **削除**.

<Callout kind="success">
  セクションを削除すると、公開は解除され、そのバリアントも公開されなくなります。コンテンツ自体は削除されません。まだ [すべてのコンテンツ](/ja/docs/kontentsuwo/content-structure/all-content).
</Callout>
