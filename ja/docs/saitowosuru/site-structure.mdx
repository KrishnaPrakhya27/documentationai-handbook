サイト上のコンテンツは、その [セクション](/ja/docs/kontentsuwo/content-structure/space)。1つまたは複数のセクションを追加できます。GitBook はそれぞれを公開し、各セクション間のナビゲーションを処理します。

## コンテンツタイプ

サイト内のコンテンツは、2つの異なるコンテンツタイプのいずれかとして扱えます。これにより、GitBook がそれをどのように扱い、訪問者に表示するかが決まります。

## サイト構造の管理

サイトの構造を管理することで、サイト上部のナビゲーションバーも管理できます。このナビゲーションバーでは、訪問者がセクション、グループ、外部リンクを開けます。

構造エディタを開く場所： **サイト構造**、以下の **一般** をサイトのサイドバーで開きます。ここでサイトのセクション、バリアント、外部リンクを確認できます。

サイトは、サイト名の付いた1つのセクションと、セットアップ中に作成したコンテンツを含む1つのバリアントから始まります。

<Image src="https://test-dai.imgix.net/org-4afef969-21f9-40f3-b5b8-b06c8b6cf68f/doc-22a3b060-9539-4176-97e4-49120e02f5d1/5c9107ce5273d70d-spaces-NkEGS7hzeqa35sMXQZ4X-uploads-D4oCABc0YRJAFzaaVBpn-structure-2x.png?fm=auto&auto=compress%2Cformat" alt="A GitBook screenshot showing a docs site's structure" caption="公開済みドキュメントサイトの構造。" />

### ドキュメントサイトにセクションを追加する

追加するには [セクション](/ja/docs/saitowosuru/site-structure/site-sections)、 **セクションを追加** ボタンを表の下でクリックし、追加するコンテンツを選択します。すると新しいセクションが表に追加され、サイト上部のタブとして訪問者に表示されます。

追加するには [バリアント](/ja/docs/saitowosuru/site-structure/variants)、 **バリアントを追加** ボタンを追加先のセクションでクリックし、追加するコンテンツを選択します。すると新しいバリアントが選択したセクション内のバリアント一覧に追加され、サイト上のバリアントのドロップダウンで訪問者が利用できるようになります。

コンテンツをバリアントまたはセクションとして追加すると、タイトルに基づいて名前とスラッグが生成されます。

### 外部リンクを追加する

外部リンクは、サイト外の移動先をナビゲーションに追加します。リンクを独立したナビゲーション項目として追加するか、関連するセクションと一緒にセクショングループに配置します。

外部リンクを追加するには：

1. サイトのサイドバーで、 **サイト構造**.
2. 追加メニューで、 **外部リンク**.
3. リンクのラベルとリンク先URLを入力します。
4. リンクを個別に追加するか、セクショングループに追加するかを選択します。
5. クリック **保存**.

リンクは、公開サイトのナビゲーションに選択した位置で表示されます。

### セクションまたはバリアントの変更

<Image src="https://test-dai.imgix.net/org-4afef969-21f9-40f3-b5b8-b06c8b6cf68f/doc-22a3b060-9539-4176-97e4-49120e02f5d1/0f39994a710c82d1-spaces-NkEGS7hzeqa35sMXQZ4X-uploads-oXvDCD0U1CNnP8pJHL1L-edit_variant-2x.png?fm=auto&auto=compress%2Cformat" alt="A GitBook screenshot showing how to edit a variant" caption="サイトのセクションまたはバリアントを更新します。" />

各セクションとバリアントの名前とスラッグは、 **編集** <Image src="https://test-dai.imgix.net/org-4afef969-21f9-40f3-b5b8-b06c8b6cf68f/doc-22a3b060-9539-4176-97e4-49120e02f5d1/ab76723fb229a5ad-spaces-NkEGS7hzeqa35sMXQZ4X-uploads-A3OfGjPkE5GnOQvN36jN-edit.svg?rasterize-bypass=true" alt="The Edit icon in GitBook" /> ボタンを編集したい項目の表の行でクリックすると、モーダルが開きます。変更したいフィールドを編集し、次に **保存** ボタンをクリックして保存します。

<Callout kind="info">
  セクションのスラッグを変更すると、正規URLが変更されます。GitBook は古いURLから新しいURLへ自動的にリダイレクトを作成します。また、 [手動でリダイレクトを作成することもできます](/ja/docs/gong-kai/site-redirects).
</Callout>

<Callout kind="info">
  スラッグは組織全体で一意です。各パスは1つのサイトでしか使用できず、別のサイトをまたいで使うこともできません。「path is already taken」というエラーが表示された場合は、別のサイトですでにそのスラッグが使われています。コンテンツにとって意味が通じる範囲で、少し変えたスラッグを選んでください。
</Callout>

セクションまたはバリアントを置き換えるには、まずその **編集** <Image src="https://test-dai.imgix.net/org-4afef969-21f9-40f3-b5b8-b06c8b6cf68f/doc-22a3b060-9539-4176-97e4-49120e02f5d1/ab76723fb229a5ad-spaces-NkEGS7hzeqa35sMXQZ4X-uploads-A3OfGjPkE5GnOQvN36jN-edit.svg?rasterize-bypass=true" alt="The Edit icon in GitBook" /> ボタンをクリックして削除し、次に **削除** ボタンをモーダルの左下でクリックします。項目が削除されたら、 **セクションを追加** または **バリアントを追加** ボタンをクリックして再度追加します。

### セクションまたはバリアントの並べ替え

サイトでは、セクションとバリアントが **サイト構造** 表に表示される順に並びます。 **ドラッグハンドル** <Image src="https://test-dai.imgix.net/org-4afef969-21f9-40f3-b5b8-b06c8b6cf68f/doc-22a3b060-9539-4176-97e4-49120e02f5d1/4c115a43418b42e3-spaces-NkEGS7hzeqa35sMXQZ4X-uploads-aS1QvPIBVYwhpFTGcPBN-options-menu.svg?rasterize-bypass=true" alt="The Options menu icon in GitBook" /> をつかんで上下に移動します。変更後の順序はすぐにサイトに反映されます。

キーボードでもコンテンツを選択して移動できます。スペースバーでセクションまたはバリアントを選択し、矢印キーで上下に移動します。もう一度スペースバーを押して新しい位置を確定します。

### デフォルトコンテンツの設定

サイトに複数のセクションがある場合、1つのセクションが **デフォルト**としてマークされます。このセクションは訪問者がサイトにアクセスしたときに表示され、サイトのルートURLから配信されます。他のセクションにはそれぞれ、ルートURLに追加されるスラッグがあります。

セクション内に複数のバリアントがある場合、1つのバリアントがデフォルトとしてマークされます。セクションと同様に、デフォルトのバリアントは訪問者がサイトにアクセスしたとき、またはセクションを訪れたときに表示されます。他のバリアントにはそれぞれ、セクションのURLに追加されるスラッグがあります。

セクションまたはバリアントをデフォルトに設定するには、 **アクションメニュー** <Image src="https://test-dai.imgix.net/org-4afef969-21f9-40f3-b5b8-b06c8b6cf68f/doc-22a3b060-9539-4176-97e4-49120e02f5d1/4fa265378c13a520-spaces-NkEGS7hzeqa35sMXQZ4X-uploads-89MTSo5XRpPMVr1T0rxS-actions.svg?rasterize-bypass=true" alt="The Actions menu icon in GitBook" /> をその表の行で開き、次に **デフォルトに設定**.

<Callout kind="info">
  コンテンツをデフォルトに設定すると、セクションのルートから配信されるため、スラッグ欄はなくなります。GitBook は古いスラッグを適切なパスにリダイレクトし、訪問者が引き続きコンテンツを閲覧できるようにします。
</Callout>

### サイトからコンテンツを削除する

サイトからセクションまたはバリアントを削除するには、 **サイト構造**、以下の **一般** サイトのサイドバーで構造エディタを開き、削除したいコンテンツを見つけます。

開く **アクションメニュー** <Image src="https://test-dai.imgix.net/org-4afef969-21f9-40f3-b5b8-b06c8b6cf68f/doc-22a3b060-9539-4176-97e4-49120e02f5d1/4fa265378c13a520-spaces-NkEGS7hzeqa35sMXQZ4X-uploads-89MTSo5XRpPMVr1T0rxS-actions.svg?rasterize-bypass=true" alt="The Actions menu icon in GitBook" /> 削除したいコンテンツの **削除**.

<Callout kind="success">
  サイトからコンテンツを削除すると、公開サイトからは消えますが、 **コンテンツ自体は削除されません** — なお、 [すべてのコンテンツ](/ja/docs/kontentsuwo/content-structure/all-content).
</Callout>

セクションのコンテンツを完全に削除しても、サイトは設定やカスタマイズとともに引き続き利用できます。削除されたコンテンツは **ゴミ箱** に7日間保存され、その後完全に削除されます。削除したセクションがサイトのデフォルトだった場合は、デフォルト設定が正しく維持されているか確認してください。
