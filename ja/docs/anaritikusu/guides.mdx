#### クイックガイド

<Expandable title="サイト分析はどのように使えばよいですか？">
  サイト分析ダッシュボードから、トラフィック、フィードバック、検索、Ask AI のアクティビティを確認します。

  このガイドでは、データの絞り込み方法とコンテンツの機会の見つけ方を紹介します。
</Expandable>

<Expandable title="検索データとフィードバックデータはどのように使えばよいですか？">
  検索語句とページ評価により、対応が必要なコンテンツが明らかになります。

  このガイドでは、ギャップを見つけてドキュメント改善の優先順位を付ける方法を紹介します。
</Expandable>

<Expandable title="Google アナリティクスでドキュメントを追跡するにはどうすればよいですか？">
  GitBook のサイト分析を超えてトラフィックを測定するために、Google アナリティクスを接続します。

  このガイドでは、統合、測定 ID、データ収集について説明します。
</Expandable>

<Expandable title="カスタム分析レポートはどのように作成すればよいですか？">
  Events Aggregation API を使用して、自分のツールでドキュメントの利用状況を分析します。

  このガイドでは、イベントデータ、クエリ、ダッシュボードのレポートについて説明します。
</Expandable>
