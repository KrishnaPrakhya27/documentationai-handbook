セクショングループを使うと、サイト内の関連するセクションを整理でき、訪問者がサイトの構造をより簡単に移動できるようになります。

セクショングループは次とは異なります [ページ](/ja/docs/kontentsuwo/content-structure/page)。ページグループは1つのセクション内のページを整理します。セクショングループはサイトナビゲーション内のセクションを整理します。どちらもグループと呼ばれますが、アイコンはそれぞれ個別に設定します。

### グループを作成する

1. サイトで、次をクリックします <strong>追加…</strong>.
2. 次をクリックします **新しいグループ**.
3. グループを表すタイトルとアイコンを選択します。

新しいグループは最初は **下書きです**：公開するまで、公開済みサイトには表示されません。

### グループにセクションを追加する

1. 次を開きます **構造エディター**.
2. セクションをグループ内にドラッグするか、グループ外へドラッグします。

または、グループ内で直接新しいセクションを作成します。

### グループを公開する

1. グループの **アクションメニュー** <Image src="https://test-dai.imgix.net/org-4afef969-21f9-40f3-b5b8-b06c8b6cf68f/doc-22a3b060-9539-4176-97e4-49120e02f5d1/4fa265378c13a520-spaces-NkEGS7hzeqa35sMXQZ4X-uploads-89MTSo5XRpPMVr1T0rxS-actions.svg?rasterize-bypass=true" alt="The Actions menu icon in GitBook" />.
2. 次をクリックします **公開**.

または、構造エディターから複数の下書きを一度に公開します。

下書きグループがサイトでどのように表示されるかをプレビューするには、サイトプレビューを次の間で切り替えます **公開中** と **公開中 + 下書き**.

### グループ名を変更する

1. 次をクリックします **アクションメニュー** アイコン <Image src="https://test-dai.imgix.net/org-4afef969-21f9-40f3-b5b8-b06c8b6cf68f/doc-22a3b060-9539-4176-97e4-49120e02f5d1/4fa265378c13a520-spaces-NkEGS7hzeqa35sMXQZ4X-uploads-89MTSo5XRpPMVr1T0rxS-actions.svg?rasterize-bypass=true" alt="The Actions menu icon in GitBook" /> グループの横にある。
2. 次をクリックします **名前を変更**.
3. グループのタイトルまたはアイコンを変更します。

### グループを削除する

1. グループの **アクションメニュー** <Image src="https://test-dai.imgix.net/org-4afef969-21f9-40f3-b5b8-b06c8b6cf68f/doc-22a3b060-9539-4176-97e4-49120e02f5d1/4fa265378c13a520-spaces-NkEGS7hzeqa35sMXQZ4X-uploads-89MTSo5XRpPMVr1T0rxS-actions.svg?rasterize-bypass=true" alt="The Actions menu icon in GitBook" />.
2. 次をクリックします **削除**.
