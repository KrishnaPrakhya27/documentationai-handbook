タグを使って関連コンテンツをグループ化し、リリース状態を示し、古いコンテンツを示し、その他、読者がドキュメントを素早く把握するのに役立つことを行えます。

#### ページにタグを付ける

ページを開き、次に **タグ** メニュー — ページタイトルにカーソルを合わせると表示されます — を開き、タグを作成または追加します。タグをドラッグして、ページ上での表示順を変更できます。

1. ページを開きます。
2. ページタイトルにカーソルを合わせて、 **ページオプション**.
3. 1つ以上のタグを追加します。

タグをドラッグして、ページ上での表示順を変更します。

#### ページ上でタグを表示または非表示にする

タグはデフォルトでページ上部に表示されます。関連するメタデータを保持したままページのタグを非表示にするには、次の操作を行います。

- 〜を開き、 **タグ** メニュー
- オフにする **ページにタグを表示** タグをメタデータのみにするため

1. 開く **ページオプション**.
2. オフにする **ページにタグを表示**.

#### 目次にタグを表示する

各ページごとに、目次に表示するタグを1つ選べます。表示するタグを選ぶには、次の操作を行います。

- 〜を開き、 **タグ** メニュー
- を使用するか、サーバーを **目次に表示** ドロップダウンでタグを選択
- タグをクリックして、 **表示**, **削除** または **目次で置き換え**.

1. 開く **ページオプション**.
2. 次の項目の下で **タグ**、ドロップダウンからタグを **目次に表示** ドロップダウン。

#### 更新ブロックにタグを付ける

各更新ブロックには独自のタグを付けられます。

1. 更新ブロックを開きます。
2. クリックして **タグを追加** 日付の下に。
3. タグピッカーを使って、タグの追加、削除、並べ替えを行います。

#### ライブラリでタグを管理する

スペースのタグを表示、作成、管理するには、 **ライブラリ** から [目次](/ja/docs/kontentsuwo/content-structure/page#table-of-contents) を選択し、 **タグ**。これには、 **タグ** メニューを開いて **タグライブラリを開く**。<br /><br />タグを選択して **ライブラリに表示**.

セクションのタグを表示、作成、管理するには、

1. 〜を開き、 **ライブラリ** 目次から行います。
2. クリックして **タグ**.

各タグには次の要素があります。

- ラベル — 読者に表示されるもの
- スラッグ — 安定した識別子
- 任意のアイコンまたは絵文字

#### Markdown内のタグ

Git Sync を使用している場合、タグはページの frontmatter に表示されます:

```yaml
---
description: "タグは、ページや更新ブロックに追加できる再利用可能なラベルです。このページでは、タグの作成、追加、管理方法を説明します"
tags:
  - ニュース
  - 実験
  - tag: beta
    primary: true
  - プロ
---
```

標準タグには文字列を使用します。 `primary: true` 1つのタグに適用してページの主タグにします — GitBook はそのタグを目次に表示できます。
