セクションは、関連するページ群に取り組むサイト内の一部です。セクションでは、コンテンツの作成、ページの整理、統合の追加などを行えます。各セクションはサイトに属しており、関連するセクションをグループにまとめて整理できます。

<Callout kind="info">
  GitBook APIでは、セクションは `space` オブジェクトとして表されます。これは API 連携や Git Sync には影響しません。
</Callout>

### セクションを作成する

1. サイトで、次をクリックします <strong>追加…</strong>.
2. クリックして **新しいセクション**.

サイトのトップレベルまたはグループ内にセクションを作成します。新しいセクションは最初、 **下書き**：サイトの一部としてチームが編集できますが、公開するまで訪問者には表示されません。

セクションヘッダーの名前にカーソルを合わせて、セクション名を編集します。

### 下書きのセクションを公開する

1. セクションの〜を開きます **アクションメニュー** <Image src="https://test-dai.imgix.net/org-4afef969-21f9-40f3-b5b8-b06c8b6cf68f/doc-22a3b060-9539-4176-97e4-49120e02f5d1/4fa265378c13a520-spaces-NkEGS7hzeqa35sMXQZ4X-uploads-89MTSo5XRpPMVr1T0rxS-actions.svg?rasterize-bypass=true" alt="The Actions menu icon in GitBook" />.
2. クリックして **公開**.

または、構成エディターから複数の下書きを一度に公開します。

下書きがサイト上でどのように表示されるかをプレビューするには、サイトプレビューを次の間で切り替えます **公開** 、 **公開 + 下書き**.

### セクションを複製する

1. セクションの〜を開きます **アクションメニュー** <Image src="https://test-dai.imgix.net/org-4afef969-21f9-40f3-b5b8-b06c8b6cf68f/doc-22a3b060-9539-4176-97e4-49120e02f5d1/4fa265378c13a520-spaces-NkEGS7hzeqa35sMXQZ4X-uploads-89MTSo5XRpPMVr1T0rxS-actions.svg?rasterize-bypass=true" alt="The Actions menu icon in GitBook" />.
2. クリックして **複製**.

セクションを複製すると、元のセクションのコピーが同じ場所（サイトまたはグループ）に作成されます。

<Callout kind="alert">
  セクションを複製すると、元のセクションの内容がコピーされます。リビジョンやバージョン履歴はコピーされません。
</Callout>

### セクションを移動または並べ替える

サイドバーのコンテンツツリーは読み取り専用です。セクションをグループに移動・グループから移動したり、セクションの順序を並べ替えたりするには：

1. 〜を開き、 **構成エディター**.
2. セクションを新しい位置にドラッグします。

変更はすぐにサイドバーと公開済みサイトに反映されます。

### セクションを削除する

1. セクションの〜を開きます **アクションメニュー** <Image src="https://test-dai.imgix.net/org-4afef969-21f9-40f3-b5b8-b06c8b6cf68f/doc-22a3b060-9539-4176-97e4-49120e02f5d1/4fa265378c13a520-spaces-NkEGS7hzeqa35sMXQZ4X-uploads-89MTSo5XRpPMVr1T0rxS-actions.svg?rasterize-bypass=true" alt="The Actions menu icon in GitBook" />.
2. クリックして **削除**.

<Callout kind="alert">
  <strong>削除したセクションは、ゴミ箱から最大7日間復元できます。</strong> それ以降は、GitBook によって完全に削除されます。
</Callout>
