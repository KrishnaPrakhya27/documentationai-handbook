ページは、コンテンツを追加、編集、埋め込みできる場所です。ページは常にセクションの中にあり、扱っているトピックや領域ごとに関連コンテンツをまとめられます。

サイトを公開すると、各セクションがサイトのナビゲーションに表示され、その中のページはすべてそのセクションの下に表示されます。

### 目次

セクションには必要なだけページを作成できます。これらはすべて、セクションの目次として画面の左サイドバーに表示されます。公開されたサイトでも目次は同じ場所に表示されますが、 [非表示にする場合を除きます](#page-options).

<Callout kind="info">
  **セクションのランディングページ**

  目次の最初のページは、たとえ目次から非表示になっていても、常にセクションのランディングページです。
</Callout>

### 新しいページを作成

1. ライブ編集モードに入るか、変更リクエストを開きます。
2. クリック <strong>新規追加...</strong> を目次の下部で。
3. クリック **ページ**.

または、目次内のページの間にカーソルを合わせて、 <strong>+</strong> 表示されるアイコンをクリックします。

<Image src="https://test-dai.imgix.net/org-4afef969-21f9-40f3-b5b8-b06c8b6cf68f/doc-22a3b060-9539-4176-97e4-49120e02f5d1/147af17102939bea-spaces-NkEGS7hzeqa35sMXQZ4X-uploads-P0V046UJgzgtkrD1NiQG-creating-content-conten.png?fm=auto&auto=compress%2Cformat" alt="A GitBook screenshot showing an empty page listed in the table of contents" caption="GitBook内の空のページです。左側の目次に一覧表示されているのが確認できます。" />

### 新しいページのオプションが見つからない

<Callout kind="alert">
  セクションでライブ編集が無効になっている場合は、変更リクエストを作成または編集してください。変更リクエストでは、 **新しいページ** ボタン — ページ、ページグループ、リンクを作成するボタン — が目次で利用できます。

  ページを編集する権限がない可能性もあります。
</Callout>

### コンテンツの整理

目次でコンテンツを整理する方法は3つあります:

#### ページ

ページには、タイトル、任意の説明、そしてあらゆる種類のコンテンツを書いたり追加したりできる領域があります。

目次でページを別のページの下にドラッグ＆ドロップしてページを入れ子にします。こうすると **サブページ**.

空の親ページにサブページを追加すると、GitBook は公開版のドキュメント内で、すべてのサブページへのリンクを含む「contents」ページを自動生成します。

<Callout kind="info">
  <strong>ヒント:</strong> ページの入れ子に制限はありませんが、ナビゲーションをシンプルに保つため、3階層を超えないようにしてください。
</Callout>

ページのタイトルを変更すると、ページのスラッグ（URL の最後の部分。たとえば `/hello-world`）も変更されます — ただし、以前にページのスラッグを手動で設定している場合は除きます。

公開されたページの URL は、Git Sync のファイル配置ではなくナビゲーションツリーに従います。URL には、最上位のセクションまたはグループのスラッグ、すべての上位ページまたはグループのスラッグ、そしてページ自身のスラッグが含まれます。

たとえば、この Git Sync のファイル配置:

```
content/
└── setup/
    └── install.md
```

次のようなナビゲーションツリーになります:

```
API
└── Guides
    └── Install
```

スラッグが `api`, `guides`、そして `install`であれば、公開URLは `/api/guides/install`です。ファイルパスはURLを決定しません。

ページのタイトル、リンクタイトル、またはスラッグを変更するには:

1. ページの **アクションメニュー** <Image src="https://test-dai.imgix.net/org-4afef969-21f9-40f3-b5b8-b06c8b6cf68f/doc-22a3b060-9539-4176-97e4-49120e02f5d1/4fa265378c13a520-spaces-NkEGS7hzeqa35sMXQZ4X-uploads-89MTSo5XRpPMVr1T0rxS-actions.svg?rasterize-bypass=true" alt="The Actions menu icon in GitBook" />.
2. クリック **タイトルとスラッグを編集**.

#### ページのリンクタイトル

ナビゲーション項目やリンク用には短いタイトルを保ちながら、ページにより長くSEOに適したタイトルを付けたい場合は、リンクタイトルを定義します。

1. ページの **アクションメニュー** <Image src="https://test-dai.imgix.net/org-4afef969-21f9-40f3-b5b8-b06c8b6cf68f/doc-22a3b060-9539-4176-97e4-49120e02f5d1/4fa265378c13a520-spaces-NkEGS7hzeqa35sMXQZ4X-uploads-89MTSo5XRpPMVr1T0rxS-actions.svg?rasterize-bypass=true" alt="The Actions menu icon in GitBook" />.
2. クリック **タイトルとスラッグを編集**.
3. 「 **ページを編集** 」ダイアログで、そのページのリンクタイトルを有効にして定義します。

Git Sync を使用している場合は、ページのリンクタイトルを `SUMMARY.md` のページリンクで設定します:

```markdown
# 目次

* [ページのメインタイトル](page.md "ページのリンクタイトル")
```

<Callout kind="info">
  <strong>注:</strong> ページのリンクタイトルは、目次、各ページ下部のページ送りボタン、そしてそのページに追加した相対リンクに表示されます。
</Callout>

ページのリンクタイトルは任意です。追加しない場合、そのページには標準のタイトルが使用されます。

#### ページグループ

ページグループは、セクションの目次内で関連ページをまとめます。各ページグループにアイコンを追加できます。

<Callout kind="info">
  ページグループは1つのセクション内のページを整理します。セクショングループはサイトナビゲーション内のセクションを整理します。どちらもグループと呼ばれますが、別のオブジェクトです。参照 [グループ](/ja/docs/kontentsuwo/content-structure/collection).
</Callout>

をクリックしてページグループを作成します <strong>新規追加...</strong> \> **グループ** を目次の下部で。

ページグループは目次の **最上位レベル** にのみ存在します。ページグループ同士を入れ子にすることはできません。

<Callout kind="alert">
  ページグループのスラッグは、すべての子ページURLの一部になります。ページグループを追加、改名、または削除すると、リダイレクトを追加しない限り、子ページのURLが変わり、既存のリンクが壊れます。参照 [サイトのリダイレクト](/ja/docs/gong-kai/site-redirects).
</Callout>

ページグループのタイトル、スラッグ、またはアイコンを変更するには:

1. をクリック **アクションメニュー** アイコン <Image src="https://test-dai.imgix.net/org-4afef969-21f9-40f3-b5b8-b06c8b6cf68f/doc-22a3b060-9539-4176-97e4-49120e02f5d1/4fa265378c13a520-spaces-NkEGS7hzeqa35sMXQZ4X-uploads-89MTSo5XRpPMVr1T0rxS-actions.svg?rasterize-bypass=true" alt="The Actions menu icon in GitBook" /> 目次内でグループタイトルの横にある
2. クリック **名前を変更**.
3. タイトル、スラッグ、またはアイコンを更新します。

<Callout kind="alert">
  `SUMMARY.md` はページグループのアイコンを保存しません。GitBook はそれらを保存しますが、Git Sync は双方向同期しません。リポジトリがページグループを再作成した場合、GitBook は元のアイコンを自動では復元しません。GitBook でアイコンを再設定してください。
</Callout>

#### 外部リンク

目次にリンクを追加して、ユーザーをリンク先コンテンツへ直接移動させます。

をクリックして外部リンクを作成します <strong>新規追加...</strong> \> **外部リンク** を目次の下部で。

### ページアイコンと絵文字

目次をざっと見たときの視認性を高めるため、個々のページに任意のアイコンや絵文字を追加できます。アイコンや絵文字は目次に表示され、ページ上部のタイトルの横にも表示されます。

アイコンや絵文字を追加するには、ページタイトルにカーソルを合わせたときに表示される **アイコンを追加** ボタン、またはタイトルの左側にある絵文字ボタンをクリックします。

### ページオプション

「 **ページオプション** メニューで、セクション内の選択したページの見た目をカスタマイズし、表示/非表示を制御します。

#### レイアウト

メニューを開くか、ページタイトルにカーソルを合わせてページのカバーを変更します。ボタンはページタイトルのすぐ上に表示されます。 **ページオプション** <Image src="https://test-dai.imgix.net/org-4afef969-21f9-40f3-b5b8-b06c8b6cf68f/doc-22a3b060-9539-4176-97e4-49120e02f5d1/8654e1652f7b5b8c-spaces-NkEGS7hzeqa35sMXQZ4X-uploads-Asao5RY8jwAmcYhpVwPI-options.svg?rasterize-bypass=true" alt="The Page options menu icon in GitBook" /> サイドパネルで、各ページをサイトの訪問者にどのように表示するかを選択します。

「 **ページオプション** 公開 **された** コンテンツ。3つのレイアウトプリセットから選ぶか、カスタムレイアウトを作成できます。

各レイアウトプリセットは、次のページ要素の表示/非表示を切り替えます:

- ページタイトル
- ページの説明
- 目次
- ページのアウトライン
- 次/前のリンク
- ページのメタデータ
- タグ

ページに **ライブラリ** → **タグ**から1つ以上のタグを付けます。 **ページにタグを表示** をオンにすると、ページヘッダーに表示されます。あるいは1つのタグをページの主要タグとして選ぶこともでき、GitBook は目次内のページの横にそれを表示できます。詳しくは Tags を参照してください。

このメニューからページのグローバル幅も設定できます。 **ワイド** を選ぶと、表、カード、コードブロックなどのブロックに公開ページ上でより多くのスペースを与えられます。見栄えのするランディングページに適しています。

#### 表示設定

公開ドキュメントでどのページを表示または非表示にするか、また各ページをサイト内検索や検索エンジンに表示するかどうかを選択します。

サイトの目次からページまたはページグループを非表示にするには:

1. ページの **アクションメニュー** <Image src="https://test-dai.imgix.net/org-4afef969-21f9-40f3-b5b8-b06c8b6cf68f/doc-22a3b060-9539-4176-97e4-49120e02f5d1/4fa265378c13a520-spaces-NkEGS7hzeqa35sMXQZ4X-uploads-89MTSo5XRpPMVr1T0rxS-actions.svg?rasterize-bypass=true" alt="The Actions menu icon in GitBook" />.
2. 切り替え **ページを非表示**.

非表示のページは、公開された目次からのみ非表示になります。サイトの MCP サーバーおよび `llms-full.txt`.

Git Sync を使用している場合、非表示ページには Markdown ファイル内に次のフロントマターが含まれます:

```markdown
---
hidden: true
---
```

<Callout kind="alert">
  非表示にする **ページタイトル** または **ページの説明** 公開コンテンツ内のページヘッダーのみを非表示にします。ページ本文内の見出しは削除されません。見出しレベルの詳細は Headings を参照してください。
</Callout>

#### メタデータ（SEO）

使用 **ページオプション → メタデータ** を使って、検索エンジンが類似ページ間の関係をどのように理解するかを制御します（例: ドキュメントのバージョンやコンテンツのバリエーション）。

- **正規URL**: このページの優先される（権威ある）URLです。検索エンジンはこれを「正本」として扱います。複数のURLで同じコンテンツが表示される場合に使用します。
- **代替URL**: 別のバリエーションにある同じコンテンツの別URLです。たとえば別のバージョンや言語です。重複として扱うのではなく、検索エンジンがバリエーションをまとめるのに役立ちます。

どちらのフィールドでも、別の GitBook ページを選択すること（推奨）も、外部URLを入力することもできます。

<Callout kind="info">
  バージョン管理されたドキュメントでは、古いページを最新の対応ページを正規とするように設定するのが一般的です（たとえば、 `1.0` → `2.0`）、そのうえで最新ページに古いバージョンを代替として列挙します。
</Callout>

#### セクション間でページを移動する

GitBook では現在、アプリ内で個別のページをセクション間で移動することはサポートされていません。ページのコンテンツを別のセクションへ移すには:

- **コピー＆ペースト** — ページのコンテンツを `Esc` キーで選択し、それをコピーして移動先に貼り付けます。一部のブロックは再設定が必要になる場合があり、コメントとページ履歴はコピーされず、画像は新しいセクションで再アップロードが必要です。
- **Git Sync を使用** — どちらのセクションもリポジトリと同期している場合、リポジトリ間でファイルをコピーし、移動先の `SUMMARY.md`にページタイトルを追加します。参照 [Git Sync](/ja/docs/docs-as-code/git-sync).

### ページカバー

ドキュメントの各ページにページカバーを設定します。 **ページカバー** <Image src="https://test-dai.imgix.net/org-4afef969-21f9-40f3-b5b8-b06c8b6cf68f/doc-22a3b060-9539-4176-97e4-49120e02f5d1/4e5d9e0bc5b806be-spaces-NkEGS7hzeqa35sMXQZ4X-uploads-I1Q5rfhHgy0toM2pUEH5-image.svg?rasterize-bypass=true" alt="The Page cover icon in GitBook" /> オプションをクリックすると、GitBook はすぐにデフォルトのカバーを追加します。理想的なカバー画像サイズは 1990 × 480 ピクセルです。カバーはこのアスペクト比に固定されるため、画面サイズが変わっても比率は維持されます。ここから次の操作ができます:

- **カバー画像を変更**

  1. ページカバーにカーソルを合わせて **カバーを変更**.
  2. をクリックします。画像を選択またはアップロードします。理想的なサイズは 1990x480 ピクセルです。
- **カバー画像の位置を調整**

  1. ページカバーにカーソルを合わせて **アクションメニュー** <Image src="https://test-dai.imgix.net/org-4afef969-21f9-40f3-b5b8-b06c8b6cf68f/doc-22a3b060-9539-4176-97e4-49120e02f5d1/4fa265378c13a520-spaces-NkEGS7hzeqa35sMXQZ4X-uploads-89MTSo5XRpPMVr1T0rxS-actions.svg?rasterize-bypass=true" alt="The Actions menu icon in GitBook" />.
  2. クリック **位置を調整**.
  3. を開きます。画像をドラッグして配置し、 **保存**.
- **カバー画像を削除**

  1. ページカバーにカーソルを合わせて **アクションメニュー** <Image src="https://test-dai.imgix.net/org-4afef969-21f9-40f3-b5b8-b06c8b6cf68f/doc-22a3b060-9539-4176-97e4-49120e02f5d1/4fa265378c13a520-spaces-NkEGS7hzeqa35sMXQZ4X-uploads-89MTSo5XRpPMVr1T0rxS-actions.svg?rasterize-bypass=true" alt="The Actions menu icon in GitBook" />.
  2. クリック **削除**.
- **フル幅とヒーロー幅**

  ページカバーのスタイルを変更して、画面全幅またはコンテンツ幅だけに広げることができます。

  1. ページカバーにカーソルを合わせて **アクションメニュー** <Image src="https://test-dai.imgix.net/org-4afef969-21f9-40f3-b5b8-b06c8b6cf68f/doc-22a3b060-9539-4176-97e4-49120e02f5d1/4fa265378c13a520-spaces-NkEGS7hzeqa35sMXQZ4X-uploads-89MTSo5XRpPMVr1T0rxS-actions.svg?rasterize-bypass=true" alt="The Actions menu icon in GitBook" />.
  2. お好みのオプションをクリックしてください。
