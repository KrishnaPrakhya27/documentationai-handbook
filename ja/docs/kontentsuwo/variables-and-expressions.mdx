変数を使うと、条件に応じて参照できる再利用可能なテキストを作成できます [式](/ja/docs/kontentsuwo/formatting/inline#expressions) 、 [アダプティブコンテンツの条件](/ja/docs/gong-kai/adaptive-content/adapting-your-content#working-with-the-condition-editor).

コンテンツ内で同じ名前、フレーズ、またはバージョン番号を何度も繰り返す場合は、 **変数** を作成して、それらのすべてを同期した正確な状態に保つのに役立てられます。更新が必要な場合や、複雑で টাইポが起こりやすい場合に便利です。

単一ページ、または単一セクションにスコープを限定した変数を作成できます。

### 新しい変数を作成

新しい変数を作成するには、 **ライブラリ** 編集中の開いているドキュメントの目次で [変更リクエスト](/ja/docs/gong-tong-zuo-ye/change-requests)。次に、 **変数**.

上部のトグルを使って、現在いるページにスコープを限定した変数と、現在のセクション内のすべてのページにスコープを限定した変数を表示・作成できます。

をクリックすると **変数を作成** するためのモーダルが開き、変数の名前と値を入力できます。

クリックして **変数を追加** して、変数を保存します。

<Callout kind="info">
  変数名は英字で始める必要があり、英字、数字、アンダースコアを含めることができます。
</Callout>

### コンテンツ内で変数を使用する

変数は、 [式](/ja/docs/kontentsuwo/formatting/inline#expressions) の中で参照して使用できます。これはインラインでコンテンツに挿入できます。式を挿入したら、ダブルクリックして式エディタを開きます。

<Callout kind="info">
  式は、ドキュメントのページ本文でのみ使用できます。ページタイトルやページのメタデータでは機能しません。
</Callout>

ページ下に定義した変数は、 `page.vars` オブジェクトから参照できます。同様に、セクション全体に定義した変数は、 `space.vars` オブジェクト。

<Callout kind="info">
  から参照できます。式では、セクションスコープの変数は `space.vars` の下にあり、— GitBook API ではセクションを `space` オブジェクトとして表します。
</Callout>

### 変数を更新する

変更リクエストの途中であれば、いつでも変数を更新できます。値を更新すると、それを参照しているすべての式ブロックで値が更新されます。変更された変数は、変更リクエストがマージされると、公開済みのサイトすべてに反映されます。
