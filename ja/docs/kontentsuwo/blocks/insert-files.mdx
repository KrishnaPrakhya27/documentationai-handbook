GitBook のセクションにファイルをアップロードし、閲覧やダウンロードのためにページへ追加できます。

画像や OpenAPI ファイルなど、一部のファイルは、何もクリックしなくてもページ上でそのまま表示して閲覧できます。PDF などのほかのファイルは、表示またはダウンロードするにはクリックする必要があります。

必要に応じて、ページに挿入したファイルの下にキャプションを追加して、さらに情報を加えることもできます。

### ファイルをアップロードする

アップロード済みのファイルは **ライブラリ** タブで管理できます。最上部の左側ナビゲーションでは、 **ライブラリ** タブは **ページ** の横にあります。

ファイルをアップロードするには、 **ファイルをドロップするか参照** セクションにドラッグ＆ドロップするか、選択してシステムのファイルダイアログを使い、アップロードしたいファイルを選択してください。

<Callout kind="alert">
  GitBook では、1 ファイルあたり最大 100MB までアップロードできます。
</Callout>

画像ブロックまたは OpenAPI ブロックを追加すると、ページにファイルを追加することもできます。これらのブロックのいずれかを作成すると、 **ライブラリ** タブが開くので、ファイルを選択するか、新しいファイルをアップロードできます。

<Callout kind="info">
  <strong>ヒント：</strong> ファイルシステムから画像を直接エディタにドラッグ＆ドロップすることも、コピーした画像をコンテンツに貼り付けることもできます。GitBook はそれらを自動的に **ライブラリ** タブに、そのセクション用として追加するため、後で表示・管理できます。
</Callout>

### ファイル名を変更する

ファイル名を変更するには、 **操作メニュー** <Image src="https://test-dai.imgix.net/org-4afef969-21f9-40f3-b5b8-b06c8b6cf68f/doc-22a3b060-9539-4176-97e4-49120e02f5d1/4fa265378c13a520-spaces-NkEGS7hzeqa35sMXQZ4X-uploads-89MTSo5XRpPMVr1T0rxS-actions.svg?rasterize-bypass=true" alt="The Actions menu icon in GitBook" /> そのファイルの **編集**。表示されたダイアログで、ファイルの新しい名前を入力してください。

### ファイルを削除する

ファイルを削除するには、 **操作メニュー** <Image src="https://test-dai.imgix.net/org-4afef969-21f9-40f3-b5b8-b06c8b6cf68f/doc-22a3b060-9539-4176-97e4-49120e02f5d1/4fa265378c13a520-spaces-NkEGS7hzeqa35sMXQZ4X-uploads-89MTSo5XRpPMVr1T0rxS-actions.svg?rasterize-bypass=true" alt="The Actions menu icon in GitBook" /> そのファイルの **削除**を開き、クリックします。ダイアログでファイルを削除してよいことを確認すると、ファイルは削除されます。

<Callout kind="alert">
  <strong>注：</strong> 削除したファイルを含むページは必ず更新してください。削除されたファイルを参照しているファイルブロックは、空のブロックとして表示されるか、 *画像を読み込めません* というエラーが表示されます。
</Callout>

### ファイルを置き換える

単に新しいバージョンに更新する必要があるファイルがある場合は、置き換えることができます。これにより、古いファイルが差し替えられ、新しいファイルがその場所に置かれます。以前に古いファイルを参照していたブロックは、その後新しいファイルを参照するようになります。

ファイルを置き換えるには、 **アクションメニュー** <Image src="https://test-dai.imgix.net/org-4afef969-21f9-40f3-b5b8-b06c8b6cf68f/doc-22a3b060-9539-4176-97e4-49120e02f5d1/4fa265378c13a520-spaces-NkEGS7hzeqa35sMXQZ4X-uploads-89MTSo5XRpPMVr1T0rxS-actions.svg?rasterize-bypass=true" alt="The Actions menu icon in GitBook" /> そのファイルの **置換**を開きます。表示されるファイル置換ダイアログで新しいファイルを選び、アップロードの完了を待ちます。ファイルはセクション内の表示箇所すべてで自動的に更新されます。

たとえば、大きなプロダクトのデザイン変更があり、複数のページに表示されている古い UI のスクリーンショットを更新する必要がある場合に便利です。元のファイルを置き換えることで、セクション内のすべての場所のスクリーンショットが更新され、時間と手間を節約できます。

<Callout kind="info">
  <strong>ヒント：</strong> 画像やファイルをアップロードしたら、画像ブロックまたはファイルブロックを作成して **ライブラリ** タブから選択することで、セクション内のどこでも参照できます。

  画像を含めたいときに毎回再アップロードするよりも、こちらの方法をおすすめします。後で画像を置き換えやすくなり、同じ名前のファイルが複数できるのを防げます。
</Callout>

### Markdownでの表記

```markdown
{% file src="https://example.com/example.pdf" %}
    これは例のファイルのキャプションです。
{% endfile %}
```
