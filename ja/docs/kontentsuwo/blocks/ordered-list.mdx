順序付きリスト（番号付きリストとも呼ばれます）を使うと、項目の優先順位を付けたり、手順のリストを作成したりできます。

### 順序付きリストの例

1. 項目 1

   1. ネストされた項目 1.1

      1. ネストされた項目 1.1.1
   2. ネストされた項目 1.2
2. 項目 2
3. 項目 3

<Callout kind="info">
  ネストされた項目を作成するには、 **Tab** インデントするには <strong>⇧ + Tab</strong> 逆インデントします。
</Callout>

### Markdownでの表記

```markdown
1. 項目 1
   1. ネストされた項目 1.1
      1. ネストされた項目 1.1.1
   2. ネストされた項目 1.2
2. 項目 2
3. 項目 3
```

### 順序付きリストにインライン画像を追加する

GitBook では、順序付きリスト内に画像を追加できます

順序付きリスト内に画像を追加したい場合は、挿入メニューを使って追加し、その後、画像の下の行に `3.` 次に `スペースキーを`入力すると、順序付きリストは続きます。

1. 項目 1
2. 項目 2
