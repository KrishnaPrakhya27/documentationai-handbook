順序なしリストは、必ずしも特定の順序で述べる必要のない一連の要点をまとめるのに最適です。実質的には箇条書きリストであり、必要に応じてネストをサポートしています。

GitBookでリストを入力しているときは、リストを終了して下に新しい空のブロックを開始するには `Enter` を2回押します。

### 順序なしリストの例

- 項目

  - ネストされた項目

    - 別のネストされた項目
  - さらに別のネストされた項目
- 別の項目
- さらに別の項目

<Callout kind="info">
  ネストされた項目を作成するには、 **Tab** インデントするには <strong>⇧ + Tab</strong> 逆インデントします。
</Callout>

### Markdownでの表記

```markdown
- 項目
   - ネストされた項目
      - 別のネストされた項目
   - さらに別のネストされた項目
- 別の項目
- さらに別の項目
```
