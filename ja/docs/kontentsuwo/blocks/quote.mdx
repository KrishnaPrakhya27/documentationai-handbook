引用は、他のソースから何かを含めたいときに便利です。

引用を開始するには、次を入力します `>` 続けて次を押します `スペースキーを` 空の段落内で、または次を使用します[ 挿入パレット](/ja/docs/kontentsuwo/blocks#inserting-a-new-content-block)。また、段落全体を選択して次を押すことで、段落ブロックを引用に変換することもできます `>`.

### 引用の例

> 「人は同じ川に二度足を踏み入れることはない。それは同じ川ではなく、彼らも同じ人ではないからだ。」— *ヘラクレイトス*

### Markdownでの表記

```markdown
> 「人は同じ川に二度足を踏み入れることはない。それは同じ川ではなく、彼らも同じ人ではないからだ。」— _ヘラクレイトス_
```
