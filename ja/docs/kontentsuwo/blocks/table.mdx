### 表ブロックのオプション

表ブロックの左側にある［オプション］メニューを開くと、表の外観の変更や表内データの管理を行うためのさまざまなオプションが表示されます。

- <strong>表／カード：</strong> データを表ブロックまたはカードブロックとして表示するよう選択できます。GitBookはこれら両方のブロックに同じデータを使用するため、希望する見た目やデザインに応じて切り替えられます。
- <strong>列を追加：</strong> 表の右側に新しい列を追加します。メニューで列の種類を選択するか、 **列を追加** をクリックしてテキスト列を追加します。
- <strong>行を挿入：</strong> 表の末尾に新しい行を追加します。
- <strong>ヘッダーを表示：</strong> 表の最上部にあるタイトル行を表示または非表示にします。
- <strong>ヘッダーを固定：</strong> 下の行をスクロールしている間も、表の最上行をページ上に表示したままにします。列タイトルを常に表示しておきたい大きな表で便利です。
- <strong>最初の列を固定：</strong> 右側の列を横方向にスクロールしている間も、表の左端の列を表示したままにします。ページ幅を超える幅広い表で、行ラベルや識別子を常に表示しておきたい場合に便利です。
- <strong>列のサイズをリセット：</strong> 列幅を変更していた場合、すべての列幅を再び同じにリセットします。
- <strong>表示する列：</strong> 表示する列と非表示にする列を選択します。表に非表示の列がある場合は、このメニューから再び表示できます。
- <strong>削除：</strong> 表ブロックとそのすべてのコンテンツを削除します。

### セルの結合

複数のセルをドラッグして選択するか、Shiftキーを押しながら矢印キーを押して選択します。セルを選択すると表示されるハンドルを使用して結合します。

結合できるのは **テキスト** と **数値** セルのみです。GitBookでは、サポートされていないフィールド、異なるフィールドタイプの混在、アンカーセル以外のコメント、およびカードビューでは結合できません。また、結合されたセルや結合されたセルを含む行の並べ替えもできません。

Git Syncを使用する場合、結合にはネイティブの `colspan` と `rowspan` を使用します。結合は位置に基づきます。アンカーセルと結合範囲は、表の現在の行順序と表示列の順序に従います。

バージョン1では、 `2x2` の選択範囲のような矩形結合はサポートしていません。セルを結合するときは、保持する値を選択してください。GitBookは他の値を消去します。結合を解除しても、消去された値は復元されません。

### 列タイプの変更

表示するデータに応じて、表の列に異なるデータタイプを設定できます。これにより、列内のすべてのセルに書式、装飾、または制限が追加されます。

- <strong>テキスト：</strong> 標準の書式設定に対応した標準テキスト列です。
- <strong>数値：</strong> 小数点以下の桁を含めるかどうかを選択できる数値列です。
- <strong>チェックボックス：</strong> 各行に、オンまたはオフにできるチェックボックスを表示します。
- <strong>選択：</strong> 次を開いて定義できるオプションのリストからデータを選択できます。 **列のオプション** メニューで **オプションを管理**を選択します。単一選択または複数選択にできます。
- <strong>ユーザー：</strong> 組織メンバーの名前とアバターを追加できます。単一選択または複数選択にできます。
- <strong>ファイル：</strong> セクション内のファイルを参照します。列内のセルにデータを入力する際、新しいファイルをアップロードできます。
- <strong>評価：</strong> 星による評価です。次を開いて最大評価を設定できます。 **列のオプション** メニューで **最大**.

次の **列のオプション** メニューを使用して列のタイプを変更します。列のタイプを変更すると、列データが削除または破損する可能性があるため、変更の確認を求めるメッセージが表示されます。

### 列のサイズ変更

列の端にカーソルを合わせてドラッグすると、サイズを変更できます。カーソルの上にピクセル数が表示されるため、列サイズを揃えるのに役立ちます。

GitBookは列サイズを全体幅に対する割合として保存するため、表全体の幅に基づいた相対的なサイズ設定が可能です。

### 表のスクロール

エディターのコンテナより幅が広い表は、横方向にスクロールできます。

### 列のオプション

列を並べ替えるには、ドラッグハンドルをクリックしてドラッグします <Image src="https://test-dai.imgix.net/org-4afef969-21f9-40f3-b5b8-b06c8b6cf68f/doc-22a3b060-9539-4176-97e4-49120e02f5d1/0a460c049ef3df1f-spaces-NkEGS7hzeqa35sMXQZ4X-uploads-PnnI41SqLSaKBNwT98fW-actions-horizontal.svg?rasterize-bypass=true" alt="The table drag handle icon in GitBook" /> 。これは移動したい列の上部にあります。

次をクリックして新しい列を追加できます。 **列を追加** 表の右端にカーソルを合わせると表示されるボタンです。

次の **列のオプション** メニューでは、自動サイズ設定のオン／オフの切り替え、右側への新しい列の追加、列の非表示、または列の削除も行えます。

### 行のオプション

行にカーソルを合わせて、 **行のオプション** <Image src="https://test-dai.imgix.net/org-4afef969-21f9-40f3-b5b8-b06c8b6cf68f/doc-22a3b060-9539-4176-97e4-49120e02f5d1/4fa265378c13a520-spaces-NkEGS7hzeqa35sMXQZ4X-uploads-89MTSo5XRpPMVr1T0rxS-actions.svg?rasterize-bypass=true" alt="The Row options menu icon in GitBook" /> その左側に表示されるボタンをクリックし、 **行のオプション** メニューを開きます。さまざまなオプションが表示されます。

- <strong>行を開く：</strong> 行のすべてのデータを表示するモーダルで、その行を開きます。ここでは、行タイプをすばやく変更したり、データを編集したり、非表示の列のデータを確認したりできます。
- <strong>上／下に挿入：</strong> 現在選択されている行の上または下に新しい行を追加します。
- <strong>列を追加：</strong> 表の右側に新しい列を追加します。
- <strong>行を削除：</strong> 表からその行のすべてのデータを完全に削除します。

### 表内の画像

表のセルをクリックすると、/キーを押して画像を挿入できます。表のヘッダー行には画像を追加できません。

### Markdownでの表現

```markdown
# 表

|   |   |   |
| - | - | - |
|   |   |   |
|   |   |   |
|   |   |   |
```

<Expandable title="GitBookでネストした表を作成できますか？">
  GitBookでは表をネストすることはできません。ドキュメントを容易に記述でき、確実にレンダリングでき、すべてのユーザーがアクセスできるようにするため、GitBookでは表をフラットに保っています。

  表が別の表のセル内に配置されると、編集、サイズ変更、移動、デバイス間での一貫した書式設定の維持が困難になります。

  ネストした表は、基礎となるドキュメント構造にも大きな複雑さをもたらし、クリーンなセマンティクスを損ない、Git Syncなどの機能で予測不能な動作につながることがよくあります。
</Expandable>
