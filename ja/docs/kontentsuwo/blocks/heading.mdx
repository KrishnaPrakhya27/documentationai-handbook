見出しはドキュメントに構造を与えるのに役立ちます。また、見出しにキーワードを使うと、検索エンジンがその構造を理解しやすくなり、検索結果でページの順位が上がる助けにもなります。

GitBook には 3 つの見出しレベルがあります。見出しレベル 1（H1）と 2（H2）は、 [ページのアウトライン](/ja/docs/rifarensu/gitbook-ui#page-outline).

### アンカーリンク

ページに見出しを追加すると、アンカーリンクが作成されます。すると、関連情報を示すために、これらの特定のセクションへ直接リンクできます。

#### アンカーへのリンク

公開コンテンツ、または読み取り専用モードの非公開コンテンツでは、タイトルにカーソルを合わせて、隣に表示される `#` をクリックすると、アンカーリンクを確認できます。これによりブラウザ上部の URL が更新されるので、コピーして他の場所で使用できます。

セクション内のページから特定のアンカーにリンクしたい場合は、 [相対リンク](/ja/docs/kontentsuwo/formatting/inline#relative-links)を使用できます。見出しを変更してもリンク切れを防ぐため、これは自動的に更新されます。

#### アンカーを編集

既定では、アンカーリンクはヘッダーのテキストと同じになります。その URL を GitBook の外でリンク先に使う予定がある場合、後でヘッダーを変更するとアンカーリンクが壊れます。その場合、リンクはアンカーの場所ではなく、ページの先頭へ訪問者を移動させます。

これを避けるには、ヘッダーの **オプションメニュー** <Image src="https://test-dai.imgix.net/org-4afef969-21f9-40f3-b5b8-b06c8b6cf68f/doc-22a3b060-9539-4176-97e4-49120e02f5d1/4c115a43418b42e3-spaces-NkEGS7hzeqa35sMXQZ4X-uploads-aS1QvPIBVYwhpFTGcPBN-options-menu.svg?rasterize-bypass=true" alt="The Options menu icon in GitBook" /> を開いてから **アンカーを編集**を選ぶことで、アンカーリンクを手動で設定できます。その後、使いたいアンカーリンクを入力できます。ヘッダー自体を変更しても、このアンカーはそのまま残ります。

### Markdownでの表記

GitBook は SEO に最適化されたページを生成します。つまり、GitBook のページタイトルは markdown では自動的に第 1 レベルの見出しとして表現されます:

```markdown
# ページタイトルです
```

つまり、もし [Git とコンテンツを同期すると](/ja/docs/docs-as-code/git-sync)、エディターで追加されたページ見出しは 1 レベル下として表現されます:

```markdown
## 私の見出し 1
### 私の見出し 2
#### 私の見出し 3
```

### 見出しの例

## 私の見出し 1

### 私の見出し 2

#### 私の見出し 3

<Callout kind="info">
  ページタイトルは、ページ本文内の見出しブロックとは別です。でページタイトルを非表示にすると **ページオプション**、H1、H2、H3 の見出しは引き続き表示されます。
</Callout>
