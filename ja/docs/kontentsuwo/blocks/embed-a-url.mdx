埋め込みURLを追加するには、埋め込みたいコンテンツのリンクを貼り付けて、 `Enter`.

### 動画

<Iframe src="https://www.youtube.com/embed/D_uLM5i0Z4c" title="Embedded content" />

<Callout kind="info">
  <strong>注：</strong> YouTube と Vimeo の埋め込みを自動再生・ループにするには、次を追加します `?autoplay=1&loop=1` を動画 URL の末尾に追加します。
</Callout>

#### 動画ファイル

アップロードした動画ファイル（MP4 など）はインラインでは再生されず、訪問者がクリックして開いたりダウンロードしたりできるリンクとして表示されます。ページ上で再生可能な動画を表示するには、YouTube や Google Drive などの公開アクセス可能なプラットフォームに動画をアップロードし、そのリンクを埋め込みブロックに貼り付けてください。非公開 URL はページに表示されません。

### よくある質問

<Expandable title="URL が機能しないのはなぜですか？">
  コンテンツは公開されている必要があります。Google ドキュメントの場合は、 *リンクを知っている全員* の共有設定を選択してください。

  GitBook は URL を次の方法で埋め込みます [Iframely](https://iframely.com/domains)。Iframely が提供元をサポートしていることを確認してから、 [Iframely で URL をテストしてください](https://iframely.com/try).

  GitBook は外部 HTML を埋め込めません `<iframe>` タグは、コンテンツ セキュリティ ポリシーのため使用できません。代わりに埋め込みブロックを使用してください。
</Expandable>
