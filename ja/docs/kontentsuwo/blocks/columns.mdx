カラムは、ドキュメントにさまざまなレイアウトを作成するのに最適な方法です。カラム内にはさまざまな種類のブロックを追加でき、必要なデザインに合わせて各側の幅を調整できます。

**ドキュメントと製品の間にシームレスな体験を作る**

ドキュメントを製品体験にそのまま組み込むことも、ユーザーに必要なものをより早く届けるパーソナライズされた体験を提供することもできます。

[詳細を見る](https://www.gitbook.com/#alpha-waitlist)
