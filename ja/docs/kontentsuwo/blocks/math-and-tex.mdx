数式をドキュメントに含めるには、mathTeX形式を使用できます。これは次の [KaTeX](https://katex.org/docs/supported.html) ライブラリです。

mathTeXも追加できます [インラインコンテンツとして](/ja/docs/kontentsuwo/formatting/inline#math-and-tex).

### Math & TeXブロックの例

$$
s = \\sqrt&#123;\\frac&#123;1&#125;&#123;N-1&#125; \\sum\_&#123;i=1&#125;^N (x\_i - \\overline&#123;x&#125;)^2&#125;
$$

### Markdownでの表記

$$f(x) = x * e^&#123;2 pi i \\xi x&#125;$$

```markdown
# 数式とTeXブロック

$$f(x) = x * e^{2 pi i \xi x}$$
```
