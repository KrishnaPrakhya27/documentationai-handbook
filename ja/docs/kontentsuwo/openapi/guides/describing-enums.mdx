APIオペレーションに enum が含まれている場合、次を追加できます `x-enumDescriptions` 各オプションについてより詳しい情報を提供するために。GitBook は、オペレーションの横にある表に enum の値とその説明を表示します。

```yaml title="openapi.yaml"
openapi: '3.0'
info: ...
components:
  schemas:
    project_status:
      type: string
      enum:
        - LIVE
        - PENDING
        - REJECTED
      x-enumDescriptions:
        LIVE: プロジェクトは公開中です。
        PENDING: プロジェクトは承認待ちです。
        REJECTED: プロジェクトは却下されました。
```
