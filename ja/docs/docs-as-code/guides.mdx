#### クイックガイド

<Expandable title="リポジトリにGit Syncを設定する">
  Git Syncは、GitHubまたはGitLabのリポジトリをGitBookと同期させます。

  このガイドでは、プロバイダーの選択、GitBookの認証、リポジトリの接続について説明します。
</Expandable>

<Expandable title="コーディングアシスタントをGitBook MCPに接続する">
  GitBook MCPにより、対応するコーディングアシスタントはGitBookのコンテンツにアクセスできます。

  このガイドでは、サーバーへの接続、アクセスの確認、ドキュメント作業の開始について説明します。
</Expandable>

<Expandable title="GitBook CLIでドキュメントのワークフローを実行する">
  GitBook CLIを使うと、コマンドラインからコンテンツを操作できます。

  このガイドでは、サインイン、コンテンツのクエリ、ドキュメントのワークフローの実行について説明します。
</Expandable>

<Expandable title="コーディングアシスタントにGitBookのスキルを与える">
  エージェントスキルは、コーディングアシスタントにGitBookの機能やコンテンツブロックに関するコンテキストを提供します。

  このガイドでは、スキルファイルの追加と、ドキュメント作業中の使用方法について説明します。
</Expandable>
