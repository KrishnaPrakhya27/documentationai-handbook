### 個人アカウント設定にアクセスする方法

組織に戻り、 **ホーム** に戻って **設定**、 **管理** サイドバー内。アカウント設定と組織設定は1つの画面を共有しており、次のようにグループ化されています **アカウント** 、 **組織** 左側のサイドバー内。個人設定は下にあります **アカウント**。 **アプリに戻る** コンテンツに戻るには。

<Expandable title="全般">
  **あなたのプロフィール**

  プロフィール画像と氏名を更新できます。

  **ログイン情報**

  GitBookアカウントへのログインに使用するメールアドレスとパスワードを更新できます。 <strong>注：</strong> アカウントを2021年10月9日以降に作成した場合、パスワードは設定されておらず、代わりにマジックリンクでサインインします。

  **サードパーティ製ログイン**

  Google および/または GitHub の認証情報を使って GitBook にログインすることもできます。

  **公開**

  個人ライブラリ内にある公開済みの各 GitBook セクションのドメインは、次の2つの部分で構成されます:

  1. `[something].gitbook.io` （これが GitBook のサブドメインです）
  2. `/[spaceURL]` （これはセクション自体の設定で指定されます）

  ここで GitBook サブドメインを更新できます。また、デフォルトコンテンツも更新できます。これは、訪問者が GitBook サブドメインに直接アクセスしたときに表示されるセクションです。

  **設定**

  好みのインターフェーステーマ — ダーク、ライト、またはシステム設定に合わせる — を選べます。 <strong>注：</strong> この設定は GitBook アプリにログインしているときの表示にのみ影響し、公開済みコンテンツには一切影響しません。

  **トラブルシューティング**

  必要に応じて、詳細ログの記録を有効にできます。これらの詳細ログは、問題をより効果的にトラブルシューティングするのに役立ちます。

  **アカウント操作**

  このセクションからサインアウトしたり、アカウントを削除したりできます。 <strong>注: アカウントを削除すると元に戻せません！</strong> 関連するデータもすべて削除されます。
</Expandable>

<Expandable title="通知">
  GitBook では次の2種類の [通知](/ja/docs/gong-tong-zuo-ye/notifications) — メール通知とアプリ内通知です。この設定画面では、さまざまなイベントが発生したときにどの種類の通知を受け取るかを選択できます。
</Expandable>

<Expandable title="組織">
  あなたの個人アカウントは複数の組織のメンバーになれるため、このタブは次へのショートカットと考えられます: [組織設定ページ](/ja/docs/akauntoto/organization-settings) 各組織ごとの設定ページです。このページから新しい組織を作成することもできます。
</Expandable>

<Expandable title="開発者ツール">
  このページでは、次のためのアクセストークンを管理・作成できます: [GitBook API](https://developer.gitbook.com/).
</Expandable>

### <strong>パスワードをリセットするにはどうすればよいですか？</strong>

なお、アカウントが2021年10月10日以降に作成された場合、パスワードはありません。マジックリンクをリクエストすることでログインできます:

1. 訪れて [https://app.gitbook.com](https://app.gitbook.com)
2. 登録した個人アカウントに関連付けられているメールアドレスを入力してください
3. クリックして **続行**
4. クリックして **リンクを送信** （迷惑メールフォルダも必ず確認してください）

もし *する* パスワードをリセットしたい場合:

1. 訪れて [https://app.gitbook.com](https://app.gitbook.com)
2. 以下を行ってください <strong>パスワードをお忘れですか？</strong> ページ下部のリンク
3. 登録した個人アカウントに関連付けられているメールアドレスを入力してください
4. クリックして **リンクを送信** （迷惑メールフォルダも必ず確認してください）

### サインインのトラブルシューティング

**管理者によってアカウントが無効化されました** — GitBook では、スパムや詐欺アカウントを防ぐため、疑わしい動作を示すアカウントを自動的にブロックします。誤ってブロックされたと思われる場合はサポートに連絡してください。ブロック解除の依頼は個別に審査されます。

**組織に参加するリンクが機能しません** — ある `auth/invalid-email` エラーは、組織に招待されたメールアドレスが、サインインしている GitBook アカウントのメールアドレスと一致しないことを意味します。招待した相手に、どのアドレスを使ったのか確認するか、別のアドレスで招待してもらってください。

**Error: auth/expired-action-code** — サインインまたは招待リンクの有効期限が切れています。新しいリンクを生成するか、送信者に新しいものを依頼してください。

**Error: auth/email-already-in-use** — サインインに使用している GitHub アカウントは、すでに別の GitBook アカウントにリンクされています。以下を参照してください: [重複している可能性のあるアカウント](/ja/docs/docs-as-code/git-sync/troubleshooting#potential-duplicated-accounts-when-signing-in) 識別してリンクを解除する手順について。
