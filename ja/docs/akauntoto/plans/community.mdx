コミュニティプランは、対象となる非営利組織、オープンソース組織、および教育関連グループは無料です。

<Callout kind="info">
  コミュニティプランには、SAML SSO を除く Ultimate プランのすべての機能が含まれます。
</Callout>

1. 非営利組織
2. オープンソース組織
3. 教育関連グループ

<Callout kind="info">
  もし他の人と共同作業する必要がなく、かつ/または [Git Sync](/ja/docs/docs-as-code/git-sync) GitHub と GitLab 経由で共同作業するために使うなら、Free プランで十分です！

  ドキュメントサイトも無料で公開したい場合は、機能が制限された Basic サイトか、 [Sponsored サイト](/ja/docs/akauntoto/plans/community/sponsored-site-plan) より多くの機能があり、小規模で関連性の高い広告を通じて資金提供を受けられます。詳細は [当社のオープンソースページ](https://www.gitbook.com/solutions/open-source) これらのプランの詳細について。
</Callout>

もし **必要があるなら** 他の人と共同作業する必要がある場合は、このまま読み進めてください。

## 審査基準

### すべての

<Callout kind="alert">
  申請をお断りする場合は、あらかじめご了承ください。詳細を共有するためのリソースがありません。可能であればある程度の背景はお伝えしますが、何が問題なのかは以下の基準をご確認ください。条件を調整して当社の基準を満たせるようになれば、いつでも再申請できます。
</Callout>

あなたの組織は <strong>〜ではない</strong>:

- 教会である、教会に所属している、または特定の宗教を推進するものであってはなりません。
- 学校、短期大学、大学などであってはなりません（ただし、学生グループ、研究室グループ、講義グループなどは可）。
- 政府機関、省庁、または公的機関であってはなりません（ただし、小規模な自治体の窓口は可）。
- 私設財団であってはなりません。
- 政治的な関連を持っていてはなりません。
- 特定の教義を広める。
- 活動の一環として宗教的立場を推進するものであってはなりません。
- ジェンダー（アイデンティティまたは表現）、人種、民族、政治的または宗教的見解、性的指向、その他いかなる理由に基づく差別も助長してはなりません。
- 暗号通貨またはゲーム関連のプロジェクトであってはなりません

### 非営利組織の条件

あなたの組織 <strong>〜である必要があります</strong>:

- 正式な非営利ステータスを持つ法人であること。
- 有効な公益法人資格（501(c) またはお住まいの国の同等資格）を示してください。

### オープンソースプロジェクトの条件

あなたのGitリポジトリ <strong>〜でなければなりません</strong>:

- 存在する *公開で* GitHub または GitLab 上に。
- 営利企業やベンチャー資金を受けた企業に関連していない、真にオープンソースのプロジェクトであること。
- 空のリポジトリであってはなりません。
- 独自の活動がないフォークであってはなりません。
- 〜を持っている `README.md` ソフトウェアの内容を明確に説明しているファイル。
- 〜を持っている `CONTRIBUTING.md` プロジェクトへの貢献方法を説明しているファイル。
- 〜を持っている `LICENSE` 〜を含むファイル [有効なOSSライセンス](https://choosealicense.com/).
- 〜を持っている `CODE_OF_CONDUCT.md` ファイル。
- 他の人が [貢献](https://docs.github.com/en/get-started/exploring-projects-on-github/finding-ways-to-contribute-to-open-source-on-github#finding-good-first-issues).

### 教育関連グループの条件

- その組織は <em>〜であってはなりません</em> 学校、短期大学、大学全体を代表するものであってはなりません。
- その組織は <em>〜することができます</em> 学校、短期大学、大学に関連する小規模なグループを代表することができます。
- あなたは <em>〜することができます</em> 少人数の学生グループ、または少人数の学生向けの授業を運営する教師であることができます。

<Callout kind="info">
  個人用メモや授業メモを保存したい個人の学生は、当社の **Free** プランをご利用ください。このプランでは、コミュニティプランに申し込む必要なく、無制限の非公開コンテンツを無料で利用でき、ドキュメントサイトを公開したい場合は、Basic サイトまたは Sponsored サイトを無料で選択できます。
</Callout>

## 申請方法

1. **サインアップまたはサインイン**<br />まずは [サインアップする](https://app.gitbook.com/join) まだお持ちでない場合は GitBook アカウントに、または [サインインする](https://app.gitbook.com) すでにお持ちの場合は。
2. **組織を選択する**<br />コミュニティプランを適用したい組織を決めてください。すでに作成済みの組織でも、新しく作成することもできます。<br /><em>（新しい組織を作成するには、上部付近の組織切り替えトグルをクリックし、</em> [*サイドバー*](/en/docs#sidebar)<em>、次に **組織を作成する**をクリックして、案内に従ってください。）</em>
3. **組織のURLを取得する**<br />〜で、 [サイドバー](/ja/docs/rifarensu/gitbook-ui#home)手順2で選択した組織名をクリックします。ブラウザのURLをコピーするかメモしてください。形式は次のようになります。 `app.gitbook.com/o/[string]/home`で、ここで `[string]` その組織を識別するために使われる、英数字の固有文字列です。
4. **当社のメッセンジャーからお問い合わせください** [**当社のウェブサイト**](https://www.gitbook.com/contact)<br />「サポートに連絡」を選択し、次に「料金について質問があります」、その次に「コミュニティプランに申し込みたい」を選んでください。別の方法として、必要情報を添えて [support@gitbook.com](mailto:support@gitbook.com) までメールでご連絡ください。

### メールで申請を送信する

申請する組織の種類に応じて、以下の該当する手順に従ってください。

<Tabs>
  <Tab title="非営利組織">
    - 非営利組織の目的を簡潔に説明してください。
    - 組織の公開ウェブサイトへのリンクを共有してください。
    - 非営利組織の有効な501(c)またはお住まいの国における同等の書類を添付してください。
    - 組織へのリンクを含めてください。このリンクの見つけ方は、上記セクションの手順3に記載されています。
  </Tab>

  <Tab title="オープンソースプロジェクト">
    - オープンソースプロジェクトの目的を簡潔に説明してください。
    - 公開Gitへのリンクを共有してください **リポジトリ** GitHub または GitLab 上に。
    - 組織へのリンクを含めてください。このリンクの見つけ方は、上記セクションの手順3に記載されています。
  </Tab>

  <Tab title="小規模な教育関連グループ">
    - グループの各メンバーに、学校のメールアドレスを使って各自のGitBookアカウントを作成してもらい、その組織に招待してください。これが完了してから申請を送信してください。
    - グループとその目的を簡潔に説明してください。
    - もしあれば、あなたの教育グループに関連する公開ウェブサイトへのリンクを共有してください。
    - 組織へのリンクを含めてください。このリンクの見つけ方は、上記セクションの手順3に記載されています。
  </Tab>
</Tabs>

ご質問がある場合は、遠慮なくサポートチームまでお問い合わせください。
