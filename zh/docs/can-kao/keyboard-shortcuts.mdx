快捷键提供轻松快捷的方式来浏览或编辑内容。

## 在已发布的文档中

| 说明 | Mac | Windows |
| --- | --- | --- |
| 打开 **提问或搜索** 面板 | <kbd>⌘</kbd>+<kbd>K</kbd> | <kbd>Ctrl</kbd>+<kbd>K</kbd> |
| 打开 **GitBook Assistant** 聊天窗口 | <kbd>⌘</kbd>+<kbd>I</kbd> | <kbd>Ctrl</kbd>+<kbd>I</kbd> |
| 关闭 **提问或搜索** 或 **GitBook Assistant** 面板 | <kbd>Esc</kbd> | <kbd>Esc</kbd> |

### 特定块快捷键

#### 段落和标题块

| 说明 | Mac | Windows |
| --- | --- | --- |
| 在段落中插入软换行 | <kbd>Shift</kbd> \+ <kbd>Enter 键</kbd> | <kbd>Shift</kbd> \+ <kbd>Enter 键</kbd> |
| 转换为段落 | <kbd>⌘</kbd> \+ <kbd>⌥</kbd> \+ <kbd>0</kbd> | <kbd>Ctrl</kbd> \+ <kbd>Alt</kbd> \+ <kbd>0</kbd> |
| 转换为一级标题 | <kbd>⌘</kbd> \+ <kbd>⌥</kbd> \+ <kbd>1</kbd> | <kbd>Ctrl</kbd> \+ <kbd>Alt</kbd> \+ <kbd>1</kbd> |
| 转换为二级标题 | <kbd>⌘</kbd> \+ <kbd>⌥</kbd> \+ <kbd>2</kbd> | <kbd>Ctrl</kbd> \+ <kbd>Alt</kbd> \+ <kbd>2</kbd> |
| 转换为三级标题 | <kbd>⌘</kbd> \+ <kbd>⌥</kbd> \+ <kbd>3</kbd> | <kbd>Ctrl</kbd> \+ <kbd>Alt</kbd> \+ <kbd>3</kbd> |

#### 表格块

| 说明 | Mac | Windows |
| --- | --- | --- |
| 在下方插入一行 | <kbd>⌥</kbd> \+ <kbd>Shift</kbd> \+ <kbd>Enter 键</kbd> | <kbd>Alt</kbd> \+ <kbd>Shift</kbd> \+ <kbd>Enter 键</kbd> |
| 在上方插入一行 | <kbd>⌥</kbd> \+ <kbd>Enter 键</kbd> | <kbd>Alt</kbd> \+ <kbd>Enter 键</kbd> |
| 移动到下一行 | <kbd>Enter 键</kbd> | <kbd>Enter 键</kbd> |
| 在文本单元格中插入新行 | <kbd>Shift</kbd> \+ <kbd>Enter 键</kbd> | <kbd>Shift</kbd> \+ <kbd>Enter 键</kbd> |
| 删除行 | <kbd>⌘</kbd> \+ <kbd>-</kbd> | <kbd>Ctrl</kbd> \+ <kbd>-</kbd> |

#### 列表和代码块

| 说明 | Mac | Windows |
| --- | --- | --- |
| 增加缩进级别 | <kbd>Tab</kbd> | <kbd>Tab</kbd> |
| 减少缩进级别 | <kbd>Shift</kbd> \+ <kbd>Tab</kbd> | <kbd>Shift</kbd> \+ <kbd>Tab</kbd> |
