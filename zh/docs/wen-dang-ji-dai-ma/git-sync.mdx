### 概述

Git Sync 让技术团队能够将 GitHub 或 GitLab 仓库与 GitBook 同步，并将一个 Markdown 文件仓库转换为美观、易用的文档。你可以直接在 GitBook 强大的编辑器中进行编辑，同时让内容与 GitHub 或 GitLab 上的代码库保持同步。

Git Sync 是双向同步的，因此你在 GitBook 编辑器中直接所做的更改会自动同步，GitHub 或 GitLab 上提交的任何变更也会自动同步。这让开发者可以直接从 GitHub 或 GitLab 提交，而技术写作者、教学设计师和产品经理可以直接在 GitBook 中编辑、讨论并反馈更改。
