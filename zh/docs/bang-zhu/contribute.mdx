感谢您花时间为 GitBook 的文档做贡献。每一项贡献都会由团队审阅。

这份文档使用 GitBook 发布，并通过 Git Sync 保持网站与以下内容同步更新： `public-docs` GitHub 上的仓库。任何经过审阅、批准并合并到该仓库中的更改都会自动部署。

#### 可贡献内容

- 更正——不准确的步骤、过时的截图、失效链接、拼写错误。
- 说明澄清——技术上正确但难以理解的部分。
- 缺失细节——页面未涵盖的边缘情况或错误消息。

如果是 GitBook 本身的问题而不是文档问题，请参阅“报告错误”。

#### 如何提交更改

1. 向……发起拉取请求 `public-docs` 仓库获取 GitBook 技能。
2. 描述您更改了什么以及原因。链接到您正在编辑的已发布页面。
3. 文档团队成员会对其进行审阅。一旦获得批准并合并，更改就会自动部署。
