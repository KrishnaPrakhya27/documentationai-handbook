GitBook 的编辑器允许你使用 Markdown 创建格式化内容。

Markdown 是一种流行的标记语法，以简洁著称。GitBook 支持它，作为一种便于键盘操作的方式来编写富文本和结构化文本。

<Callout kind="info">
  你可以通过访问以下内容来进一步了解 Markdown 本身： [CommonMark](https://commonmark.org/help/).
</Callout>

### 文本格式

GitBook 支持所有经典的内联 Markdown 格式：

| 格式 | Markdown 版本 | 结果 |
| --- | --- | --- |
| 加粗 | `**粗体**` | **粗体** |
| 斜体 | `_斜体_` | *斜体* |
| 删除线 | `~删除线~` | ~~删除线~~ |
| 行内代码 | `` `代码` `` | `代码` |

### 换行

按 `Enter 键` 以开始一个新段落。

按 `Shift` \+ `Enter 键` 在同一段落中插入软换行。

### 粘贴 Markdown

当直接将 Markdown 内容粘贴到编辑器中时，重要的是使用 **粘贴并匹配样式** 选项（通常 <kbd>Shift</kbd> \+ <kbd>Cmd</kbd> \+ <kbd>V</kbd> 在 Mac 上或 <kbd>Shift</kbd> \+ <kbd>Ctrl</kbd> \+ <kbd>V</kbd> 在 Windows 上）。

如果你使用标准的粘贴选项来粘贴从另一个编辑器或网页复制的内容，它可能会被插入为代码块而不是格式化文本。

### 标题

- 一级标题： `# 一级标题`
- 二级标题： `## 二级标题`
- 三级标题： `### 三级标题`

### 列表

GitBook 会在你输入时自动检测并创建有序列表和无序列表。

- 以一行开头，输入 `-` 或 `*` 以开始无序项目符号列表。
- 以一行开头，输入 `1.` 以开始编号列表。
- 以一行开头，输入 `- [ ]` 以开始任务列表。

编写列表时，按 `Tab` 进行缩进，并按 `Shift+Tab` 来减少缩进。

### 引用

以一行开头，输入 `>` 以创建块引用。如果你从开头到结尾选中整个段落，输入 `>` 会将内容包裹在块引用中。
