无序列表非常适合用于列出一系列不一定需要按特定顺序呈现的要点。它们本质上就是项目符号列表，并且支持按需嵌套。

在 GitBook 中输入列表时，你可以按 `Enter 键` 两次。

### 无序列表示例

- 项目

  - 嵌套项目

    - 另一个嵌套项目
  - 又一个嵌套项目
- 另一个项目
- 又一个项目

<Callout kind="info">
  要创建嵌套项目，你可以使用 **Tab** 进行缩进，并使用 <strong>⇧ + Tab</strong> 来减少缩进。
</Callout>

### Markdown 中的表示方式

```markdown
- 项目
   - 嵌套项目
      - 另一个嵌套项目
   - 又一个嵌套项目
- 另一个项目
- 又一个项目
```
