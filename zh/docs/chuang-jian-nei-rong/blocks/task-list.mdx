任务列表可让你创建一个带有复选框的项目列表，你可以勾选或取消勾选。

<Callout kind="info">
  <strong>注意：</strong> 你发布的网站的读者无法勾选或取消勾选这些框。你可以在创建内容时决定哪些框被勾选、哪些未勾选。
</Callout>

### 任务列表示例

- [ ] 这是一个尚未完成的任务

  - [ ] 这是一个已完成的子任务，使用以下方式缩进 `Tab`.
  - [ ] 这是一个尚未完成的子任务。
- [ ] 最后，一个项目，使用以下方式取消缩进 `Shift` \+ `选项卡`.

### Markdown 表示法

```markdown
- [ ] 这是一个尚未完成的任务
  - [x] 这是一个已完成的子任务，使用 `tab` 缩进
  - [ ] 这是一个尚未完成的子任务。
- [ ] 最后，一个项目，使用 `shift` + `tab` 取消缩进。
```
