当你想引用其他来源的内容时，引用很有用。

通过输入 `>` 然后按下 `空格键` 在空段落中，或者使用[ 插入面板](/zh/docs/chuang-jian-nei-rong/blocks#inserting-a-new-content-block)。你也可以通过高亮整个段落并按下将段落块转换为引用 `>`.

### 引用示例

> “从来没有人两次踏入同一条河流，因为那不是同一条河流，也不是同一个人。”—— *赫拉克利特*

### Markdown 中的表示方式

```markdown
> “从来没有人两次踏入同一条河流，因为那不是同一条河流，也不是同一个人。”——_赫拉克利特_
```
