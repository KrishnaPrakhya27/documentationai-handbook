你可以直接通过 GitBook 使用集成的 [Excalidraw](https://excalidraw.com/) 编辑器创建图画或草图，然后将其直接添加到你的 GitBook 页面中。

要创建图画，请按 `/` 在空白行上调出插入面板，然后选择 **绘图**。这将打开一个带有 Excalidraw 工具的弹出窗口——完成后只需关闭弹窗，你的图表就会显示在 GitBook 页面上。

GitBook 将图画作为区块中的特殊 SVG 文件存储。这些文件的扩展名为 `drawing.svg`.

### 使用 GitBook AI 绘图

在使用绘图块时，你可以通过指定提示词让 GitBook AI 生成插图。只需输入提示词并按 **生成**，或者选择一个建议的提示词开始。

一旦 GitBook AI 完成绘图，你可以双击打开完整的绘图面板，并按你的喜好进行编辑。

编辑图画时，点击 **使用 AI 生成** 按钮，再次调出 GitBook AI 的提示编辑器并生成新图画。

### Markdown 中的表示方式

