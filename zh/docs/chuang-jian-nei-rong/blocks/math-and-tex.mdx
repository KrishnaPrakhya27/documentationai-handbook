您可以使用 mathTeX 格式在文档中包含数学公式。我们通过 [KaTeX](https://katex.org/docs/supported.html) 库。

您也可以添加 mathTeX [作为行内内容](/zh/docs/chuang-jian-nei-rong/formatting/inline#math-and-tex).

### Math 与 TeX 块示例

$$
s = \\sqrt&#123;\\frac&#123;1&#125;&#123;N-1&#125; \\sum\_&#123;i=1&#125;^N (x\_i - \\overline&#123;x&#125;)^2&#125;
$$

### Markdown 中的表示方式

$$f(x) = x * e^&#123;2 pi i \\xi x&#125;$$

```markdown
# 数学与 TeX 块

$$f(x) = x * e^{2 pi i \\xi x}$$
```
