使用标签来分组相关内容、传达发布状态、标记过时内容，或做任何能帮助读者快速浏览文档的事情。

#### 为页面添加标签

打开页面，然后打开 **标签** 菜单——将鼠标悬停在页面标题上即可访问——并创建或添加标签。你可以拖动标签来更改它们在页面上显示的顺序。

1. 打开页面。
2. 将鼠标悬停在页面标题上并打开 **页面选项**.
3. 添加一个或多个标签。

拖动标签可更改它们在页面上的显示顺序。

#### 在页面上显示或隐藏标签

默认情况下，标签会显示在页面顶部。若要隐藏页面标签同时保留相关元数据：

- 打开 **标签** 菜单
- 关闭 **在页面上显示标签** 以仅将标签保留为元数据

1. 打开 **页面选项**.
2. 关闭 **在页面上显示标签**.

#### 在目录中显示一个标签

对于每个页面，你可以选择一个标签显示在目录中。若要选择显示哪个标签：

- 打开 **标签** 菜单
- 使用 **在目录中显示** 下拉菜单选择你的标签
- 你也可以点击某个标签并 **显示**, **移除** 或 **在目录中替换**.

1. 打开 **页面选项**.
2. 在 **标签**，从 **在目录中显示** 下拉菜单中选择你的标签。

#### 为更新块添加标签

每个更新块都可以有自己的标签。

1. 打开更新块。
2. 点击 **添加标签** 在日期下方。
3. 使用标签选择器添加、移除或重新排序标签。

#### 在库中管理标签

若要查看、创建和管理你空间中的标签，请打开 **资料库** 来自 [目录](/zh/docs/chuang-jian-nei-rong/content-structure/page#table-of-contents) 并选择 **标签**。你可以通过打开 **标签** 菜单并选择 **打开标签库**。<br /><br />你也可以在库中查看某个单独标签，方法是选择该标签并选择 **在库中显示**.

若要查看、创建和管理你部分中的标签：

1. 打开 **资料库** 从目录中。
2. 点击 **标签**.

每个标签都有：

- 一个标签名——读者看到的内容
- 一个 slug——稳定标识符
- 一个可选图标或表情符号

#### Markdown 中的标签

如果你使用 Git Sync，标签会出现在页面 frontmatter 中：

```yaml
---
description: "标签是可重复使用的标记，你可以将其添加到页面和更新块中——本页将告诉你如何创建、添加和管理标签"
tags:
  - 新闻
  - 实验
  - tag: beta
    primary: true
  - 专业版
---
```

标准标签使用字符串。使用 `primary: true` 在一个标签上将其设为页面的主标签——GitBook 可以在目录中显示该标签。
