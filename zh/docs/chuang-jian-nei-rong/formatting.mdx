要设置文本格式，只需选中所需的词语，然后从上下文菜单中选择一种格式——或者使用键盘快捷键，或通过 Markdown 语法对文本进行格式化。

<Callout kind="info">
  我们使用 Mac 键编写了这些快捷键。请使用 **Control** 代替 <strong>⌘（Command）</strong> 在 Windows 或 Linux 操作系统上。查看我们的键盘快捷键部分，可了解所有操作系统的全部快捷键。
</Callout>

#### 加粗

键盘快捷键： <kbd>⌘</kbd> \+ <kbd>B</kbd>

<Tabs>
  <Tab title="Markdown">
    ```markdown
    **加粗**
    ```
  </Tab>
</Tabs>

#### 斜体

键盘快捷键： <kbd>⌘</kbd> \+ <kbd>I</kbd>

<Tabs>
  <Tab title="Markdown">
    ```markdown
    _斜体_
    ```
  </Tab>
</Tabs>

#### 删除线

键盘快捷键： <kbd>⇧</kbd> \+ <kbd>⌘</kbd> \+ <kbd>S</kbd>

<Tabs>
  <Tab title="Markdown">
    ```markdown
    ~~删除线~~
    ```
  </Tab>
</Tabs>

#### 代码

键盘快捷键： <kbd>⌘</kbd> \+ <kbd>E</kbd>

<Tabs>
  <Tab title="Markdown">
    ```markdown
    `代码`
    ```
  </Tab>
</Tabs>

点击上下文菜单中的颜色图标，然后为文本或其背景选择一种颜色。

### 从右到左文本

GitBook 目前不支持从右到左的贡献。段落和标题会自动检测 RTL 文本并调整布局，但列表和其他内容块可能无法正确对齐，而且某些语言的字体质量可能会降低。
