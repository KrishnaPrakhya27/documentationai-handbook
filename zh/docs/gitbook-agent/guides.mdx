#### 快速指南

<Expandable title="如何使用 GitBook Agent 创建初稿？">
  GitBook Agent 可以将有范围限定的请求转化为草稿变更。

  本指南涵盖添加上下文、审阅草稿以及优化内容。
</Expandable>

<Expandable title="如何使用 GitBook Agent 审查变更请求？">
  GitBook Agent 可以在你合并前审查文档变更并识别问题。

  本指南涵盖请求审查、处理反馈以及批准变更。
</Expandable>

<Expandable title="如何自动查找并修复文档缺口？">
  GitBook Agent 可以识别过时或不完整的文档并准备修复。

  本指南涵盖运行改进、审查建议的变更以及发布更新。
</Expandable>

<Expandable title="如何使用 GitBook Agent 翻译文档？">
  GitBook Agent 可以翻译内容，并保持译文与源文档同步。

  本指南涵盖创建翻译、审阅本地化内容以及管理更新。
</Expandable>
