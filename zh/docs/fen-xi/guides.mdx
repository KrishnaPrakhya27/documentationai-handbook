#### 快速指南

<Expandable title="如何使用站点分析？">
  在你的站点分析仪表板中查看流量、反馈、搜索和 Ask AI 活动。

  本指南展示如何筛选数据并识别内容优化机会。
</Expandable>

<Expandable title="如何使用搜索和反馈数据？">
  搜索词和页面评分会突出显示需要关注的内容。

  本指南展示如何发现缺口并优先安排文档改进。
</Expandable>

<Expandable title="如何使用 Google Analytics 跟踪文档？">
  连接 Google Analytics，以衡量超出 GitBook 站点分析范围的流量。

  本指南涵盖集成、衡量 ID 和数据收集。
</Expandable>

<Expandable title="如何构建自定义分析报告？">
  使用 Events Aggregation API 在你自己的工具中分析文档行为。

  本指南涵盖事件数据、查询和仪表板报告。
</Expandable>
