站点分析会为你提供有关你已发布内容及其表现的信息。它分为不同部分—— **流量**, **页面与反馈**, **智能体和 LLM**, **搜索**, **询问 AI**, **链接**, **MCP**，以及 **OpenAPI**.

你可以在网站的 **概览** 页面中查看分析的顶层概览，位于 **常规** 下方，在站点侧边栏中，带有一个地球图标，可按位置显示过去一小时的访问量。

点击 **分析** 在站点页眉中打开该站点的站点分析。

<Callout kind="info">
  如果你连接了 **Google Analytics**，你的网站可能会显示 Cookie 提示。要将其移除，请打开 [**站点设置 → 分析 Cookie**](/zh/docs/guan-li-ni-de-zhan-dian/site-settings#analytics-cookie) 并禁用或移除该 **Google Analytics** 集成。
</Callout>

### 筛选与分组

你可以添加筛选器或对数据分组，以特定方式查看数据。例如，你可以查看某个特定站点章节中的搜索数据，或按国家/地区、设备、浏览器等筛选流量数据。

通过结合筛选与分组，你可以深入查看精确的分析数据，跟踪你关注的事件。

### 按自定义时间段查看

你可以使用时间筛选器 <Image src="https://test-dai.imgix.net/org-4afef969-21f9-40f3-b5b8-b06c8b6cf68f/doc-22a3b060-9539-4176-97e4-49120e02f5d1/5995e7af18e55747-spaces-NkEGS7hzeqa35sMXQZ4X-uploads-1g9fFv9V674Y7JGjHOGw-calendar.svg?rasterize-bypass=true" alt="" /> 在 **分析** 页面右侧，在过去 24 小时、7 天、30 天或 3 个月之间切换时间段。

若要查看自定义时间段内的数据，请点击 **自定义范围** 以在日历中选择自定义时间段。

### 数据类型

站点分析分为七个部分，每个部分都专注于一种特定的数据类型。

#### 流量

GitBook 会跟踪页面浏览量，帮助你了解内容的受欢迎程度和覆盖范围。每当用户访问你的文档站点上的某个页面时，就会计为一次页面浏览。

页面浏览量对于评估内容策略的有效性以及根据用户兴趣优化文档至关重要。它会拆分为不同的视图和画像，包括国家/地区、语言、浏览器等。

<Callout kind="success">
  在整个站点分析中，你会看到事件和访客指标。 **事件** 表示某一类别的总发生次数，而 **访客** 表示执行这些操作的唯一用户。

  在页面浏览的语境中，事件是页面浏览的总量，而访客是执行页面浏览的不同用户数量。
</Callout>

#### 页面与反馈

页面与反馈可让你从高层次了解用户如何评价你的内容。你会看到站点所有章节和变体的概览，并且在站点的“自定义”菜单中启用 [页面评分](/zh/docs/guan-li-ni-de-zhan-dian/site-settings#page-ratings-pro-and-enterprise-plans) 后，你可以看到每个页面的平均反馈评分。 **自定义** 菜单中启用

**筛选并分组反馈数据**

使用筛选器聚焦于评分和评论的子集。使用分组可在某个维度上比较这些数据。可用维度取决于你选择的报告。

你可以按以下方式筛选或分组页面与反馈数据：

- 内容：章节、变体和页面。
- 访客维度：国家/地区、语言、设备、浏览器、来源和已认证访客状态。
- 为自适应内容配置的访客声明，例如客户、套餐、角色或功能访问权限。

内容筛选可识别反馈来源。访客维度会添加与站点分析中其他位置相同的受众上下文。例如，可按国家/地区筛选某个页面的评分，或按设备或已认证访客状态对其反馈分组。

**按访客声明筛选**

“ **已认证访客** ”筛选器会显示 GitBook 在访客留下反馈时是否识别了该访客：

- **已认证**：访客通过登录或带着已签名的访客声明到达。
- **匿名**：访客在没有已签名身份标识的情况下到达。通过 URL 参数或公共访客 cookie 传递的声明未签名。
- **未知**：GitBook 在 2026 年 8 月开始跟踪访客认证之前记录了该事件。

“ **已认证** 以及 **匿名** 的值自 2026 年 8 月起才具有意义。更多详情请参见 [已认证访客常见问题](#what-does-authenticated-visitor-mean).

<Callout kind="info">
  若要隔离来自某个客户或细分群体的反馈，请按你通过自适应内容传递的声明进行筛选。例如，按客户、套餐、角色或功能访问声明筛选。这只会显示其事件中包含该声明值的访客反馈。

  声明筛选器只使用为你的网站配置的声明。它们不会从页面内容、章节或变体推断客户身份。请参见 [启用自适应内容](/zh/docs/fa-bu/adaptive-content/enabling-adaptive-content) 以配置访客声明。
</Callout>

**你可以了解什么**

页面与反馈筛选可帮助你将评分和评论转化为有针对性的更新。例如，你可以：

- 找出评分较低的页面或章节，然后查看其评论。
- 比较已认证访客和匿名访客的反馈，以发现特定受众的差距。
- 查看按客户声明变化的页面评分，然后改进该细分群体的内容。

如果你想在 GitBook 之外进一步使用或分析这些数据，请点击 **下载 CSV** 以下载一个 `.csv` 文件到你的设备。

你还可以查看对页面进行评分的访客留下的评论列表，以获得关于如何改进文档的可操作见解。

<Callout kind="info">
  <strong>为什么我看不到网站的任何反馈数据？</strong><br />我们仅显示已发布且启用了页面评分的网站数据。如果你的网站未发布或未启用页面评分，就不会看到任何分析数据。
</Callout>

跟踪来自 LLM、编码智能体和机器人 的流量。

此视图显示对 `llms.txt`, `llms-full.txt`以及 Markdown 页面 的请求。你还可以查看哪些智能体最常访问你的内容。

#### 失效的 URL

失效的 URL 会显示来自外部来源、导致“页面未找到”错误的所有入站链接。这些链接可能是拼写错误的 URL、没有重定向的过期链接，或垃圾链接。

如果某个失效链接指向文档其他位置存在的主题，或者你只是想将流量导向你的主文档，可以设置 [站点重定向](/zh/docs/fa-bu/site-redirects) 来将这些访客引导到正确的位置。

#### 搜索

你可以通过查看用户搜索文档时最常使用的关键词来衡量并改进你的文档。此视图可让你看到哪些关键词表现最好，以及哪些关键词还有改进空间。

这里的信息有助于指导你的内容架构，让文档的某些部分在无需搜索的情况下更容易被找到，或者根据访客正在搜索的内容为现有页面添加更多内容。

#### 询问 AI

“ [询问 AI](/zh/docs/chuang-jian-nei-rong/searching-your-content/gitbook-ai) 该部分可让你查看用户在使用 GitBook AI 时提出了什么。此洞察可帮助你识别常见问题，发现文档缺口，并改进内容以更好地满足用户需求。

你还可以看到用户如何评价 AI 对其问题给出的答案。通过查看这些查询及其评分，你可以优化文档结构，提高可发现性，并找出哪些地方需要补充更多文档信息。

#### 链接

GitBook 会跟踪链接，帮助你了解用户如何与文档中的外部资源交互。此功能可提供关于外部链接、其域名以及它们在文档中的位置（如页眉、页脚或侧边栏）的洞察。分析链接使用情况有助于你优化导航、提高内容可访问性，并根据用户参与度完善文档策略。

#### OpenAPI

“ [OpenAPI](/zh/docs/chuang-jian-nei-rong/openapi) GitBook 中的分析视图可洞察用户如何与你的 API 文档互动。

它会跟踪端点查看、参数搜索和请求探索等交互，帮助你了解 API 的哪些部分最常被访问，以及用户可能在哪些地方需要更多说明。这些洞察可帮助你完善文档、改善开发者体验，并确保 API 内容有效满足用户需求。

#### MCP

查看你的网站内容是如何通过 [MCP](/zh/docs/wei-du-zhe-ti-gong-de-ai/mcp-servers-for-published-docs) 集成被访问的。你可以查看一段时间内的 MCP 请求，并查看哪些机器人和智能体正在访问你的网站内容。

### 常见问题

<Expandable title="谁可以查看站点分析？">
  任何有权访问该站点的人都可以查看其分析——包括读者、审阅者和编辑者。创建者和管理员还可以访问站点设置和自定义。
</Expandable>

<Expandable title="为什么我的分析数据没有加载？">
  如果分析仪表板没有加载，通常是因为广告拦截器或隐私扩展程序阻止了分析脚本。请暂时禁用该扩展并重新加载页面，或者将 GitBook 及其使用的服务添加到该扩展的允许列表。
</Expandable>

<Expandable title="“页面未找到”是什么意思？">
  “页面未找到”表示访客尝试打开你网站上不存在的页面。该表仅统计对默认“页面未找到”页面的访问。若要查看哪些 URL 失效，请打开 **失效的 URL** 站点分析——在那里你可以看到每个失效链接有多少访客，以及 [创建重定向](/zh/docs/fa-bu/site-redirects) （如有需要）。
</Expandable>

<Expandable title="引荐来源数据中的“未设置”是什么意思？">
  “未设置”引荐来源表示直接流量——访客直接输入了你的 URL、使用了书签，或点击了不会传递引荐来源数据的电子邮件和应用中的链接。
</Expandable>

<Expandable title="“已认证访客”是什么意思？">
  “已认证访客”筛选器会显示 GitBook 在事件发生时是否能够识别访客。

  当访客通过访客认证登录或带着已签名的访客声明到达时，会计为“已认证”，例如在使用自适应内容的网站上。通过 URL 参数或公共访客 cookie 传递的个性化属性未签名，因此这些访客计为“匿名”。
</Expandable>

<Expandable title="对已认证访客而言，“未知”是什么意思？">
  “未知”表示 GitBook 在 2026 年 8 月开始跟踪访客认证之前记录了该事件。

  GitBook 会将这些较早的事件标记为“未知”，而不是推断其状态。因此，涵盖更早时期的报告会显示大多数流量为“未知”。“已认证”和“匿名”的区分自 2026 年 8 月起才具有意义。
</Expandable>
