你网站上的内容位于其 [部分](/zh/docs/chuang-jian-nei-rong/content-structure/space)。你可以添加一个或多个部分。GitBook 会发布每个部分并处理它们之间的导航。

## 内容类型

你网站中的内容可以作为两种不同内容类型之一，它们决定 GitBook 如何处理内容并向访客展示。

## 管理你的网站结构

通过管理网站结构，你也可以管理网站顶部导航栏。该导航栏可让访客打开部分、组和外部链接。

从以下位置打开结构编辑器： **网站结构**，在 **常规** 网站侧边栏中。你可以在这里看到网站的部分、版本和外部链接。

你的网站初始包含一个以网站名称命名的部分，以及一个包含你在网站设置过程中创建内容的单一版本。

<Image src="https://test-dai.imgix.net/org-4afef969-21f9-40f3-b5b8-b06c8b6cf68f/doc-22a3b060-9539-4176-97e4-49120e02f5d1/5c9107ce5273d70d-spaces-NkEGS7hzeqa35sMXQZ4X-uploads-D4oCABc0YRJAFzaaVBpn-structure-2x.png?fm=auto&auto=compress%2Cformat" alt="A GitBook screenshot showing a docs site's structure" caption="已发布文档网站的结构。" />

### 向你的文档网站添加部分

要添加一个 [部分](/zh/docs/guan-li-ni-de-zhan-dian/site-structure/site-sections)，点击 **添加部分** 表格下方的按钮，然后选择要添加的内容。新部分随后会添加到表格中，并作为你网站顶部的选项卡供访客使用。

要添加一个 [版本](/zh/docs/guan-li-ni-de-zhan-dian/site-structure/variants)，点击 **添加版本** 按钮，然后选择要添加的内容。新版本随后会添加到所选部分中的版本列表里，并会在你网站的版本下拉菜单中供访客使用。

当你添加内容——作为版本或部分——系统会根据其标题生成名称和 slug。

### 添加外部链接

外部链接会将网站外部的目标添加到其导航中。你可以将链接作为独立导航项添加，或将其放入与相关部分一起的分组中。

要添加外部链接：

1. 在网站侧边栏中，打开 **网站结构**.
2. 在添加菜单中，选择 **外部链接**.
3. 输入链接标签和目标 URL。
4. 选择将链接单独添加，还是添加到部分组中。
5. 点击 **保存**.

链接会以你选择的位置显示在已发布网站的导航中。

### 更改部分或版本

<Image src="https://test-dai.imgix.net/org-4afef969-21f9-40f3-b5b8-b06c8b6cf68f/doc-22a3b060-9539-4176-97e4-49120e02f5d1/0f39994a710c82d1-spaces-NkEGS7hzeqa35sMXQZ4X-uploads-oXvDCD0U1CNnP8pJHL1L-edit_variant-2x.png?fm=auto&auto=compress%2Cformat" alt="A GitBook screenshot showing how to edit a variant" caption="更新网站部分或版本。" />

你可以通过点击 **编辑** <Image src="https://test-dai.imgix.net/org-4afef969-21f9-40f3-b5b8-b06c8b6cf68f/doc-22a3b060-9539-4176-97e4-49120e02f5d1/ab76723fb229a5ad-spaces-NkEGS7hzeqa35sMXQZ4X-uploads-A3OfGjPkE5GnOQvN36jN-edit.svg?rasterize-bypass=true" alt="The Edit icon in GitBook" /> 按钮来更改你想编辑的项目所在行。此时会打开一个弹窗。编辑你想更改的字段，然后点击 **保存** 按钮保存。

<Callout kind="info">
  更改部分的 slug 会改变其规范 URL。GitBook 会自动将旧 URL 重定向到新 URL。你也可以 [手动创建重定向](/zh/docs/fa-bu/site-redirects).
</Callout>

<Callout kind="info">
  slug 在你的整个组织内是唯一的——每个路径只能用于一个网站，即使跨不同网站也是如此。如果你看到“path is already taken”错误，说明另一个网站已经在使用该 slug。请选择一个稍有变化但仍能表达内容含义的 slug。
</Callout>

要替换部分或版本，首先点击其 **编辑** <Image src="https://test-dai.imgix.net/org-4afef969-21f9-40f3-b5b8-b06c8b6cf68f/doc-22a3b060-9539-4176-97e4-49120e02f5d1/ab76723fb229a5ad-spaces-NkEGS7hzeqa35sMXQZ4X-uploads-A3OfGjPkE5GnOQvN36jN-edit.svg?rasterize-bypass=true" alt="The Edit icon in GitBook" /> 按钮将其删除，然后点击 **删除** 按钮（位于弹窗左下角）。项目删除后，点击 **添加部分** 或 **添加版本** 按钮重新添加它。

### 重新排序部分或版本

你的网站会按照它们在你的 **网站结构** 表格中出现的顺序显示部分和版本。你可以通过拖动 **拖动手柄** <Image src="https://test-dai.imgix.net/org-4afef969-21f9-40f3-b5b8-b06c8b6cf68f/doc-22a3b060-9539-4176-97e4-49120e02f5d1/4c115a43418b42e3-spaces-NkEGS7hzeqa35sMXQZ4X-uploads-aS1QvPIBVYwhpFTGcPBN-options-menu.svg?rasterize-bypass=true" alt="The Options menu icon in GitBook" /> 并将其向上或向下移动来重新排序。更改后的顺序会立即反映在你的网站上。

你也可以使用键盘选择并移动内容。按空格键选中一个部分或版本，然后使用方向键将其上下移动。再次按空格键确认新位置。

### 设置默认内容

如果你的网站中有多个部分，其中一个部分将被标记为 **默认**。该部分会在访客进入你的网站时显示，并通过你网站的根 URL 提供。其他部分各自都有一个附加到根 URL 的 slug。

如果一个部分中有多个版本，其中一个版本会被标记为默认。与部分一样，默认版本会在访客进入你的网站或访问某个部分时显示。其他版本各自都有一个附加到该部分 URL 的 slug。

要将某个部分或版本设为默认，请点击 **操作菜单** <Image src="https://test-dai.imgix.net/org-4afef969-21f9-40f3-b5b8-b06c8b6cf68f/doc-22a3b060-9539-4176-97e4-49120e02f5d1/4fa265378c13a520-spaces-NkEGS7hzeqa35sMXQZ4X-uploads-89MTSo5XRpPMVr1T0rxS-actions.svg?rasterize-bypass=true" alt="The Actions menu icon in GitBook" /> 所在行中的，然后点击 **设为默认**.

<Callout kind="info">
  将内容设为默认后会移除其 slug 字段，因为它将改为从部分根路径提供。GitBook 会将旧 slug 重定向到相应路径，以确保访客仍能看到你的内容。
</Callout>

### 从网站中移除内容

要从网站中移除某个部分或版本，请从以下位置打开结构编辑器： **网站结构**，在 **常规** 网站侧边栏中，并找到你想移除的内容。

打开 **操作菜单** <Image src="https://test-dai.imgix.net/org-4afef969-21f9-40f3-b5b8-b06c8b6cf68f/doc-22a3b060-9539-4176-97e4-49120e02f5d1/4fa265378c13a520-spaces-NkEGS7hzeqa35sMXQZ4X-uploads-89MTSo5XRpPMVr1T0rxS-actions.svg?rasterize-bypass=true" alt="The Actions menu icon in GitBook" /> 针对你想移除的内容，并选择 **移除**.

<Callout kind="success">
  从网站中移除内容会将其从已发布网站中删除，但 **不会删除内容本身** ——你仍可在 [全部内容](/zh/docs/chuang-jian-nei-rong/content-structure/all-content).
</Callout>

如果你完全删除某个部分的内容，网站——连同其设置和自定义——仍然可用。已删除内容会保留在 **废纸篓** 中七天，然后才会被永久移除。如果被删除的部分是你网站的默认部分，请检查默认设置是否仍然正确。
