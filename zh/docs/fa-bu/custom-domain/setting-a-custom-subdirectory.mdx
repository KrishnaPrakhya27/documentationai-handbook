使用自定义子目录，你可以让你的文档站点可在 `example.com/docs`。这不同于一个 [自定义域名](/zh/docs/fa-bu/custom-domain) 它可以让你的文档站点可通过以下地址访问 `docs.example.com`.

这样做的一个原因是让你的文档 URL 与你网站上的其他 URL 保持一致的格式。使用子目录也可能有利于 SEO。

要配置子目录，你需要先在网站后端进行设置，然后在 GitBook 站点设置中完成最后步骤。
