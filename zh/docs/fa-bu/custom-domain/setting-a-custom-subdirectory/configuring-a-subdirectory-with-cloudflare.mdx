<Steps>
  <Step title="配置你的 GitBook 站点" titleType="h3">
    在你的 GitBook 组织中，点击侧边栏中的文档站点名称，然后点击 **管理站点** 或者打开 **设置** 选项卡。打开 **域名和重定向** 部分，然后在“Subdirectory”下，点击 **设置子目录**.

    输入你希望托管文档的 URL。然后指定文档访问的子目录，例如 `tomatopy.pizza/docs`，并点击 **配置**.

    在 **附加配置**，你现在会看到一个代理 URL。你将在下一步配置 Cloudflare worker 时使用它。将其复制到剪贴板。
  </Step>

  <Step title="创建你的 Cloudflare worker" titleType="h3">
    登录你的 Cloudflare 账户并前往 **Workers 和 Pages**

    点击 **创建** 按钮。

    在“创建应用程序”界面中，点击 **你好，世界** “从模板开始”卡片中的按钮。

    给这个 worker 起一个更具描述性的名称，例如 `mydocs-subpath-proxy`。完成 worker 重命名后，点击 **部署**.
  </Step>

  <Step title="配置你的自定义域名" titleType="h3">
    你的 worker 会获得一个可使用的默认 URL。若要改为配置你的自定义域名（例如 `tomatopy.pizza`），点击 <strong>设置。</strong> 然后，在“域名与路由”部分中，点击 <strong>\+ 添加</strong>.

    在打开的“域名与路由”抽屉中，点击 **自定义域名**，然后在随后出现的文本框中输入你的自定义域名。当你指定自定义域名时， *不要* 包含子目录。例如， `tomatopy.pizza` 是正确的，而 `tomatopy.pizza/docs` 则不正确。
  </Step>

  <Step title="更新 worker 代码" titleType="h3">
    当 worker 完成部署后，点击 **编辑代码**，或者点击 **继续进入项目**，然后点击 **编辑代码** 右上角的按钮。

    在打开的代码编辑器中，将示例代码替换为以下代码片段：

    ```javascript
    export default {
      fetch(request) { 
        const SUBDIRECTORY = '/docs';
        const url = new URL(request.url);
        const target = "<INSERT YOUR PROXY URL FROM GITBOOK>" + url.pathname.slice(SUBDIRECTORY.length);
        const proxy = new URL(
          target.endsWith('/') ? target.slice(0, -1) : target 
        )
        proxy.search = url.search;
        return fetch(new Request(proxy, request));
      }
    };
    ```

    <Callout kind="info">
      务必使用你在第一步中从 GitBook 获取的代理 URL 更新第 5 行的 URL。
    </Callout>

    完成后，点击 **部署**。此过程可能需要几分钟。完成后，访问该 URL 时，你应该能看到你的文档站点！
  </Step>
</Steps>
