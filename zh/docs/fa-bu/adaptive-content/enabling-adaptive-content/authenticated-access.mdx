GitBook 提供开箱即用的解决方案来保护你的文档。Auth0、Okta、Azure AD 和 AWS Cognito 的集成可让你安装相应集成，在访问已发布的网站之前强制显示登录页面。

根据你使用的经过身份验证的访问方式，你仍然需要根据所使用的集成再配置一些内容，以便将正确的数据发送到 GitBook。

前往相关指南，查看有关如何使用经过身份验证的访问设置自适应内容的完整说明。

如果你使用自己的身份验证流程， [设置自定义后端](/zh/docs/fa-bu/site-audience/authenticated-access/setting-up-a-custom-backend) 涵盖登录、备用重定向和登出。
