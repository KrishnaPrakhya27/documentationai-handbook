要将你的文档置于登录界面之后进行保护，你需要先为你的网站启用经过身份验证的访问。

### 启用经过身份验证的访问

前往你的 [网站设置](/zh/docs/guan-li-ni-de-zhan-dian/site-settings)，并选择 **经过身份验证的访问** 从你的网站受众设置中选择。选定后，你会看到一些继续配置网站所需的选项。你还会看到一个生成的“**私钥**”，这是你在后续配置经过身份验证的访问时需要用到的。

### 选择一种身份验证方法

根据你的设置，我们提供了针对不同工具配置经过身份验证的访问的集成和指南。

前往相关指南，继续为你的网站设置经过身份验证的访问。
