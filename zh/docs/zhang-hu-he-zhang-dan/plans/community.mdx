社区方案对符合条件的非营利组织、开源组织和教育相关团体免费。

<Callout kind="info">
  社区方案包含 Ultimate 方案的所有功能，但不包括 SAML SSO。
</Callout>

1. 非营利组织
2. 开源组织
3. 教育相关团体

<Callout kind="info">
  如果你不需要与他人协作，和/或可以使用 [Git Sync](/zh/docs/wen-dang-ji-dai-ma/git-sync) 通过 GitHub 和 GitLab 协作，那么我们的免费方案应该就能满足你的需求！

  如果你还想免费发布一个文档站点，你可以选择功能受限的 Basic 站点，或者 [一个 Sponsored 站点](/zh/docs/zhang-hu-he-zhang-dan/plans/community/sponsored-site-plan) 它拥有更多功能，并通过小而相关的广告为你带来资助。请参阅 [我们的开源页面](https://www.gitbook.com/solutions/open-source) 了解这些方案的更多详情。
</Callout>

如果你将 **需要** 与他人协作，那么请继续阅读。

## 我们的标准

### 适用于所有

<Callout kind="alert">
  如果我们拒绝你的申请，先向你致歉。我们没有足够的资源来分享具体细节。如果可能，我们会尽量给你一些背景说明，但请查看下面的标准，找出可能的问题。请注意，如果你能够调整并满足我们的标准，你可以随时重新申请。
</Callout>

你的组织应当 **不应**:

- 是教会、与教会有关联，或宣传任何特定宗教。
- 是学校、学院、大学等。（但可以是学生团体、实验室小组、课程小组等。）
- 是政府办公室、部委或职能机构。（但可以是小型市政地方办公室。）
- 是私人基金会。
- 有政治关联。
- 宣扬教条。
- 将宗教立场作为其活动的一部分加以宣传。
- 基于性别（身份或表达）、种族、族裔、政治或宗教观点、性取向或任何其他原因，宣扬任何形式的歧视。
- 是加密货币或游戏相关项目

### 非营利组织的标准

你的组织 **需要**:

- 是一家拥有官方非营利身份的公司。
- 提供有效的慈善身份（501(c) 或你所在国家/地区的等效证明）。

### 开源项目的标准

你的 Git 仓库 **必须**:

- 存在 *公开地* 在 GitHub 或 GitLab 上。
- 是一个真正的开源项目，且不隶属于营利性公司或风险投资支持的公司。
- 不能是空仓库。
- 不能是一个没有自身活动的 fork。
- 有一个 `README.md` 文件，清楚说明该软件的用途。
- 有一个 `CONTRIBUTING.md` 文件，说明如何为该项目做贡献。
- 有一个 `LICENSE` 文件，包含 [有效的 OSS 许可证](https://choosealicense.com/).
- 有一个 `CODE_OF_CONDUCT.md` 文件。
- 让其他人更容易 [贡献](https://docs.github.com/en/get-started/exploring-projects-on-github/finding-ways-to-contribute-to-open-source-on-github#finding-good-first-issues).

### 教育相关团体的标准

- 该组织 *不得* 代表整个学校、学院或大学。
- 该组织 *可以* 代表与学校、学院或大学相关的小团体。
- 你 *可以* 是一个小型学生团体，或者是一位为一小组学生组织课程的教师。

<Callout kind="info">
  希望保留个人笔记和课程笔记的单个学生应使用我们的 **免费** 方案。该方案可免费提供无限私有内容，无需申请社区方案；如果你想发布文档站点，也可以免费选择 Basic 站点或 Sponsored 站点。
</Callout>

## 如何申请

1. **注册或登录**<br />首先 [注册](https://app.gitbook.com/join) 一个 GitBook 账户，如果你还没有的话，或者 [登录](https://app.gitbook.com) 如果你已经有账户。
2. **选择一个组织**<br />决定你希望将社区方案应用到哪个组织。这个组织可以是你已经创建的，也可以是你想新建的组织。<br /><em>（要创建新组织，请点击顶部附近的切换组织开关，</em> [*侧边栏*](/en/docs#sidebar)<em>，然后点击 **创建组织**，并按照提示操作。）</em>
3. **获取该组织的 URL**<br />在 [侧边栏](/zh/docs/can-kao/gitbook-ui#home)中，点击你在第 2 步选择的组织名称。复制或记下浏览器中的 URL。其格式为 `app.gitbook.com/o/[string]/home`，其中 `[string]` 将是用于标识该组织的唯一字母和数字字符串。
4. **通过我们网站上的即时通讯联系我们** [**我们的网站**](https://www.gitbook.com/contact)<br />选择“联系支持”，然后选择“我有一个关于定价的问题”，接着选择“我想申请社区方案”；或者也可以将所需信息通过电子邮件发送至 [support@gitbook.com](mailto:support@gitbook.com)

### 通过电子邮件提交申请

根据你申请的组织类型，请遵循下面列出的相关步骤。

<Tabs>
  <Tab title="非营利组织">
    - 简要描述你的非营利组织的宗旨。
    - 分享你组织公开网站的链接。
    - 附上你非营利组织有效的 501(c) 或你所在国家/地区的等效证明文件。
    - 包含你组织的链接。如何找到该链接已在上面部分的第 3 步中说明。
  </Tab>

  <Tab title="开源项目">
    - 简要描述你的开源项目的宗旨。
    - 分享你的公开 Git **仓库** 在 GitHub 或 GitLab 上。
    - 包含你组织的链接。如何找到该链接已在上面部分的第 3 步中说明。
  </Tab>

  <Tab title="小型教育相关团体">
    - 请让小组的每位成员使用他们的学校邮箱地址创建自己的 GitBook 账户，并将他们邀请到该组织中。请仅在完成此步骤后再提交申请。
    - 简要描述你们的团体及其宗旨。
    - 如果你们有公开网站，请分享与你的教育团体相关的公开网站链接。
    - 包含你组织的链接。如何找到该链接已在上面部分的第 3 步中说明。
  </Tab>
</Tabs>

如果你有任何问题，欢迎联系我们的支持团队。
