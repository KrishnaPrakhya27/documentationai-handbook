我们已 [更新了我们的定价模式](https://www.gitbook.com/blog/new-site-sections#new-pricing-for-new-users) 最近进行了更新，以适应我们为已发布站点推出的许多新功能。因此，您可能仍在使用我们的旧定价模式。

我们正在发布的一些新功能仅适用于我们更新后的定价方案。请 联系支持 如果您想了解更多并升级您的定价方案。

你可以 [查看我们当前的方案](/zh/docs/zhang-hu-he-zhang-dan/plans) 这里。

### 更新后的定价

我们对方案做了一些更改，以简化发布流程，并使功能与站点方案更好地匹配。以下是摘要：

- **Pro 方案**：不再包含每月平台费用。即使在免费方案中，您也可以无限制地购买和发布站点。
- **组织方案**：现在专注于协作。

AI 搜索适用于 Premium 和 Ultimate 站点方案。GitBook Assistant 和其他高级 AI 功能适用于 Ultimate 站点方案。

**功能现已与站点方案绑定**

| **功能** | **所需方案** |
| --- | --- |
| AI 搜索 | Premium 或 Ultimate |
| PDF 导出 | Premium 或 Ultimate |
| 搜索洞察 | Premium 或 Ultimate |
| 自定义域名 | Premium 或 Ultimate |
| 页面评分/反馈 | Premium 或 Ultimate |
| 高级自定义 | Premium 或 Ultimate |
| 非公开可见性 | Premium 或 Ultimate |
| 共享链接 | Premium 或 Ultimate |
| 已认证访问 | 终极版 |
| 站点重定向 | Premium 或 Ultimate |
| 站点分区 | 终极版 |
