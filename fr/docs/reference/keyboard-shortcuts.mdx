Les raccourcis clavier permettent des moyens simples et rapides de naviguer ou de modifier du contenu.

## Dans la documentation publiée

| Description | Mac | Windows |
| --- | --- | --- |
| Ouvrez le **Poser une question ou rechercher** panneau | <kbd>⌘</kbd>+<kbd>K</kbd> | <kbd>Ctrl</kbd>+<kbd>K</kbd> |
| Ouvrez le **Assistant GitBook** fenêtre de chat | <kbd>⌘</kbd>+<kbd>I</kbd> | <kbd>Ctrl</kbd>+<kbd>I</kbd> |
| Fermez le **Poser une question ou rechercher** ou **Assistant GitBook** panneaux | <kbd>Échap</kbd> | <kbd>Échap</kbd> |

## Dans l’application GitBook

| Description | Mac | Windows |
| --- | --- | --- |
| Copier | <kbd>⌘</kbd>+<kbd>C</kbd> | <kbd>Ctrl</kbd>+<kbd>C</kbd> |
| Coller | <kbd>⌘</kbd>+<kbd>V</kbd> | <kbd>Ctrl</kbd>+<kbd>V</kbd> |
| Coller en texte brut, sans mise en forme | <kbd>⌘</kbd>+<kbd>Maj</kbd>+<kbd>V</kbd> | <kbd>Ctrl</kbd>+<kbd>Maj</kbd>+<kbd>V</kbd> |
| Annuler | <kbd>⌘</kbd>+<kbd>Z</kbd> | <kbd>Ctrl</kbd>+<kbd>Z</kbd> |
| Rétablir | <kbd>⌘</kbd>+<kbd>Maj</kbd>+<kbd>Z</kbd> | <kbd>Ctrl</kbd>+<kbd>Maj</kbd>+<kbd>Z</kbd> |
| Dupliquer le(s) bloc(s) sélectionné(s) | <kbd>⌘</kbd> \+ <kbd>D</kbd> | <kbd>Ctrl</kbd> \+ <kbd>D</kbd> |
| Quitter le bloc de contenu (code, onglets, tableau, citation ...) | <kbd>⌘</kbd>+<kbd>Entrée</kbd> | <kbd>Ctrl</kbd>+<kbd>Entrée</kbd> |
| Ouvrir la palette d’insertion de blocs. | <kbd>/</kbd> | <kbd>/</kbd> |
| Ouvrir la palette de modification de blocs. | <kbd>⌘</kbd>+<kbd>/</kbd> | <kbd>Ctrl</kbd>+<kbd>/</kbd> |
| Basculer en gras | <kbd>⌘</kbd>+<kbd>B</kbd> | <kbd>Ctrl</kbd>+<kbd>B</kbd> |

| Basculer en code en ligne | <kbd>⌘</kbd>+<kbd>E</kbd> | <kbd>Ctrl</kbd>+<kbd>E</kbd> |
| Insérer ou basculer le lien | <kbd>⌘</kbd>+<kbd>K</kbd> (dans l’éditeur) | <kbd>Ctrl</kbd>+<kbd>K</kbd> (dans l’éditeur) |
| Sélectionner le bloc entier | <kbd>Échap</kbd> | <kbd>Échap</kbd> |
| Fermer une boîte de dialogue ou le panneau de recherche | <kbd>Échap</kbd> (navigation) | <kbd>Échap</kbd> (navigation) |
| Ouvrir le panneau Demander ou rechercher | <kbd>⌘</kbd>+<kbd>K</kbd> (en dehors de l’éditeur) | <kbd>Ctrl</kbd>+<kbd>K</kbd> (en dehors de l’éditeur) |

### Raccourcis spécifiques aux blocs

#### Blocs de paragraphe et de titre

| Description | Mac | Windows |
| --- | --- | --- |
| Insérer un saut de ligne souple dans un paragraphe | <kbd>Maj</kbd> \+ <kbd>Entrée</kbd> | <kbd>Maj</kbd> \+ <kbd>Entrée</kbd> |
| Convertir en paragraphe | <kbd>⌘</kbd> \+ <kbd>⌥</kbd> \+ <kbd>0</kbd> | <kbd>Ctrl</kbd> \+ <kbd>Alt</kbd> \+ <kbd>0</kbd> |
| Convertir en titre 1 | <kbd>⌘</kbd> \+ <kbd>⌥</kbd> \+ <kbd>1</kbd> | <kbd>Ctrl</kbd> \+ <kbd>Alt</kbd> \+ <kbd>1</kbd> |
| Convertir en titre 2 | <kbd>⌘</kbd> \+ <kbd>⌥</kbd> \+ <kbd>2</kbd> | <kbd>Ctrl</kbd> \+ <kbd>Alt</kbd> \+ <kbd>2</kbd> |
| Convertir en titre 3 | <kbd>⌘</kbd> \+ <kbd>⌥</kbd> \+ <kbd>3</kbd> | <kbd>Ctrl</kbd> \+ <kbd>Alt</kbd> \+ <kbd>3</kbd> |
