Ainsi que [créer du contenu](/fr/docs/agent-gitbook/write-and-edit-with-ai), GitBook Agent peut examiner vos demandes de modification pour repérer et corriger rapidement les erreurs, suggérer des améliorations, et plus encore.

L’Agent comprend le contexte du reste du contenu de votre documentation, et vous pouvez aussi ajouter [le guide de style de votre équipe](/fr/docs/agent-gitbook/overview#add-a-style-guide-and-custom-instructions) pour qu’il examine vos modifications tout en respectant le style de votre équipe.

### Examinez les demandes de modification avec GitBook Agent

Vous pouvez demander une revue à GitBook Agent dans n’importe quelle [demande de modification ouverte](/fr/docs/collaborer/change-requests/change-requests-screen) sur votre site.

Lorsque vous consultez une demande de modification ouverte, vous pouvez ajouter GitBook Agent en tant que relecteur. Une fois ajouté comme relecteur, GitBook Agent passera en revue vos modifications et vérifiera leur exactitude, leur clarté, et plus encore — dans le contexte de votre site publié et de votre guide de style.

Si vous souhaitez examiner les modifications vous-même, ouvrez la demande de modification dans l’éditeur et passez à l’onglet **Modifications** . En bas de l’éditeur, le navigateur de différences flottant vous permet de passer d’un bloc modifié à l’autre, de continuer vers la page suivante avec les différences, et de terminer la revue à partir de la dernière modification grâce aux actions de revue disponibles.

Il suggérera d’autres modifications si nécessaire — et si vous voulez que l’Agent les mette en œuvre, vous pouvez lui demander de le faire soit [via la fenêtre de discussion](/fr/docs/agent-gitbook/write-and-edit-with-ai#open-gitbook-agent-chat-window-in-any-change-request) ou en [le mentionnant dans un commentaire](/fr/docs/agent-gitbook/write-and-edit-with-ai#tag-gitbook-agent-in-a-comment).

Une fois que vous êtes satisfait de vos modifications, vous pouvez [fusionner la demande de modification](/fr/docs/collaborer/change-requests#merge) pour publier les changements en ligne.

### Mettez à jour les demandes de modification avec GitBook Agent

GitBook Agent travaille avec vous comme un autre membre de votre équipe. [Dans une demande de modification](/fr/docs/collaborer/change-requests/change-requests-in-a-space), vous pouvez [ouvrir la fenêtre de discussion de GitBook Agent](/fr/docs/agent-gitbook/write-and-edit-with-ai#open-gitbook-agent-chat-window-in-any-change-request) pour commencer à collaborer.

Vous pouvez lui demander de faire des choses comme :

- Rédiger du nouveau contenu ou développer des sections existantes
- Corriger les fautes de frappe et d’orthographe
- Réécrire des explications peu claires ou obsolètes
- Relire les pages pour en vérifier l’exactitude, la clarté et l’exhaustivité
- Générer ou mettre à jour des exemples de code
- Identifier les documents manquants ou les lacunes dans les workflows.

En savoir plus sur [rédiger avec GitBook Agent ici](/fr/docs/agent-gitbook/write-and-edit-with-ai).
