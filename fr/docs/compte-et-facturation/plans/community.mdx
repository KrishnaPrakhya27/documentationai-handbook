Le plan Communauté est gratuit pour les organisations à but non lucratif éligibles, les organisations open source et les groupes liés à l’éducation.

<Callout kind="info">
  Le plan Communauté inclut toutes les fonctionnalités du plan Ultimate, à l’exception du SSO SAML.
</Callout>

1. Organisations à but non lucratif
2. Organisations open source
3. Groupes liés à l’éducation

<Callout kind="info">
  Si vous n’aurez pas besoin de collaborer avec d’autres et/ou pouvez utiliser [Git Sync](/fr/docs/la-documentation-comme-code/git-sync) pour collaborer via GitHub et GitLab, alors vos besoins devraient être couverts par notre plan Gratuit !

  Si vous souhaitez aussi publier un site de documentation gratuitement, vous pouvez choisir soit un site Basic avec des fonctionnalités limitées, soit [un site Sponsorisé](/fr/docs/compte-et-facturation/plans/community/sponsored-site-plan) qui offre davantage de fonctionnalités et vous rapporte un financement grâce à de petites publicités pertinentes. Voir [notre page open source](https://www.gitbook.com/solutions/open-source) pour plus de détails sur ces offres.
</Callout>

Si vous **devez** collaborer avec d’autres, alors veuillez continuer à lire.

## Nos critères

### Pour tous

<Callout kind="alert">
  Nous vous présentons nos excuses par avance si nous rejetons votre candidature. Nous n’avons pas les ressources nécessaires pour partager des détails. Nous ferons de notre mieux pour vous donner un peu de contexte si possible, mais veuillez consulter nos critères ci-dessous afin de déterminer ce qui pourrait poser problème. Veuillez noter que vous pouvez refaire une demande à tout moment si vous êtes en mesure de vous adapter et de satisfaire à nos critères.
</Callout>

Votre organisation devrait **ne pas**:

- être une église, y être affiliée ou promouvoir une religion spécifique.
- être une école, un collège, une université, etc. (mais cela peut être un groupe d’étudiants, un groupe de laboratoire, un groupe de cours, etc.).
- être un bureau gouvernemental, un ministère ou une fonction (mais peut être un petit bureau municipal local).
- être une fondation privée.
- avoir des affiliations politiques.
- promouvoir un dogme.
- promouvoir une position religieuse dans le cadre de son activité.
- promouvoir toute forme de discrimination, fondée sur le genre (identité ou expression), la race, l’ethnicité, l’opinion politique ou religieuse, l’orientation sexuelle ou tout autre critère.
- être un projet lié à la cryptomonnaie ou au jeu vidéo

### Critères pour les organisations à but non lucratif

Votre organisation **doit**:

- être une entreprise ayant un statut officiel d’organisation à but non lucratif.
- présenter un statut caritatif valide (501(c) ou équivalent pour votre pays).

### Critères pour les projets open source

Votre dépôt Git **doit**:

- exister *publiquement* sur GitHub ou GitLab.
- Être un véritable projet open source qui n’est pas associé à une entreprise à but lucratif ou financée par des investisseurs.
- Ne pas être un dépôt vide.
- Ne pas être un fork sans activité propre.
- Avoir un `README.md` qui explique clairement de quoi parle le logiciel.
- Avoir un `CONTRIBUTING.md` qui explique comment contribuer au projet.
- Avoir un `LICENSE` fichier avec [une licence OSS valide](https://choosealicense.com/).
- Avoir un `CODE_OF_CONDUCT.md` fichier.
- Rendez la contribution facile pour les autres [contribuer](https://docs.github.com/en/get-started/exploring-projects-on-github/finding-ways-to-contribute-to-open-source-on-github#finding-good-first-issues).

### Critères pour les groupes liés à l’éducation

- L’organisation *ne doit pas* représenter une école, un collège ou une université dans son ensemble.
- L’organisation *peut* représenter un petit groupe lié à une école, un collège ou une université.
- Vous pouvez *peut* être un petit groupe d’étudiants ou un enseignant organisant un cours pour un petit groupe d’étudiants.

<Callout kind="info">
  Les étudiants individuels qui souhaitent conserver leurs notes personnelles et de cours doivent utiliser notre **plan Gratuit** Ce plan offre du contenu privé illimité sans frais, sans avoir besoin de demander le plan Communauté, et si vous souhaitez publier des sites de documentation, vous pouvez choisir gratuitement un site Basic ou Sponsorisé.
</Callout>

## Comment postuler

1. **Créer un compte ou se connecter**<br />Commencez par [créer un compte](https://app.gitbook.com/join) pour un compte GitBook si vous n’en avez pas encore un, ou [vous connecter](https://app.gitbook.com) si c’est le cas.
2. **Choisissez une organisation**<br />Décidez à quelle organisation vous souhaitez appliquer le plan Communauté. Il peut s’agir d’une organisation que vous avez déjà créée, ou vous pouvez vouloir en créer une nouvelle.<br /><em>(Pour créer une nouvelle organisation, cliquez sur le bouton bascule de changement d’organisation près du haut de la</em> [*barre latérale*](/en/docs#sidebar)<em>, puis cliquez sur **créer une organisation**, et suivez les instructions.)</em>
3. **Obtenez l’URL de l’organisation**<br />Dans la [barre latérale](/fr/docs/reference/gitbook-ui#home), cliquez sur le nom de l’organisation que vous avez choisie à l’étape 2. Copiez ou notez l’URL dans votre navigateur. Elle sera au format `app.gitbook.com/o/[string]/home`, où `[string]` sera une chaîne unique de lettres et de chiffres utilisée pour identifier cette organisation.
4. **Contactez-nous via notre messagerie sur** [**notre site web**](https://www.gitbook.com/contact)<br />Sélectionnez « Contacter le support », puis « J’ai une question sur les tarifs », puis « Je souhaite postuler au plan Communauté », ou envoyez-nous alternativement un e-mail avec les informations requises à [support@gitbook.com](mailto:support@gitbook.com)

### Soumettre votre demande par e-mail

Selon le type d’organisation pour lequel vous postulez, veuillez suivre les étapes pertinentes listées ci-dessous.

<Tabs>
  <Tab title="Organisations à but non lucratif">
    - Décrivez brièvement la mission de votre organisation à but non lucratif.
    - Partagez un lien vers le site web public de votre organisation.
    - Joignez la documentation valide 501(c) de votre organisation à but non lucratif ou l’équivalent pour votre pays.
    - Incluez le lien vers votre organisation. La façon de trouver ce lien est décrite à l’étape 3 de la section ci-dessus.
  </Tab>

  <Tab title="Projets open source">
    - Décrivez brièvement la mission de votre projet open source.
    - Partagez un lien vers votre dépôt Git **public** sur GitHub ou GitLab.
    - Incluez le lien vers votre organisation. La façon de trouver ce lien est décrite à l’étape 3 de la section ci-dessus.
  </Tab>

  <Tab title="Petits groupes liés à l’éducation">
    - Demandez à chaque membre du groupe de créer son propre compte GitBook en utilisant son adresse e-mail scolaire, et invitez-le à l’organisation. Veuillez envoyer votre demande uniquement une fois cette étape effectuée.
    - Décrivez brièvement votre groupe et sa mission.
    - Partagez un lien vers un site web public associé à votre groupe éducatif, si vous en avez un.
    - Incluez le lien vers votre organisation. La façon de trouver ce lien est décrite à l’étape 3 de la section ci-dessus.
  </Tab>
</Tabs>

Si vous avez des questions, n’hésitez pas à contacter notre équipe d’assistance.
