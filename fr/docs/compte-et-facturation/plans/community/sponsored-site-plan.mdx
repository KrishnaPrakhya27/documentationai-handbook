  Ce plan de site est uniquement disponible pour les utilisateurs de notre [plan communautaire](/fr/docs/compte-et-facturation/plans/community).
</Callout>

Le plan de site sponsorisé vous permet d’accéder gratuitement à toutes les meilleures fonctionnalités de site de documentation de GitBook, tout en affichant une petite publicité pertinente dans le coin de votre site de documentation. Chaque vue génère des revenus pour vous, transformant votre documentation en source de revenus.

### Demander le plan de site sponsorisé

Le plan de site sponsorisé est conçu spécifiquement pour **les projets open source**. Veuillez noter que nous n’acceptons pas les projets de cryptomonnaie, de web3 ou liés à ceux-ci pour ce plan.

Consultez les étapes ci-dessous pour apprendre à publier votre premier site sponsorisé.

<Steps>
  <Step title="Créer et publier un site sponsorisé">
    Commencez par créer un nouveau site depuis l’assistant de création de site et en configurant votre site avec du contenu. Par défaut, tout site créé sur le plan communautaire sera éligible au plan de site sponsorisé.
  </Step>

  <Step title="Soumettre votre site pour examen publicitaire">
    Votre site doit être [publié **publiquement**](/fr/docs/publier/publish-a-docs-site/public-publishing) pendant **sept jours** avant de pouvoir le soumettre pour examen.

    Rendez-vous dans les paramètres de votre site, puis faites défiler jusqu’à la **section Annonces et sponsoring** . À partir de là, examinez la checklist des annonces pour vous assurer que votre site répond à toutes les exigences avant de le soumettre.
  </Step>

  <Step title="Attendre l’examen">
    Après avoir soumis votre candidature, voici à quoi vous pouvez vous attendre :

    - <strong>Processus d’examen :</strong> Votre site sera examiné, et le délai d’examen estimé est de **jusqu’à sept jours**. Veuillez noter que ce délai peut varier en fonction des retards de traitement.
    - <strong>Mise à jour finale du statut :</strong> Après l’examen, nous mettrons à jour le statut de votre site. Votre site sera soit marqué comme **approuvé** ou **refusé**, selon le résultat de l’examen. S’il est approuvé, des annonces seront ajoutées à votre site et vous pourrez commencer à gagner de l’argent !
    - Si **refusé**, vous aurez l’occasion de mettre à jour votre site et de le soumettre à nouveau pour approbation.
  </Step>
</Steps>

### Comment ça fonctionne

Une fois votre site en ligne, voici comment fonctionne le plan de site sponsorisé :

- <strong>Potentiel de gains :</strong> Chaque fois que quelqu’un consulte votre documentation, une petite publicité pertinente sera affichée dans le coin inférieur de chaque page. Vous gagnez de l’argent à chaque vue, que vous pouvez utiliser pour soutenir les efforts de développement en cours.
- <strong>Publicité éthique :</strong> Chez GitBook, nous privilégions la publicité éthique. Les annonces affichées sur votre site ne suivront jamais vos utilisateurs ni ne les cibleront à nouveau, garantissant une expérience respectueuse pour votre audience.
- <strong>Visibilité du contenu :</strong> Votre contenu reste au centre de l’attention. Une seule petite annonce apparaîtra sur chaque page, afin que votre documentation reste toujours au premier plan.

### FAQ

<Expandable title="Pourquoi mon site a-t-il été refusé ?">
  Votre site peut être refusé pour le plan de site sponsorisé pour plusieurs raisons. Les raisons courantes incluent, sans s’y limiter :

  - Votre projet n’est pas un projet open source ou à but non lucratif.
  - Votre projet est un projet de cryptomonnaie.
  - Le site n’est pas publié en anglais car c’est sa **principale** langue.
  - Le site ne contient pas de contenu de qualité.
  - Le site n’atteint pas un nombre minimum de pages vues par mois.
</Expandable>

<Expandable title="Combien d’argent est-ce que je gagne par vue ?">
  Le CPM (coût pour 1 000) fluctue, ce qui signifie qu’il n’y a pas de montant fixe en $ par vue.

  Une fois votre site approuvé, vous aurez accès à votre tableau de bord publicitaire, ce qui vous donnera davantage d’informations sur les performances de votre site au fil du temps.
</Expandable>

<Expandable title="Que se passe-t-il si je ne soumets pas mon site pour examen ?">
  Le plan de site sponsorisé vous permet d’utiliser les fonctionnalités ultimes du site pour préparer votre site avant de le soumettre à l’examen.

  Tout site non soumis à l’examen après 1 mois reviendra automatiquement à un plan gratuit, et toutes les fonctionnalités ultimes du site utilisées seront désactivées, y compris des éléments comme les domaines personnalisés, les personnalisations, et plus encore.
</Expandable>

<Expandable title="Que se passe-t-il si je décide de revenir à un plan de site gratuit ?">
  Le plan de site sponsorisé inclut des fonctionnalités qui ne sont pas disponibles pour les sites du plan gratuit. Revenir à un plan gratuit rétrogradera effectivement votre plan de site, ce qui signifie que vous pourriez perdre l’accès à certaines fonctionnalités.
</Expandable>
