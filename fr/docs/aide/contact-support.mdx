Il existe deux façons de contacter l’équipe d’assistance de GitBook :

- Envoyez une demande d’assistance depuis l’application GitBook. Cliquez sur le **point d’interrogation** icône dans la barre latérale, cliquez sur **Contactez-nous**puis cliquez sur **Envoyez-nous un message**.
- E-mail [support@gitbook.com](mailto:support@gitbook.com) directement.

Avant de signaler un problème, consultez [la page d’état de GitBook](https://www.gitbookstatus.com/) pour voir s’il y a des interruptions affectant l’application ou les services tiers dont elle dépend. Pour les problèmes que vous pouvez peut-être résoudre vous-même, consultez Résoudre les problèmes de l’application GitBook.

#### Ce qu’il faut inclure

Incluez tous les détails pertinents afin que l’équipe puisse vous aider aussi efficacement que possible :

- Si votre demande concerne un contenu spécifique, incluez-y un lien.
- Décrivez les étapes que vous suivez, ce qui se passe lorsque vous les effectuez, et ce que vous vous attendez à voir se produire à la place.
- Si vous recevez un message d’erreur, indiquez-le dans son intégralité.
- Des captures d’écran — ou une courte vidéo montrant les étapes que vous suivez — sont extrêmement utiles.

Pour les problèmes liés à l’application, l’équipe peut demander une capture réseau. Voir Signaler un bug.

#### Quand vous recevrez une réponse

GitBook s’efforce de répondre à chaque message dans un délai d’un jour ouvré. En période de forte activité, cela peut ne pas être possible, mais l’équipe vous répond toujours dès qu’elle le peut. L’assistance n’est pas en temps réel — vous serez averti lorsqu’il y aura une réponse.

L’équipe d’assistance travaille du lundi au vendredi, de 9 h à 17 h GMT (+/- 3 heures).
