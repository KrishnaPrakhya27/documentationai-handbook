Les groupes de sections vous permettent d’organiser des sections associées au sein de votre site, ce qui facilite la navigation des visiteurs dans la structure de votre site.

Les groupes de sections sont différents de [Pages](/fr/docs/creer-du-contenu/content-structure/page). Les groupes de pages organisent les pages dans une section. Les groupes de sections organisent les sections dans la navigation du site. Les deux sont appelés groupes, mais vous configurez leurs icônes indépendamment.

### Créer un groupe

1. Dans votre site, cliquez sur <strong>Ajouter…</strong>.
2. Cliquez sur **Nouveau groupe**.
3. Choisissez un titre et une icône qui représentent le groupe.

Les nouveaux groupes commencent comme **des brouillons**: ils ne sont pas visibles sur votre site publié tant que vous ne les publiez pas.

### Ajouter des sections à un groupe

1. Ouvrez le **éditeur de structure**.
2. Faites glisser la section dans le groupe ou hors du groupe.

Ou créez une nouvelle section directement dans un groupe.

### Publier un groupe

1. Ouvrez le **menu d'actions** <Image src="https://test-dai.imgix.net/org-4afef969-21f9-40f3-b5b8-b06c8b6cf68f/doc-22a3b060-9539-4176-97e4-49120e02f5d1/4fa265378c13a520-spaces-NkEGS7hzeqa35sMXQZ4X-uploads-89MTSo5XRpPMVr1T0rxS-actions.svg?rasterize-bypass=true" alt="The Actions menu icon in GitBook" />.
2. Cliquez sur **Publier**.

Ou publiez plusieurs brouillons à la fois depuis l’éditeur de structure.

Pour prévisualiser l’apparence des groupes en brouillon sur votre site, basculez l’aperçu du site entre **En direct** et **En direct + Brouillons**.

### Renommer un groupe

1. Cliquez sur l’ **menu d'actions** icône <Image src="https://test-dai.imgix.net/org-4afef969-21f9-40f3-b5b8-b06c8b6cf68f/doc-22a3b060-9539-4176-97e4-49120e02f5d1/4fa265378c13a520-spaces-NkEGS7hzeqa35sMXQZ4X-uploads-89MTSo5XRpPMVr1T0rxS-actions.svg?rasterize-bypass=true" alt="The Actions menu icon in GitBook" /> à côté du groupe.
2. Cliquez sur **Renommer**.
3. Modifiez le titre ou l’icône du groupe.

### Supprimer un groupe

1. Ouvrez le **menu d'actions** <Image src="https://test-dai.imgix.net/org-4afef969-21f9-40f3-b5b8-b06c8b6cf68f/doc-22a3b060-9539-4176-97e4-49120e02f5d1/4fa265378c13a520-spaces-NkEGS7hzeqa35sMXQZ4X-uploads-89MTSo5XRpPMVr1T0rxS-actions.svg?rasterize-bypass=true" alt="The Actions menu icon in GitBook" />.
2. Cliquez sur **Supprimer**.
