Pour mettre en forme votre texte, il vous suffit de sélectionner les mots souhaités et de choisir l’un des formats dans le menu contextuel — ou de mettre en forme votre texte à l’aide d’un raccourci clavier ou via la syntaxe Markdown.

<Callout kind="info">
  Nous avons écrit ces raccourcis en utilisant les touches Mac. Utilisez **Contrôle** à la place de <strong>⌘ (Commande)</strong> sur les systèmes d’exploitation Windows ou Linux. Consultez notre section des raccourcis clavier pour voir tous les raccourcis pour tous les systèmes d’exploitation.
</Callout>

#### Gras

Raccourci clavier : <kbd>⌘</kbd> \+ <kbd>B</kbd>

<Tabs>
  <Tab title="Markdown">
    ```markdown
    **Gras**
    ```
  </Tab>
</Tabs>

#### Italique

Raccourci clavier : <kbd>⌘</kbd> \+ <kbd>I</kbd>

<Tabs>
  <Tab title="Markdown">
    ```markdown
    _Italique_
    ```
  </Tab>
</Tabs>

#### Barré

Raccourci clavier : <kbd>⇧</kbd> \+ <kbd>⌘</kbd> \+ <kbd>S</kbd>

<Tabs>
  <Tab title="Markdown">
    ```markdown
    ~~Barré~~
    ```
  </Tab>
</Tabs>

#### Code

Raccourci clavier : <kbd>⌘</kbd> \+ <kbd>E</kbd>

<Tabs>
  <Tab title="Markdown">

  </Tab>
</Tabs>

#### Lien

Raccourci clavier : <kbd>⌘</kbd> \+ <kbd>K</kbd>

Lorsque vous ajoutez un lien à du texte sur votre page, il vous sera demandé de fournir le lien. Vous pouvez ajouter n’importe quelle URL, mais si vous créez un lien vers une autre page ou une autre section de votre site, nous vous recommandons d’utiliser un lien relatif.

Il s’agit d’un [lien vers une page externe](https://www.gitbook.com).

Il s’agit d’un [lien vers une autre page de cette section](/fr/docs/creer-du-contenu/blocks).

Il s’agit d’un [lien vers une section de cette page](#code).

Il s’agit d’un [lien qui démarre un e-mail vers une adresse spécifique](mailto:support@gitbook.com).

### Texte de droite à gauche

GitBook ne prend actuellement pas en charge les contributions de droite à gauche. Les paragraphes et les titres détectent automatiquement le texte RTL et adaptent leur mise en page, mais les listes et autres blocs de contenu peuvent ne pas s’aligner correctement, et la qualité de la police peut être réduite pour certaines langues.
