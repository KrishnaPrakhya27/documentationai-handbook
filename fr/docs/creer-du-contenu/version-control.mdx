Vous pouvez suivre toutes les modifications apportées à votre contenu en utilisant le **Historique des versions** panneau latéral.

<a id="see-the-activity-of-a-specific-draft"></a>

### Historique des versions

Dans l’historique des versions d’une section, vous pouvez voir une liste de toutes les actions qui ont modifié le contenu qu’elle contient. Celles-ci incluent :

- Lorsqu’une personne a effectué des modifications en direct de la section.
- Lorsqu’une personne a fusionné une demande de modification.
- Lorsqu’une personne a effectué une opération Git Sync.

### Afficher les versions historiques du contenu

Pour afficher les versions passées de votre contenu et voir les modifications apportées, cliquez sur le **Historique des versions** <Image src="https://test-dai.imgix.net/org-4afef969-21f9-40f3-b5b8-b06c8b6cf68f/doc-22a3b060-9539-4176-97e4-49120e02f5d1/3954e3d9e39aa47e-spaces-NkEGS7hzeqa35sMXQZ4X-uploads-VEyYlyeOFMIwGJkpdIWh-history.svg?rasterize-bypass=true" alt="The Version history icon in GitBook" /> bouton dans l’en-tête de la section, ou ouvrez le **menu Actions** <Image src="https://test-dai.imgix.net/org-4afef969-21f9-40f3-b5b8-b06c8b6cf68f/doc-22a3b060-9539-4176-97e4-49120e02f5d1/0a460c049ef3df1f-spaces-NkEGS7hzeqa35sMXQZ4X-uploads-PnnI41SqLSaKBNwT98fW-actions-horizontal.svg?rasterize-bypass=true" alt="The Actions menu icon in GitBook" /> à côté du titre de la section ou de la demande de modification, puis cliquez sur **Historique des versions**.

Cliquez sur n’importe quel élément de la liste pour voir à quoi ressemblait votre contenu au moment où cette modification a été effectuée. Cela ressemble beaucoup à la manière dont vous consultez les demandes de modification.

### Afficher les modifications

Lorsque vous consultez une ancienne version de votre contenu, vous pouvez choisir de mettre en évidence les différences entre l’ancien contenu et le contenu actuel, comme dans l’affichage des différences d’une demande de modification.

Pour l’activer ou la désactiver, utilisez le **Afficher les modifications** interrupteur en bas du **Historique des versions** panneau latéral.

Lorsque l’option Afficher les modifications est activée, le contenu qui a changé sera mis en évidence par une icône à gauche de son bloc de contenu.

### Consultation des versions publiées antérieures

Si vous examinez l’historique des versions d’une section publiée, vous pouvez également afficher des aperçus de l’apparence des versions précédentes dans le contexte publié (c’est-à-dire ce que verrait l’utilisateur final).

Vous pouvez procéder ainsi :

<Steps>
  <Step title="Step">
    Dans le panneau latéral de l’historique des versions, sélectionnez la révision
  </Step>

  <Step title="Step">
    Copiez l’ID à la fin de l’URL
  </Step>

  <Step title="Step">
    Ajoutez-le à la fin de l’URL de vos docs publiés sous la forme `/~/revisions/<id>`
  </Step>
</Steps>

### Revenir à une version précédente

Le retour en arrière vous permet de restaurer le contenu d’une section tel qu’il était à un moment précédent. C’est utile si vous avez accidentellement apporté une modification incompatible ou supprimé du contenu et que vous devez revenir rapidement à une version précédente de la section.

Pour revenir à une version précédente de votre section, survolez la version dans le panneau latéral, puis cliquez sur le **bouton Actions** <Image src="https://test-dai.imgix.net/org-4afef969-21f9-40f3-b5b8-b06c8b6cf68f/doc-22a3b060-9539-4176-97e4-49120e02f5d1/4fa265378c13a520-spaces-NkEGS7hzeqa35sMXQZ4X-uploads-89MTSo5XRpPMVr1T0rxS-actions.svg?rasterize-bypass=true" alt="The Actions menu icon in GitBook" /> puis cliquez sur **Revenir en arrière**.
