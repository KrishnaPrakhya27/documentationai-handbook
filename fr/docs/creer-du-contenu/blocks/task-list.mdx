Les listes de tâches vous permettent de créer une liste d’éléments avec des cases à cocher que vous pouvez cocher ou décocher.

<Callout kind="info">
  <strong>Remarque :</strong> Les lecteurs de votre site publié ne peuvent pas cocher ou décocher ces cases. Vous pouvez décider quelles cases sont cochées et décochées lorsque vous créez le contenu.
</Callout>

### Exemple d’une liste de tâches

- [ ] Voici une tâche qui n’a pas été effectuée

  - [ ] Voici une sous-tâche qui a été effectuée, mise en retrait à l’aide de `Tabulation`.
  - [ ] Voici une sous-tâche qui n’a pas été effectuée.
- [ ] Enfin, un élément, sans retrait à l’aide de `Maj` \+ `Tabulation`.

### Représentation en markdown

```markdown
- [ ] Voici une tâche qui n’a pas été effectuée
  - [x] Voici une sous-tâche qui a été effectuée, mise en retrait à l’aide de `tab`
  - [ ] Voici une sous-tâche qui n’a pas été effectuée.
- [ ] Enfin, un élément, sans retrait à l’aide de `Maj` + `Tabulation`.
```
