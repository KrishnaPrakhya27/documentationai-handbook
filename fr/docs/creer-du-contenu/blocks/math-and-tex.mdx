Vous pouvez utiliser le format mathTeX pour inclure des formules mathématiques dans votre documentation. Nous proposons cela via la [KaTeX](https://katex.org/docs/supported.html) bibliothèque.

Vous pouvez également ajouter mathTeX [comme contenu en ligne](/fr/docs/creer-du-contenu/formatting/inline#math-and-tex).

### Exemple de bloc Math & TeX

$$
s = \\sqrt&#123;\\frac&#123;1&#125;&#123;N-1&#125; \\sum\_&#123;i=1&#125;^N (x\_i - \\overline&#123;x&#125;)^2&#125;
$$

### Représentation en Markdown

$$f(x) = x * e^&#123;2 pi i \\xi x&#125;$$

```markdown
# Bloc Math et TeX

$$f(x) = x * e^{2 pi i \xi x}$$
```
