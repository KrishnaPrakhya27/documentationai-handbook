Les listes non ordonnées sont idéales pour présenter une série de points qui n’ont pas nécessairement besoin d’être énoncés dans un ordre particulier. Ce sont en pratique des listes à puces, avec prise en charge de l’imbrication selon les besoins.

Lorsque vous saisissez une liste dans GitBook, vous pouvez quitter la liste et commencer un nouveau bloc vide en dessous en appuyant sur `Entrée` deux fois.

### Exemple de liste non ordonnée

- Élément

  - Élément imbriqué

    - Un autre élément imbriqué
  - Encore un autre élément imbriqué
- Un autre élément
- Encore un autre élément

<Callout kind="info">
  Pour créer des éléments imbriqués, vous pouvez utiliser **Tab** pour ajouter un retrait et <strong>⇧ + Tab</strong> pour diminuer le retrait.
</Callout>

### Représentation en Markdown

```markdown
- Élément
   - Élément imbriqué
      - Un autre élément imbriqué
   - Encore un autre élément imbriqué
- Un autre élément
- Encore un autre élément
```
