Vous pouvez téléverser des fichiers dans votre section GitBook et les ajouter à votre page pour que les utilisateurs puissent les consulter ou les télécharger.

Vous pouvez afficher directement sur la page certains fichiers, comme des images et des fichiers OpenAPI, pour que les utilisateurs puissent les voir sans cliquer sur quoi que ce soit. Pour d’autres, comme les PDF, les utilisateurs devront cliquer pour les consulter ou les télécharger.

Vous pouvez également ajouter facultativement une légende sous n’importe quel fichier que vous insérez dans votre page afin d’ajouter plus d’informations si nécessaire.

### Téléverser un fichier

Vous pouvez gérer les fichiers téléversés dans l’ **Bibliothèque** onglet de la section de votre site. L’ **Bibliothèque** onglet se trouve à côté de **Pages** en haut de la navigation de gauche.

Pour téléverser un fichier, faites-le glisser et déposez-le dans la **Déposez votre fichier ou parcourez** section, ou sélectionnez-le et utilisez la boîte de dialogue de fichiers de votre système pour choisir le fichier que vous souhaitez téléverser.

<Callout kind="alert">
  GitBook vous permet de téléverser des fichiers jusqu’à 100 Mo par fichier.
</Callout>

Vous pouvez également ajouter des fichiers à une page lorsque vous ajoutez un bloc d’image ou un bloc OpenAPI. Lorsque vous créez l’un de ces blocs, l’ **Bibliothèque** onglet s’ouvre, afin que vous puissiez soit sélectionner un fichier, soit en téléverser un nouveau.

<Callout kind="info">
  <strong>Astuce :</strong> Vous pouvez aussi faire glisser et déposer des images depuis votre système de fichiers directement dans l’éditeur — ou coller une image copiée dans votre contenu. GitBook les ajoutera automatiquement à l’ **Bibliothèque** onglet de la section correspondante, afin que vous puissiez les consulter et les gérer plus tard.
</Callout>

### Renommer un fichier

Pour renommer un fichier, ouvrez le **menu Actions** <Image src="https://test-dai.imgix.net/org-4afef969-21f9-40f3-b5b8-b06c8b6cf68f/doc-22a3b060-9539-4176-97e4-49120e02f5d1/4fa265378c13a520-spaces-NkEGS7hzeqa35sMXQZ4X-uploads-89MTSo5XRpPMVr1T0rxS-actions.svg?rasterize-bypass=true" alt="The Actions menu icon in GitBook" /> du fichier et cliquez sur **Modifier**. Dans la boîte de dialogue, saisissez le nouveau nom de votre fichier.

### Supprimer un fichier

Pour supprimer un fichier, ouvrez le **menu Actions** <Image src="https://test-dai.imgix.net/org-4afef969-21f9-40f3-b5b8-b06c8b6cf68f/doc-22a3b060-9539-4176-97e4-49120e02f5d1/4fa265378c13a520-spaces-NkEGS7hzeqa35sMXQZ4X-uploads-89MTSo5XRpPMVr1T0rxS-actions.svg?rasterize-bypass=true" alt="The Actions menu icon in GitBook" /> du fichier et cliquez sur **Supprimer**. Après avoir confirmé dans la boîte de dialogue que vous êtes sûr de vouloir supprimer le fichier, celui-ci sera supprimé.

<Callout kind="alert">
  <strong>Remarque :</strong> Assurez-vous de mettre à jour toutes les pages qui incluaient votre fichier supprimé ! Les blocs de fichier qui font référence à un fichier supprimé afficheront un bloc vide, ou *Impossible de charger l’image* erreur.
</Callout>

### Remplacer un fichier

Si vous avez un fichier qui doit simplement être mis à jour vers une nouvelle version, vous pouvez le remplacer. Cela remplacera l’ancien fichier par le nouveau. Tous les blocs qui faisaient auparavant référence à l’ancien fichier feront alors référence au nouveau fichier.

Pour remplacer un fichier, ouvrez le **menu Actions** <Image src="https://test-dai.imgix.net/org-4afef969-21f9-40f3-b5b8-b06c8b6cf68f/doc-22a3b060-9539-4176-97e4-49120e02f5d1/4fa265378c13a520-spaces-NkEGS7hzeqa35sMXQZ4X-uploads-89MTSo5XRpPMVr1T0rxS-actions.svg?rasterize-bypass=true" alt="The Actions menu icon in GitBook" /> du fichier et cliquez sur **Remplacer**. Dans la boîte de dialogue de remplacement de fichier qui apparaît, choisissez le nouveau fichier et attendez que l’indicateur de téléversement se termine. Votre fichier est automatiquement mis à jour partout où il apparaissait dans votre section.

Cela peut être utile si, par exemple, votre produit a fait l’objet d’une refonte majeure et que vous devez mettre à jour des captures d’écran d’interface obsolètes qui apparaissent sur plusieurs pages. Le remplacement du fichier d’origine mettrait à jour la capture d’écran partout dans votre section, ce qui vous ferait gagner du temps et des efforts.

<Callout kind="info">
  <strong>Astuce :</strong> Une fois que vous avez téléversé une image ou un fichier, vous pouvez y faire référence partout dans votre section en créant un bloc d’image ou de fichier et en le sélectionnant dans l’ **Bibliothèque** onglet.

  Nous vous recommandons de faire cela plutôt que de téléverser l’image à nouveau à chaque fois que vous souhaitez l’inclure, afin de faciliter le remplacement des images par la suite et d’éviter d’avoir plusieurs fichiers portant le même nom.
</Callout>
