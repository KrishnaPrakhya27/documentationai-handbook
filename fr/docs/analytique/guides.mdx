#### Guides rapides

<Expandable title="Comment utiliser les analyses du site ?">
  Consultez le trafic, les retours, les recherches et l'activité de Ask AI depuis votre tableau de bord d'analyses du site.

  Ce guide montre comment filtrer les données et repérer des opportunités de contenu.
</Expandable>

<Expandable title="Comment utiliser les données de recherche et de retours ?">
  Les termes de recherche et les évaluations des pages mettent en évidence le contenu qui nécessite une attention.

  Ce guide montre comment repérer les lacunes et prioriser les améliorations de la documentation.
</Expandable>

<Expandable title="Comment suivre la documentation avec Google Analytics ?">
  Connectez Google Analytics pour mesurer le trafic au-delà des analyses du site GitBook.

  Ce guide couvre l'intégration, les ID de mesure et la collecte de données.
</Expandable>

<Expandable title="Comment créer un rapport d'analyse personnalisé ?">
  Utilisez l'API d'agrégation des événements pour analyser le comportement de la documentation dans vos propres outils.

  Ce guide couvre les données d'événements, les requêtes et la création de rapports dans les tableaux de bord.
</Expandable>
