#### Guides rapides

<Expandable title="Comment publier un site de documentation ?">
  Créez un site de documentation, ajoutez un espace et choisissez qui peut y accéder.

  Ce guide couvre la création du site, les paramètres d’audience et la publication de votre contenu.
</Expandable>

<Expandable title="Comment personnaliser mon site de documentation ?">
  Personnalisez votre site de documentation pour qu’il corresponde à votre marque et améliorez la navigation.

  Ce guide couvre les thèmes, les logos, la navigation et les paramètres de page.
</Expandable>

<Expandable title="Comment contrôler l’accès à ma documentation ?">
  Choisissez si les visiteurs accèdent à votre documentation publiquement, via des liens de partage ou après authentification.

  Ce guide couvre les paramètres d’audience, les liens de partage et l’accès authentifié.
</Expandable>

<Expandable title="Comment mesurer les performances du site de documentation ?">
  Les statistiques du site montrent comment les visiteurs utilisent votre documentation et où ils ont besoin d’aide.

  Ce guide couvre le trafic, les retours sur les pages, la recherche et les questions à l’IA.
</Expandable>
