### Autorisez les lecteurs à exporter une version PDF de votre contenu publié

Pour activer ou désactiver l’export PDF pour les visiteurs de votre [site de documentation publié](/fr/docs/publier/publish-a-docs-site), ouvrez **Personnaliser**, sous **Outils** dans la barre latérale du site, puis accédez à **Configurer → Actions de la page**. À partir de là, vous pouvez activer ou désactiver **Exporter en PDF** activé ou désactivé.

Ce paramètre détermine si **les lecteurs de votre contenu publié peuvent le télécharger au format PDF**. Cette fonctionnalité est disponible uniquement pour **les sites Premium et Ultimate**.

### Exportez votre propre contenu interne en PDF

Quelle que soit la façon dont vous décidez de configurer vos sites de documentation publiés, tous les membres connectés d’une organisation sur un plan Pro ou Enterprise peuvent exporter une page — ou une section entière — de votre base de connaissances interne en tant que fichier PDF.

<Callout kind="alert">
  Notez que les liens entre sections ne sont pas actuellement pris en charge lors de l’exportation de contenu interne en PDF.
</Callout>

#### Exporter une page individuelle

1. Ouvrez la page que vous souhaitez exporter, puis ouvrez le [menu Actions](/fr/docs/reference/gitbook-ui#the-actions-menu)

   <Image src="https://test-dai.imgix.net/org-4afef969-21f9-40f3-b5b8-b06c8b6cf68f/doc-22a3b060-9539-4176-97e4-49120e02f5d1/4fa265378c13a520-spaces-NkEGS7hzeqa35sMXQZ4X-uploads-89MTSo5XRpPMVr1T0rxS-actions.svg?rasterize-bypass=true" alt="L’icône du menu Actions dans GitBook" />

   à côté du titre de la page.
2. Sélectionnez **Exporter en PDF > Page actuelle**.
3. Attendez que la page se charge, puis cliquez sur le **Imprimer ou enregistrer en PDF** bouton en haut à droite pour ouvrir le menu Imprimer de votre navigateur.
4. À partir de là, vous pouvez enregistrer la page en PDF ou l’ouvrir dans votre lecteur PDF en suivant la procédure habituelle de votre navigateur.

#### Exporter une section entière

1. Ouvrez le[ menu Actions](/fr/docs/creer-du-contenu/content-structure)

   <Image src="https://test-dai.imgix.net/org-4afef969-21f9-40f3-b5b8-b06c8b6cf68f/doc-22a3b060-9539-4176-97e4-49120e02f5d1/4fa265378c13a520-spaces-NkEGS7hzeqa35sMXQZ4X-uploads-89MTSo5XRpPMVr1T0rxS-actions.svg?rasterize-bypass=true" alt="L’icône du menu Actions dans GitBook" />

   à côté du titre de la page et choisissez **Exporter en PDF > Toutes les pages**. Vous pouvez également ouvrir le **menu Actions**

   <Image src="https://test-dai.imgix.net/org-4afef969-21f9-40f3-b5b8-b06c8b6cf68f/doc-22a3b060-9539-4176-97e4-49120e02f5d1/0a460c049ef3df1f-spaces-NkEGS7hzeqa35sMXQZ4X-uploads-PnnI41SqLSaKBNwT98fW-actions-horizontal.svg?rasterize-bypass=true" alt="L’icône du menu Actions dans GitBook" />

   dans le [en-tête de section](/fr/docs/reference/gitbook-ui#space-header) et choisissez **Exporter en PDF** dans le menu déroulant.<br /><br />&#xNAN;<em>Remarque : cette action n’est pas disponible dans une demande de modification.</em>
2. Attendez que la page se charge, puis cliquez sur le **Imprimer ou enregistrer en PDF** bouton en haut à droite pour ouvrir le menu Imprimer de votre navigateur.
3. À partir de là, vous pouvez enregistrer la page en PDF ou l’ouvrir dans votre lecteur PDF en suivant la procédure habituelle de votre navigateur.
