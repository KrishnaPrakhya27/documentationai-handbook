Avec un sous-répertoire personnalisé, vous pouvez rendre votre site de documentation accessible à `example.com/docs`. Ceci est différent d'un [domaine personnalisé](/fr/docs/publier/custom-domain) qui vous permet de rendre votre site de documentation accessible à `docs.example.com`.

Une des raisons de le faire est que l’URL de votre documentation soit formatée de manière cohérente avec les URL de votre autre site. L’utilisation d’un sous-répertoire peut également être bénéfique pour le référencement.

Pour configurer un sous-répertoire, vous devrez effectuer la configuration dans le backend de votre site web, puis finaliser le processus dans les paramètres de votre site GitBook.
