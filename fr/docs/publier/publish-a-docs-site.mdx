Lorsque vous avez terminé d’écrire, de modifier ou d’importer votre contenu, publiez-le pour l’audience sélectionnée.

Le contenu d’un site de documentation se trouve dans ses [sections](/fr/docs/gerer-votre-site/site-structure). La structure que vous modifiez est celle que voient les visiteurs. Les nouvelles sections commencent comme des brouillons, afin que vous contrôliez ce qui apparaît sur votre site publié.

### Créer un site de documentation

Pour créer un site de documentation :

1. Depuis votre organisation **Accueil**, cliquez sur l’ <strong>+</strong> icône à côté de **Sites**.
2. Saisissez un nom que les visiteurs reconnaîtront.
3. Cliquez sur **Créer**.
4. Sélectionnez un point de départ : un modèle de documentation, une importation, une spécification OpenAPI, une section vierge ou Git Sync.

Pour un guide d’installation complet, consultez le [Démarrage rapide](/fr/docs/getting-started/quickstart).

<Callout kind="info">
  Vous pouvez gérer les autorisations du site dans **Paramètres** → **Membres**. Cela vous permet de contrôler qui peut afficher ou modifier chaque site indépendamment des paramètres de l’organisation. Voir [Rôles](/fr/docs/collaborer/member-management/roles) pour plus de détails.
</Callout>

### Publier un site de documentation

Pour publier votre site :

1. Depuis votre organisation **Accueil**, ouvrez votre site.
2. Cliquez sur **Publier** dans l’en-tête du site.

Les sites sont publics par défaut. Modifiez la visibilité de votre site dans **Paramètres** → **Audience**. Voir [Paramètres du site](/fr/docs/gerer-votre-site/site-settings).

### Prévisualiser votre site

Cliquez sur **Aperçu** dans l’en-tête du site pour voir votre contenu tel que le verront les visiteurs — avant de publier le site, ou pendant que vous travaillez sur des modifications. Relisez votre contenu et vos personnalisations, puis publiez lorsque tout est correct.

### Supprimer ou dépublier un site de documentation

Pour dépublier votre site, ouvrez **Paramètres** → **Général** et sélectionnez **Dépublier le site**. Une fois confirmé, le site n’est plus accessible aux visiteurs.

La dépublication ne modifie pas votre facturation. Pour ajuster le nombre de sites que vous payez, mettez à jour votre forfait dans les paramètres de facturation de votre organisation.

#### Mon site est toujours accessible après la dépublication ou la suppression

Si vous pouvez toujours ouvrir l’URL, l’ancienne version est généralement mise en cache — dans votre navigateur, sur un CDN ou dans un résultat de moteur de recherche. Pour confirmer que le site n’est plus en ligne, ouvrez l’URL dans une fenêtre privée, ou videz le cache de votre navigateur pour ce site, puis rechargez.

#### Mon site apparaît toujours dans les moteurs de recherche

Les moteurs de recherche mettent du temps à mettre à jour leurs index, donc un site dépublié peut apparaître dans les résultats pendant un certain temps. La durée dépend de facteurs tels que la fréquence d’exploration et le nombre d’autres sites qui renvoient vers la page.

Pour accélérer le processus, demandez une nouvelle exploration depuis Google Search Console : ouvrez l’ **Inspection de l’URL** onglet, saisissez l’URL et cliquez sur **Demander l’indexation**. Google examine la demande et supprime la page de son index si elle n’est plus publiée.

Vous pouvez vérifier si votre site est toujours indexé en recherchant dans Google `site:` suivi de l’URL de votre site.

Pour supprimer un site de documentation :

1. Ouvrez **Paramètres** → **Général**.
2. Sélectionnez [**Supprimer le site**](/fr/docs/gerer-votre-site/site-settings#delete-site).

La suppression d’un site supprime définitivement ses paramètres et ses personnalisations. Votre contenu reste dans votre organisation — retrouvez-le dans [Tout le contenu](/fr/docs/creer-du-contenu/content-structure/all-content).
