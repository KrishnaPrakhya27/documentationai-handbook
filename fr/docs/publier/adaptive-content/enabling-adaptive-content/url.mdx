Vous pouvez transmettre des données de visiteur à votre documentation via des paramètres de requête d'URL. Voici un aperçu de la méthode :

| Méthode | Cas d'utilisation | Facilité de configuration | Sécurité | Format |
| --- | --- | --- | --- | --- |
| Paramètres de requête `visitor.<prop>=` | Indicateurs de fonctionnalité, rôles | Facile à utiliser | ❌ Le visiteur peut remplacer les propriétés | JSON |

### Paramètres de requête

Pour transmettre des données à GitBook via des paramètres d'URL, vous devrez passer les données dans l'URL au format `visitor.<prop>`.

Par exemple :

```url
https://docs.acme.org/?visitor.language=fr
```

Cela vous permettra d'utiliser ces revendications dans le [éditeur de conditions](/fr/docs/publier/adaptive-content/adapting-your-content#working-with-the-condition-editor) sous l'objet unsigned :

```javascript
visitor.claims.unsigned.language === "fr"
```

<Callout kind="alert">
  Les données transmises via les paramètres de requête doivent être définies dans votre schéma de visiteur via un [unsigned](/fr/docs/publier/adaptive-content/enabling-adaptive-content#set-an-unsigned-claim) objet. De plus, les paramètres de requête peuvent être facilement modifiés par le visiteur et conviennent mieux aux informations non sensibles.
</Callout>
