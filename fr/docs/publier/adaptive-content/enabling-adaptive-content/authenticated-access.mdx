GitBook propose des solutions prêtes à l'emploi pour protéger votre documentation. Des intégrations pour Auth0, Okta, Azure AD et AWS Cognito vous permettent d’installer une intégration afin d’imposer un écran de connexion avant de pouvoir accéder à votre site publié.

Selon la méthode d’accès authentifié que vous utilisez, vous devrez tout de même configurer quelques éléments supplémentaires en fonction de l’intégration que vous utilisez afin d’envoyer les bonnes données à GitBook.

Consultez le guide correspondant pour obtenir des instructions complètes sur la configuration du contenu adaptatif avec l’accès authentifié.

Si vous utilisez votre propre flux d’authentification, [Configuration d’un backend personnalisé](/fr/docs/publier/site-audience/authenticated-access/setting-up-a-custom-backend) couvre la connexion, les redirections de secours et la déconnexion.
