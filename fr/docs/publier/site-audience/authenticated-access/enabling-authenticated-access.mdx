Pour protéger vos docs derrière un écran de connexion, vous devrez d’abord activer l’accès authentifié pour votre site.

### Activer l’accès authentifié

Rendez-vous dans les [paramètres du site](/fr/docs/gerer-votre-site/site-settings), puis choisissez **Accès authentifié** dans les paramètres d’audience de votre site. Une fois sélectionné, vous verrez quelques options que vous devrez continuer à configurer pour votre site. Vous verrez également une "**clé privée**", que vous devrez utiliser plus tard dans la configuration de l’accès authentifié.

### Choisissez une méthode d’authentification

Selon votre configuration, nous proposons des intégrations et des guides pour configurer l’accès authentifié avec différents outils.

Rendez-vous dans le guide correspondant pour poursuivre la configuration de l’accès authentifié pour votre site.
