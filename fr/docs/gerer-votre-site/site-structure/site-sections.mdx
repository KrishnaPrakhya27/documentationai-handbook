Les sections vous permettent de centraliser votre documentation sur un seul site. Utilisez-les pour organiser des produits distincts. Vous pouvez aussi proposer un contenu adapté à différents publics.

Regroupez des sections pour créer un menu déroulant dans votre barre de navigation. Les groupes ajoutent de la hiérarchie à votre site.

### Sections ou variantes ?

Chaque section contient son propre contenu. Utilisez les sections pour des espaces de documentation distincts. Elles peuvent représenter des produits, des publics ou des sujets.

Pour des variations du même contenu, utilisez [des variantes de contenu](/fr/docs/gerer-votre-site/site-structure/variants). Les variations incluent les localisations et les versions historiques des produits.

### Ajouter une section

Pour ajouter une section :

1. Dans la barre latérale du site, ouvrez **la structure du site**.
2. Sous le tableau, cliquez sur **Nouvelle section**.
3. Sélectionnez le contenu à ajouter.

La section apparaît dans le tableau. Elle apparaît aussi comme un onglet sur votre site publié.

### Créer un groupe de sections

Les groupes de sections créent un menu de navigation déroulant sous un seul titre. Les sections groupées peuvent avoir une description facultative. La description apparaît sous le titre de la section.

Pour créer un groupe :

1. À côté de **Nouvelle section**, cliquez sur la flèche.
2. Sélectionnez **Nouveau groupe de sections**.
3. Saisissez un nom de groupe.
4. Cliquez sur **Ajouter une section**.
5. Ajoutez des sections existantes ou sélectionnez un nouveau contenu.

Si votre site prend en charge plusieurs langues, traduisez les titres des groupes, les titres des sections et les descriptions. Voir [Sections multilingues](/fr/docs/gerer-votre-site/site-structure/multilingual-sections).

### Modifier une section

Pour modifier une section :

1. Dans la ligne du tableau de la section, cliquez sur **Modifier**.
2. Modifiez le nom, l'icône ou le slug.
3. Cliquez sur **Enregistrer**.

Pour supprimer une section, cliquez sur **Supprimer** dans le coin inférieur gauche.

<Callout kind="info">
  Modifier le slug d'une section modifie son URL canonique. GitBook crée une redirection depuis l'ancienne URL. Vous pouvez aussi [créer des redirections manuellement](/fr/docs/publier/site-redirects).
</Callout>

### Masquer une section

**Afficher dans la navigation du site** détermine si une section apparaît dans la navigation supérieure de votre site. Masquer une section la retire de la navigation publiée. Cela ne supprime pas la section ni son contenu.

Pour masquer une section :

1. Dans la barre latérale du site, ouvrez **la structure du site**.
2. Dans la ligne du tableau de la section, cliquez sur **Modifier**.
3. Désactivez **Afficher dans la navigation du site**.
4. Cliquez sur **Enregistrer**.

Ce paramètre contrôle la visibilité des sections. Il est différent de **Masquer la page**, qui masque une page de la table des matières d'une section. Les visiteurs ne verront pas les sections masquées dans la navigation du site publié.

### Réorganiser les sections

Les sections apparaissent dans le même ordre que le **la structure du site** tableau. Pour réorganiser une section, faites glisser sa poignée vers le haut ou vers le bas. Le contenu de la section se déplace avec elle. Le nouvel ordre apparaît immédiatement sur votre site.

Pour utiliser un clavier :

1. Appuyez sur **Espace** pour sélectionner une section.
2. Appuyez sur une touche fléchée pour déplacer la section.
3. Appuyez sur **Espace** pour confirmer.

### Définir la section d'accueil

La section d'accueil apparaît lorsque les visiteurs ouvrent votre site. Elle se charge à l'URL racine de votre site. Les autres sections ajoutent un slug à l'URL racine.

Pour définir la section d'accueil :

1. Dans la ligne du tableau de la section, ouvrez le **menu** .
2. Cliquez sur **Définir comme page d'accueil**.

### Définir la variante d'accueil

Si une section comporte plusieurs variantes, choisissez la variante que les visiteurs ouvrent en premier.

Pour définir la variante d'accueil :

1. Ouvrez **les paramètres du site**.
2. Cliquez sur **Structure**.
3. Cliquez sur la section à mettre à jour.
4. Trouvez la variante que les visiteurs ouvrent en premier.
5. Cliquez sur **Définir comme page d'accueil**.

### Supprimer une section

Pour supprimer une section :

1. Dans la barre latérale du site, ouvrez **la structure du site**.
2. Ouvrez le **menu** .
3. Cliquez sur **Supprimer**.

<Callout kind="success">
  La suppression d'une section la dépublie, ainsi que ses variantes. Cela ne supprime pas le contenu. Vous pouvez toujours le retrouver dans [Tout le contenu](/fr/docs/creer-du-contenu/content-structure/all-content).
</Callout>
