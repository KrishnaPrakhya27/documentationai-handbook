### Général

<Expandable title="Titre du site">
  Modifiez le nom de votre site ; si vous n'avez pas de logo personnalisé, c'est le nom que verront les visiteurs de votre site.
</Expandable>

<Expandable title="Cookie d'analyse">
  Si vous souhaitez utiliser [les analyses du site](/fr/docs/analytique/insights), votre site utilisera des cookies pour identifier les visiteurs récurrents et recueillir les données nécessaires à la consultation de vos analyses. Vous pouvez choisir de désactiver ces cookies, mais cela vous empêchera d'utiliser les analyses du site.<br /><br />L'avis relatif aux cookies apparaît lorsque l'analyse est activée sur votre site via une intégration, en particulier **Google Analytics**.

  Pour supprimer cet avis, ouvrez **Paramètres du site → Intégrations**  en haut à droite. Désactivez ou supprimez ensuite **Google Analytics**

  La désactivation de ces cookies désactive également [les analyses du site](/fr/docs/analytique/insights) pour ce site.
</Expandable>

<Expandable title="Dépublier le site">
  Dépubliez votre site, mais conservez ses paramètres et ses personnalisations. Vous pourrez republier votre site à tout moment.
</Expandable>

<Expandable title="Supprimer le site">
  Dépubliez et supprimez votre site de la **section du site de documentation** dans l’application GitBook.

  <strong>Note :</strong> La suppression d’un site est définitive et irréversible. Tous les paramètres et personnalisations seront perdus, mais votre contenu restera dans son [espace](/fr/docs/creer-du-contenu/content-structure/space).
</Expandable>

<Expandable title="Accès">
  Gérez qui peut accéder à votre site de documentation et l’administrer.

  Ouvrez **Accès** puis cliquez sur **Gérer les autorisations**. Vous pouvez également utiliser **Partager** depuis la **page d’aperçu** .

  Les autorisations du site sont disponibles dans toutes les formules.

  Par défaut, les nouveaux sites héritent des autorisations de leurs [espaces](/fr/docs/creer-du-contenu/content-structure/space), jusqu’à ce que vous mettiez à jour les autorisations depuis la fenêtre modale des autorisations du site.

  Les autorisations du site peuvent également affecter les autorisations des espaces liés qui utilisent **Hérité** le mode. Dans ce cas, chaque espace hérité reçoit le niveau d’autorisation le plus élevé accordé par l’organisation, toute collection parente et tout site qui l’inclut.
</Expandable>

### Audience

<a id="audience"></a>

<Expandable title="Audience">
  Choisissez qui voit votre contenu publié. Voir [Publier un site de documentation](/fr/docs/publier/publish-a-docs-site) pour plus d’informations.
</Expandable>

<Expandable title="Contenu adaptatif">
  Activez le contenu adaptatif pour les pages, variantes et sections de votre site. [Contenu adaptatif](/fr/docs/publier/adaptive-content) vous permet de masquer ou d’afficher du contenu à différents visiteurs, selon leurs autorisations.

  Votre clé de signature du jeton visiteur sera également affichée ici.
</Expandable>

<Expandable title="Domaine personnalisé">

</Expandable>

<Expandable title="Sous-répertoire GitBook">

### Fonctionnalités

<Expandable title="Exportation PDF">
  Permettez à vos visiteurs d’exporter votre GitBook en PDF. Voir [Export PDF](/fr/docs/publier/pdf-export) pour plus d’informations.
</Expandable>

<Expandable title="Évaluations des pages">
  Choisissez si les visiteurs de votre contenu publié peuvent ou non laisser une note sur chaque page pour vous indiquer ce qu’ils en pensent. Ils pourront choisir un visage triste, neutre ou content.

  Vous pouvez consulter les résultats de ces évaluations en ouvrant [les analyses du site](/fr/docs/analytique/insights) depuis le tableau de bord de votre site de documentation et en sélectionnant **Pages et commentaires**.
</Expandable>

### IA et MCP

Les paramètres d’IA sont disponibles selon certaines formules. L’emplacement de la barre de recherche est disponible avec les formules de site Premium et Ultimate. L’emplacement dans la barre latérale et les connecteurs MCP sont disponibles avec Ultimate.

<Expandable title="Assistant IA">
  Activez ou désactivez l’Assistant IA pour votre site. Voir [Assistant IA](/fr/docs/lia-pour-vos-lecteurs/gitbook-ai-assistant) pour plus d’informations.
</Expandable>

<Expandable title="Apparence">
  Choisissez où l’Assistant apparaît à l’aide de **Emplacement** — **Barre latérale** pour l’expérience de chat complète, disponible avec les formules de site Ultimate, ou **Barre de recherche** pour répondre aux questions dans la barre de recherche de votre site, disponible avec les formules de site Premium et Ultimate. Vous pouvez également définir ici le message d’accueil de l’Assistant, qui s’applique uniquement à l’emplacement dans la barre latérale. Voir [Assistant IA](/fr/docs/lia-pour-vos-lecteurs/gitbook-ai-assistant) pour plus d’informations.
</Expandable>

<Expandable title="Étendez l’Assistant GitBook avec des connecteurs MCP">
  Configurez les serveurs MCP que l’Assistant GitBook peut utiliser pour répondre aux questions dans votre documentation. Ce paramètre est disponible avec les formules de site Ultimate. Voir [Serveurs MCP pour la documentation publiée](/fr/docs/lia-pour-vos-lecteurs/mcp-servers-for-published-docs) pour plus d’informations.
</Expandable>
