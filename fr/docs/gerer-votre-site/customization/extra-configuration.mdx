Dans le **Configuration** onglet, vous pouvez modifier d’autres paramètres associés à votre site. Par exemple, vous pouvez configurer la localisation de l’interface, le comportement des liens et les actions de page qui aident vos utilisateurs à ajouter votre contenu à des outils d’IA comme ChatGPT.

Sur cette page, vous apprendrez ce que fait chacune de ces options et comment les activer ou les désactiver.

### Localiser l’interface utilisateur

Vous pouvez sélectionner une langue dans une liste pour localiser l’interface utilisateur de votre contenu publié. Cela applique des traductions aux zones de l’interface qui ne sont pas personnalisées.

Ce paramètre ne va *pas* traduire automatiquement votre contenu réel, mais il peut aider à faire correspondre l’interface à la langue dans laquelle vous écrivez. Pour en savoir plus sur la traduction de votre contenu, rendez-vous dans la [Traductions](/fr/docs/agent-gitbook/translations) section.

Y a-t-il une langue que nous ne proposons pas encore et que vous aimeriez voir ajoutée ? [Faites-le-nous savoir](https://github.com/GitbookIO/gitbook/issues), ou [proposez votre propre traduction](https://www.gitbook.com/solutions/open-source)!

### Lien principal

Dans le **Lien principal** section de l’ **onglet Configuration** , vous pouvez définir une URL personnalisée pour le logo situé dans le coin supérieur gauche de votre site de documentation.

Par défaut, cliquer sur le logo ou le titre du site ramènera les utilisateurs à la première page de votre site de documentation. Vous pouvez définir à la place une URL personnalisée hors de votre site — ou une page, une section ou une variante de votre site — à ouvrir. Si votre documentation fait partie d’un site web plus vaste, cela peut aider les visiteurs à revenir vers votre propre page d’accueil.

### Liens externes

La **Liens externes** section de l’ **onglet Configuration** onglet contrôle le comportement lorsque les utilisateurs de votre site cliquent sur un lien vers une URL externe. Par défaut, ces liens s’ouvrent dans le même onglet, mais vous pouvez modifier cela pour qu’ils s’ouvrent dans un nouvel onglet si c’est votre préférence.

### Actions de page

Actions de page ajoute un menu déroulant au niveau de la page à chaque page de votre documentation, permettant aux utilisateurs d’effectuer rapidement des actions sur le contenu d’une page — idéal pour utiliser le contenu de votre documentation comme contexte dans une invite d’IA.

Vous pouvez désactiver cette option depuis l’ **onglet Configuration** onglet si vous ne souhaitez pas afficher les options de page dans votre documentation publiée.

Si vous désactivez **Actions de page**, GitBook désactive également le serveur MCP à `~gitbook/mcp`. Pour utiliser MCP, laissez **Actions de page** activé dans **Personnalisation du site** → **Actions de page**.

#### Ouvrir dans des fournisseurs d’IA

Activez cette option pour afficher une action permettant d’ouvrir ChatGPT ou Claude avec le contenu de la page.

#### Copier/Afficher en Markdown

Activez cette option pour afficher une action permettant de copier ou d’afficher la page en Markdown.

#### Se connecter au serveur MCP

Activez cette option pour afficher le lien du serveur MCP dans le menu des actions de page.

Cette option n’active pas le serveur MCP lui-même. Le serveur MCP fonctionne uniquement lorsque **Actions de page** est activé. Pour en savoir plus, consultez [Serveurs MCP pour la documentation publiée](/fr/docs/lia-pour-vos-lecteurs/mcp-servers-for-published-docs).

#### Modifier sur GitHub/GitLab

Si votre section est connectée à un dépôt Git, vous pouvez activer cette option dans l’ **onglet Configuration** onglet pour afficher un lien permettant à vos utilisateurs de contribuer à votre documentation depuis votre dépôt lié.

#### Exporter en PDF

Activez cette option pour permettre aux visiteurs d’ [exporter un PDF](/fr/docs/publier/pdf-export) de votre documentation.

### Politique de confidentialité

Dans le **Politique de confidentialité** section de l’ **onglet Configuration** onglet, vous pouvez créer un lien vers votre propre politique de confidentialité afin d’aider les visiteurs à comprendre comment votre contenu GitBook utilise des cookies et comment vous protégez leur vie privée. Si vous choisissez de ne pas en définir une, votre site utilisera par défaut [la politique de confidentialité de GitBook](/en/docs/policies/privacy-and-security/statement/cookies).
