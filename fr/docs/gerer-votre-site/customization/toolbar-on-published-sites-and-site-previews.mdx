Lorsque vous consultez votre site de documentation en ligne, il se peut qu’une barre d’outils apparaisse en bas de la fenêtre du navigateur. Elle permet d’accéder rapidement à des options utiles en un clic :

- Ouvrir l’éditeur pour consulter et modifier le contenu de votre site
- Ouvrez les paramètres de votre site dans GitBook
- Ouvrez les paramètres de personnalisation de votre site
- Ouvrir les statistiques du site

<Callout kind="alert">
  La barre d’outils est **visible uniquement aux membres connectés de votre organisation GitBook**. Les visiteurs du site qui ne sont pas membres de votre organisation GitBook **ne verront pas la barre d’outils**.
</Callout>

Vous verrez également une version légèrement différente de la barre d’outils lorsque vous [ouvrez une URL d’aperçu de votre site](/fr/docs/collaborer/change-requests#preview-a-change-request) depuis l’application GitBook, ce qui vous permet de revenir dans l’application pour ajouter un retour ou continuer à modifier.

#### Quand la barre d’outils apparaît-elle ?

Vous verrez la barre d’outils dans les situations suivantes :

- Consultation de votre site en ligne lorsque vous êtes connecté à GitBook
- Prévisualisation d’anciennes versions de votre site via votre [historique des versions](/fr/docs/creer-du-contenu/version-control)
- Prévisualisation des liens pour des modifications proposées, par exemple dans une [demande de modification](/fr/docs/collaborer/change-requests) créée dans GitBook ou d’une pull request créée via [Git Sync](/fr/docs/la-documentation-comme-code/git-sync/github-pull-request-preview)

#### Pourquoi la barre d’outils n’est-elle pas affichée ?

Si vous êtes connecté à GitBook et que vous ne voyez toujours pas la barre d’outils, il se peut que votre navigateur bloque les cookies tiers.

La barre d’outils utilise des cookies tiers pour reconnaître votre session GitBook sur votre site de documentation publié ou sur l’URL d’aperçu. Si votre navigateur bloque ces cookies, la barre d’outils peut ne pas apparaître.

Pour afficher la barre d’outils, activez les cookies tiers pour le domaine de votre documentation dans les paramètres de votre navigateur, puis rechargez la page.

<Callout kind="info">
  Ce problème est plus fréquent dans les navigateurs ou les extensions ayant des paramètres de confidentialité plus stricts.
</Callout>

#### Puis-je masquer la barre d’outils ?

Oui. En cliquant sur le dernier bouton de la barre d’outils, vous pouvez choisir parmi différentes options pour modifier l’affichage de la barre d’outils :

1. <strong>Réduire :</strong> Cela réduit la barre d’outils à une petite pastille. Pour la déployer à nouveau, il vous suffit de cliquer dessus.
2. <strong>Fermer pour une session :</strong> Supprime complètement la barre d’outils dans l’onglet actuel jusqu’à ce que vous le fermiez.
3. <strong>Ne plus afficher :</strong> Masque la barre d’outils et mémorise votre choix. Vous pouvez rétablir la barre d’outils en effaçant le stockage local de votre navigateur.
