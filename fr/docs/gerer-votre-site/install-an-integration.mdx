Il y a [de nombreuses intégrations différentes](https://www.gitbook.com/integrations#custom-experiences) disponibles dans GitBook. Des blocs de contenu interactifs aux outils d'analyse avancée, vos outils préférés ne sont qu'à un clic de l'intégration avec GitBook.

Vous pouvez installer une intégration dans une seule section, dans plusieurs sections ou dans toutes les sections de votre organisation.

Si vous installez une intégration dans une seule section, elle ne fonctionnera que dans cette section spécifique. En installant une intégration dans plusieurs sections, vous pourrez effectuer des actions sur l'ensemble de ces sections.

### Installer une intégration

#### 1\. Ouvrez l'écran des intégrations

Avant d'activer une intégration dans une section ou un site, vous devez l'installer dans votre organisation. Retournez à votre organisation **Accueil** et cliquez sur **Intégrations** dans la barre latérale. Parcourez les intégrations par catégorie ou recherchez celle dont vous avez besoin.

Une fois l'intégration installée dans votre organisation, vous pouvez également l'utiliser au niveau du site — cliquez sur **Intégrations**, sous **Étendre** dans la barre latérale du site. Les intégrations déjà ajoutées au site apparaissent sous **Intégrations installées**.

#### 2\. Sélectionnez l'intégration et installez-la

Ensuite, cliquez sur l'intégration que vous souhaitez installer. Certaines intégrations peuvent être installées pour vos sections, et d'autres pour votre documentation publiée.

Sur cet écran, vous pouvez sélectionner les zones dans lesquelles vous souhaitez installer votre intégration.

#### 3\. Configurez votre intégration

<Callout kind="info">
  Les intégrations d'analyse — comme Google Analytics, Segment ou Fathom — sont configurées pour l'ensemble du site. Si votre site contient plusieurs sections, vous ne pouvez pas collecter des statistiques séparées par section ; une seule configuration s'applique à l'ensemble du site.
</Callout>

Vous pouvez maintenant utiliser votre intégration. Certaines intégrations peuvent nécessiter une configuration supplémentaire. Le cas échéant, vous verrez un message vous demandant de configurer votre intégration dans votre section ou votre site.

Consultez les instructions de l'intégration pour en savoir plus sur sa configuration pour votre équipe.

### FAQ

<Expandable title="Comment configurer mon intégration ?">
  Chaque intégration possède ses propres options de configuration. Vous pouvez trouver les instructions de configuration spécifiques à chaque intégration sur sa page d'installation.
</Expandable>

<Expandable title="Puis-je demander une intégration ?">
  Oui — [soumettre une demande d'intégration](https://survey.refiner.io/e61q1m-dp057m), ou rendez-vous sur la [communauté GitBook](https://github.com/GitbookIO/community) pour discuter de ce que vous aimeriez voir dans GitBook.
</Expandable>

<Expandable title="Puis-je créer ma propre intégration ?">
  La plateforme d'intégration est disponible pour toute personne disposant d'un compte GitBook. Consultez [notre page des intégrations](https://www.gitbook.com/integrations) ou la [documentation développeur](https://developer.gitbook.com/) pour commencer.
</Expandable>

<Expandable title="GitBook prend-il en charge Google Tag Manager ?">
  Non. Google Tag Manager permet l'injection de CSS et de JavaScript, ce qui peut casser des sites et pose des problèmes de sécurité ; GitBook ne s'y intègre donc pas.
</Expandable>
