## La documentation que vos utilisateurs lisent vraiment

Vos utilisateurs sont des humains et leurs agents IA — GitBook publie pour les deux. Écrivez dans l’éditeur, pilotez-le depuis votre agent, ou synchronisez depuis Git.

[Démarrage rapide](/fr/docs/getting-started/quickstart)[GitBook MCP](/fr/docs/la-documentation-comme-code/gitbook-mcp)

### IA prête à l’emploi

Deux travaillent pour vous pendant que vous écrivez. Trois travaillent pour vos lecteurs après votre publication.

<Columns cols={2}>
  <Card title="Agent GitBook" href="/fr/docs/agent-gitbook/overview">
    ÉCRIT AVEC VOUS

    Rédige, modifie, relit les demandes de changement et signale les lacunes par rapport à votre guide de style.
  </Card>

  <Card title="Assistant IA" href="/fr/docs/lia-pour-vos-lecteurs/gitbook-ai-assistant">
    RÉPOND AUX LECTEURS

    Répond aux questions sur votre site à partir de vos docs et des sources d’assistance connectées, dans la barre latérale ou la zone de recherche.
  </Card>

  <Card title="Insights IA" href="/fr/docs/analytique/ai-insights">
    AMÉLIORE LA DOCS

    Voyez ce que vos visiteurs demandent et identifiez les lacunes de connaissance dans vos docs.
  </Card>

  <Card title="MCP pour vos docs" href="/fr/docs/lia-pour-vos-lecteurs/mcp-servers-for-published-docs">
    SERVE LES AGENTS

    Vos docs publiées comme un outil, afin que les agents de vos clients puissent les lire correctement.
  </Card>
