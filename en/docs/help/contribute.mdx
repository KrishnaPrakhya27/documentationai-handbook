Thank you for investing your time in contributing to GitBook's documentation. Every contribution is reviewed by the team.

This documentation is published with GitBook, using Git Sync to keep the site up to date with the `public-docs` repository on GitHub. Any change that's reviewed, approved, and merged into the repository is deployed automatically.

#### What to contribute

- Corrections — inaccurate steps, outdated screenshots, broken links, typos.
- Clarifications — a section that's technically correct but hard to follow.
- Missing detail — an edge case or error message the page doesn't cover.

For problems with GitBook itself rather than the documentation, see Report a bug.

#### How to submit a change

1. Open a pull request against the `public-docs` repository.
2. Describe what you changed and why. Link to the published page you're editing.
3. A member of the documentation team reviews it. Once it's approved and merged, the change deploys automatically.
