```tsx
<textinput id="name" label="Name" initialValue="John Doe" placeholder="Enter a name" />
```

| Props | Type | Description |
| --- | --- | --- |
| `state`* | `string` | Binding state key. |
| `initialValue` | `string` | Initial value. |
| `label` | `string` | Input label. |
| `placeholder` | `string` | Placeholder. |

Use `@editor.node.updateProps` to save `element.dynamicState('content')` as a block property. Follow [Create an interactive text input](/en/docs/developers/integrations/guides/create-an-interactive-text-input) for an example.
