| Term | Description | Where to Find |
| --- | --- | --- |
| `<organizationId>` | A unique identifier of an Organization in GitBook. | Found in the URL of any space or via the "Copy org ID" button in the organization settings.<br /><br />Example: `https://app.gitbook.com/o/<organizationId/s/<sapceId>` |
| `<spaceId>` | A unique identifier of a Space in GitBook. | Found in the URL of any space or via the "Copy space ID" button in the upper-right dropdown in a space.<br /><br />Example: `https://app.gitbook.com/o/<organizationId/s/<sapceId>` |
| `<userId>` | A unique identifier of a User in GitBook. | Retrieved from the "GET Current User" API endpoint or via the "Copy user ID" button from your organization settings. |
