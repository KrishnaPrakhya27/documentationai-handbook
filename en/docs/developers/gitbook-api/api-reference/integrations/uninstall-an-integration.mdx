**DELETE** `/integrations/{integrationName}/installations/{installationId}`

**Parameters**

<ParamField header="Authorization" param-type="string" required={true} />

<ParamField path="integrationName" param-type="string" required={true}>
  Name of the integration.
</ParamField>

<ParamField path="installationId" param-type="string" required={true}>
  Identifier of the installation
</ParamField>

**Responses**

`204` Integration installation did not exist

`205` Integration uninstalled successfully
