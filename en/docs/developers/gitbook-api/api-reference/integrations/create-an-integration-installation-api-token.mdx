Creates a temporary API token of an integration's installation that has access to the installation and it's scopes. You must be authenticated as the integration to obtain this token.

**POST** `/integrations/{integrationName}/installations/{installationId}/tokens`

**Parameters**

<ParamField header="Authorization" param-type="string" required={true} />

<ParamField path="integrationName" param-type="string" required={true}>
  Name of the integration.
</ParamField>

<ParamField path="installationId" param-type="string" required={true}>
  Identifier of the installation
</ParamField>

**Responses**

`200` The API token for the installation

<ResponseField name="token" field-type="string" required={true}>
  Temporary access token to authenticate with the API
</ResponseField>

`404` Not Found

<ResponseField name="error" field-type="object" required={true}>

    <ResponseField name="code" field-type="integer" required={true} enum="404" />

    <ResponseField name="message" field-type="string" required={true} />
  </Expandable>
</ResponseField>
