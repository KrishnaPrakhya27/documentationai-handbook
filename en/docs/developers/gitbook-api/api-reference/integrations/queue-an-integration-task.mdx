**POST** `/integrations/{integrationName}/tasks`

**Parameters**

<ParamField header="Authorization" param-type="string" required={true} />

<ParamField path="integrationName" param-type="string" required={true}>
  Name of the integration.
</ParamField>

**Request body**

<ParamField body="task" param-type="object" required={true}>
  Payload for the integration task
</ParamField>

<ParamField body="schedule" param-type="number">
  Number of seconds to wait before executing the task, defaults to 0
</ParamField>

**Responses**

`204` Integration task created successfully

`404` Not Found

    <ResponseField name="message" field-type="string" required={true} />
  </Expandable>
