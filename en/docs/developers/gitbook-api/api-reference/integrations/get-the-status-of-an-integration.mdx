Returns whether an integration is installed for the organization and the status of that installation. Use this for a single integration instead of listing every status.

**GET** `/orgs/{organizationId}/integrations/{integrationName}/installation_status`

**Parameters**

<ParamField header="Authorization" param-type="string" />

<ParamField path="organizationId" param-type="string" required={true}>
  The unique id of the organization
</ParamField>

<ParamField path="integrationName" param-type="string" required={true}>
  Name of the integration.
</ParamField>

**Responses**

`200` Integration installation status

<ResponseField name="status" field-type="string" required={true} enum="active,pending,paused" />

`404` Not Found

    <ResponseField name="message" field-type="string" required={true} />
  </Expandable>
</ResponseField>
