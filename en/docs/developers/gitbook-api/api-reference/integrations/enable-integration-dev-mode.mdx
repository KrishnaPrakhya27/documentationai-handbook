**PUT** `/integrations/{integrationName}/dev`

**Parameters**

<ParamField header="Authorization" param-type="string" />

<ParamField path="integrationName" param-type="string" required={true}>
  Name of the integration.
</ParamField>

**Request body**

<ParamField body="tunnelUrl" param-type="string" required={true}>
  URL of the tunnel to dispatch integration events to
</ParamField>

<ParamField body="all" param-type="boolean">
  If set to true, all requests will be forwarded to the tunnel, not just from the owning organization.
</ParamField>

**Responses**

`204` Updated development mode successfully

`404` Not Found
