**POST** `/integrations/{integrationName}/render`

**Parameters**

<ParamField header="Authorization" param-type="string" />

<ParamField path="integrationName" param-type="string" required={true}>
  Name of the integration.
</ParamField>

**Request body**

<ParamField body="componentId" param-type="string" required={true}>
  ID of the component to render in the integration.
</ParamField>

<ParamField body="props" param-type="object" required={true} />

<ParamField body="state" param-type="object">
  Current local state of the UI.
</ParamField>

<ParamField body="context" param-type="string" required={true}>
  Object representing the context in which a ContentKit component is rendered.
</ParamField>

<ParamField body="action" param-type="string" />

**Responses**

`200` ContentKit element to render
