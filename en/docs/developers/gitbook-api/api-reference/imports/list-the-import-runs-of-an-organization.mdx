Returns the import runs of the organization, most recent first. Runs left behind by an import that never reported back are returned as failed.

**GET** `/org/{organizationId}/imports`

**Parameters**

<ParamField header="Authorization" param-type="string" />

<ParamField path="organizationId" param-type="string" required={true}>
  The unique id of the organization
</ParamField>

<ParamField query="space" param-type="string">
  Only return the import runs targeting this space.
</ParamField>

<ParamField query="changeRequest" param-type="string">
  Only return the import runs targeting this change request.
</ParamField>

<ParamField query="site" param-type="string">
  Only return the import runs targeting a space of this site.
</ParamField>

<ParamField query="status" param-type="string" enum="active,pending,in-progress,completed,failed,cancelled">
  Only return the import runs in this status. `active` covers both `pending` and `in-progress`.
</ParamField>

<ParamField query="page" param-type="string">
  Identifier of the page results to fetch.
</ParamField>

<ParamField query="limit" param-type="number">
  The number of results per page
</ParamField>
