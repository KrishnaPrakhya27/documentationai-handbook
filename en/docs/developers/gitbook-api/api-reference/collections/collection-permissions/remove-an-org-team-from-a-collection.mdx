**DELETE** `/collections/{collectionId}/permissions/teams/{teamId}`

**Parameters**

<ParamField header="Authorization" param-type="string" />

<ParamField path="collectionId" param-type="string" required={true}>
  The unique id of the collection
</ParamField>

<ParamField path="teamId" param-type="string" required={true}>
  The unique ID of the Team
</ParamField>

**Responses**

`204` The team was not found in the collection

`205` The team has been removed from the collection
