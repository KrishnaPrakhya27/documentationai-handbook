Add or updates member in the specified organization team.

**PUT** `/orgs/{organizationId}/teams/{teamId}/members/{userId}`

**Parameters**

<ParamField header="Authorization" param-type="string" />

<ParamField path="organizationId" param-type="string" required={true}>
  The unique id of the organization
</ParamField>

<ParamField path="teamId" param-type="string" required={true}>
  The unique ID of the Team
</ParamField>

<ParamField path="userId" param-type="string" required={true}>
  The unique ID of the User
</ParamField>

**Request body**

<ParamField body="role" param-type="string" enum="owner,member">
  "The role of a team member.
  "owner": Can manage team members.
  "member": Is a member of the team.
</ParamField>

**Responses**

`204` Member has been added to the team
