Deletes member from the specified organization team.

**DELETE** `/orgs/{organizationId}/teams/{teamId}/members/{userId}`

**Parameters**

<ParamField header="Authorization" param-type="string" />

<ParamField path="organizationId" param-type="string" required={true}>
  The unique id of the organization
</ParamField>

<ParamField path="teamId" param-type="string" required={true}>
  The unique ID of the Team
</ParamField>

<ParamField path="userId" param-type="string" required={true}>
  The unique ID of the User
</ParamField>

**Responses**

`204` Member was not part of the team

`205` Member has been deleted from the team
