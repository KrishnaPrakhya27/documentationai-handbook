Returns the structural navigation links for a specific page within a change request, such as its parent page, previous sibling, and next sibling in the page tree. Use this to understand a page's position within the content hierarchy of the draft.

**GET** `/spaces/{spaceId}/change-requests/{changeRequestId}/content/page/{pageId}/meta-links`

**Parameters**

<ParamField header="Authorization" param-type="string" />

<ParamField path="spaceId" param-type="string" required={true}>
  The unique id of the space
</ParamField>

<ParamField path="changeRequestId" param-type="string" required={true}>
  The unique ID of the change request or its number identifier in the space
</ParamField>

<ParamField path="pageId" param-type="string" required={true}>
  The unique id of the page
</ParamField>

**Responses**

`200` OK

<ResponseField name="canonical" field-type="string" />

<ResponseField name="alternates" field-type="string[]" />
