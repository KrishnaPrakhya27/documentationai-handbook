Returns a paginated list of comments posted on the change request, optionally filtered by status, target page, or author. Comments can be anchored to a specific page or be general change-request-level comments. Use this to read the review discussion before responding. To fetch replies to a comment, use the comment replies endpoint.

**GET** `/spaces/{spaceId}/change-requests/{changeRequestId}/comments`

**Parameters**

<ParamField header="Authorization" param-type="string" />

<ParamField path="spaceId" param-type="string" required={true}>
  The unique id of the space
</ParamField>

<ParamField path="changeRequestId" param-type="string" required={true}>
  The unique ID of the change request or its number identifier in the space
</ParamField>

<ParamField query="page" param-type="string">
  Identifier of the page results to fetch.
</ParamField>

<ParamField query="limit" param-type="number">
  The number of results per page
</ParamField>

<ParamField query="order" param-type="string" enum="asc,desc">
  An order for the items in the list
</ParamField>

<ParamField query="format" param-type="string" enum="document,markdown">
  Output format for the content.
</ParamField>

<ParamField query="status" param-type="string" enum="all,open,resolved">
  When provided, only comments with the given status are returned. Defaults to "all".
</ParamField>

<ParamField query="targetPage" param-type="string">
  The target page of the comment
</ParamField>

<ParamField query="authors" param-type="string[]">
  User IDs to filter queried comments on
</ParamField>
