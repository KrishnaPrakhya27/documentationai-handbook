Sends review request notifications to one or more users, asking them to review the change request. Optionally updates the change request subject and description at the same time. Use this to move the change request into the review workflow after finishing edits. The users array must contain at least one valid user ID.

**POST** `/spaces/{spaceId}/change-requests/{changeRequestId}/requested-reviewers`

**Parameters**

<ParamField header="Authorization" param-type="string" />

<ParamField path="spaceId" param-type="string" required={true}>
  The unique id of the space
</ParamField>

<ParamField path="changeRequestId" param-type="string" required={true}>
  The unique ID of the change request or its number identifier in the space
</ParamField>

**Request body**

<ParamField body="users" param-type="string[]" required={true}>
  An array of user ids that will be requested.
</ParamField>

<ParamField body="subject" param-type="string">
  Optionally, update the subject of the change request when requesting reviewers.
</ParamField>

<ParamField body="description" param-type="object">

          The schema version of the document. If undefined, the document is considered to be of the latest schema version.
        </ParamField>
      </Expandable>
    </ParamField>

    <ParamField body="nodes" param-type="string[]" required={true} />

    <ParamField body="meta" param-type="object">
      <Expandable title="Object Properties">
        <ParamField body="token" param-type="string">
          A content token that can be used to fetch the content referenced in this document from the API.
        </ParamField>
      </Expandable>
    </ParamField>
  </Expandable>
</ParamField>

**Responses**

`200` The requests have successfully been sent.
