**DELETE** `/spaces/{spaceId}/change-requests/{changeRequestId}/requested-reviewers/{userId}`

**Parameters**

<ParamField header="Authorization" param-type="string" />

<ParamField path="spaceId" param-type="string" required={true}>
  The unique id of the space
</ParamField>

<ParamField path="changeRequestId" param-type="string" required={true}>
  The unique ID of the change request or its number identifier in the space
</ParamField>

<ParamField path="userId" param-type="string" required={true}>
  The unique ID of the User
</ParamField>

**Responses**

`204` Reviewer was not found

`205` The reviewer has been removed from the change request
