Returns pre-generated condition templates derived from the site's visitor attributes schema. These templates can be used as building blocks when writing adaptive content expressions to conditionally show or hide content for different visitor types. Use this to discover available conditions before authoring adaptive rules.

**GET** `/orgs/{organizationId}/sites/{siteId}/adaptive-schema/template-conditions`

**Parameters**

<ParamField header="Authorization" param-type="string" />

<ParamField path="organizationId" param-type="string" required={true}>
  The unique id of the organization
</ParamField>

<ParamField path="siteId" param-type="string" required={true}>
  The unique id of the site
</ParamField>

**Responses**

`200` List of template conditions generated based on the site visitor schema.

<ResponseField name="items" field-type="array" required={true}>
  <Expandable title="Array Items">
    <ResponseField name="description" field-type="string" required={true}>
      A short description of the suggested condition.
    </ResponseField>

    <ResponseField name="condition" field-type="string" required={true}>
      The suggested condition.
    </ResponseField>
  </Expandable>
</ResponseField>
