Keep your site's content fresh without breaking old links. This API allows you to create and manage redirection rules.

## The SiteRedirect object

<ResponseField name="object" field-type="string" required={true} enum="site-redirect" />

<ResponseField name="id" field-type="string" required={true}>
  The unique identifier for the redirect.
</ResponseField>

<ResponseField name="source" field-type="string" required={true}>
  The source path to redirect from.
</ResponseField>

<ResponseField name="draft" field-type="boolean" required={true}>
  Whether the redirect is draft and not live.
</ResponseField>

<ResponseField name="captureWildcard" field-type="boolean" required={true}>
  Capture and append the wildcard-matched suffix to the destination URL.
</ResponseField>

<ResponseField name="permanent" field-type="boolean" required={true}>
  Whether the redirect is configured as permanent. Permanent redirects are served as HTTP 308 for public live traffic and HTTP 307 in non-public contexts.
</ResponseField>

<ResponseField name="destination" field-type="string" required={true} />

<ResponseField name="createdAt" field-type="string" required={true}>
  When the redirect was created.
</ResponseField>

<ResponseField name="updatedAt" field-type="string">
  When the redirect was last updated. Absent if never updated since creation.
</ResponseField>
