Retrieves one Ask AI answer, including the question that prompted it, the response, and its feedback. Use it to inspect a specific answer discovered via listSiteQuestionAnswers.

**GET** `/orgs/{organizationId}/sites/{siteId}/answers/{siteQuestionAnswerId}`

**Parameters**

<ParamField header="Authorization" param-type="string" />

<ParamField path="organizationId" param-type="string" required={true}>
  The unique id of the organization
</ParamField>

<ParamField path="siteId" param-type="string" required={true}>
  The unique id of the site
</ParamField>

<ParamField path="siteQuestionAnswerId" param-type="string" required={true}>
  The unique id of the site question answer
</ParamField>

**Responses**

`200` OK
