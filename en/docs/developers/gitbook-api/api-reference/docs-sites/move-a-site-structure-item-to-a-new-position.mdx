Reorders a site space, section, section group, or external link relative to any sibling at the same structure level. Sorting changes sibling order only; move an item between the root and a group through that item's update operation first.

**PATCH** `/orgs/{organizationId}/sites/{siteId}/structure/sort`

**Parameters**

<ParamField header="Authorization" param-type="string" />

<ParamField path="organizationId" param-type="string" required={true}>
  The unique id of the organization
</ParamField>

<ParamField path="siteId" param-type="string" required={true}>
  The unique id of the site
</ParamField>

<ParamField header="prefer" param-type="string" enum="return=minimal,return=representation">
  Control whether a successful response includes the updated resource representation.
</ParamField>
