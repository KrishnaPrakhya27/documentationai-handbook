Lists the questions end users asked GitBook's Ask-AI assistant that were used as evidence for a documentation issue. Use this to see what users actually wanted to know before deciding how to fix the issue.

**GET** `/orgs/{organizationId}/sites/{siteId}/findings/{siteFindingId}/questions`

**Parameters**

<ParamField header="Authorization" param-type="string" />

<ParamField query="page" param-type="string">
  Identifier of the page results to fetch.
</ParamField>

<ParamField query="limit" param-type="number">
  The number of results per page
</ParamField>

<ParamField path="organizationId" param-type="string" required={true}>
  The unique id of the organization
</ParamField>

<ParamField path="siteId" param-type="string" required={true}>
  The unique id of the site
</ParamField>

<ParamField path="siteFindingId" param-type="string" required={true}>
  The unique id of the site finding
</ParamField>

**Responses**

`200` List of questions linked to the site finding
