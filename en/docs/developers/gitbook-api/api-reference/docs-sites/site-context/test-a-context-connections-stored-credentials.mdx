Verifies the stored credentials of a context connection against the external service, without changing anything. A failed verification is reported in the response body with `success` set to `false` rather than as an HTTP error. Connectors that have nothing to verify report `success: true`.

**POST** `/orgs/{organizationId}/sites/{siteId}/context-connections/{siteContextConnectionId}/test`

**Parameters**

<ParamField header="Authorization" param-type="string" />

<ParamField path="organizationId" param-type="string" required={true}>
  The unique id of the organization
</ParamField>

<ParamField path="siteId" param-type="string" required={true}>
  The unique id of the site
</ParamField>

<ParamField path="siteContextConnectionId" param-type="string" required={true}>
  The unique id of the context connection
</ParamField>

**Responses**

`200` The connection test completed (see \`success\` for the outcome).

<ResponseField name="object" field-type="string" required={true} enum="context-connection-test-result" />

<ResponseField name="success" field-type="boolean" required={true}>
  Whether the stored credentials authenticated successfully.
</ResponseField>

<ResponseField name="error" field-type="string">
  A human-readable reason for the failure, when the test failed.
</ResponseField>
