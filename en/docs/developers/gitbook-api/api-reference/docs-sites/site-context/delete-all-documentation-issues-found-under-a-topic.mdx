Permanently deletes every finding associated with a site topic, regardless of status. This is a bulk, irreversible cleanup operation — use `updateSiteFindingById` to resolve or dismiss individual issues instead unless the intent is to wipe every issue under a topic, for example when the topic itself is being removed.

**DELETE** `/orgs/{organizationId}/sites/{siteId}/topics/{siteTopicId}/findings`

**Parameters**

<ParamField header="Authorization" param-type="string" />

<ParamField path="organizationId" param-type="string" required={true}>
  The unique id of the organization
</ParamField>

<ParamField path="siteId" param-type="string" required={true}>
  The unique id of the site
</ParamField>

<ParamField path="siteTopicId" param-type="string" required={true}>
  The unique id of the topic
</ParamField>

**Responses**

`204` Topic had no findings or did not exist

`205` Topic findings deleted
