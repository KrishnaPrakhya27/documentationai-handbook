Updates the advertising configuration for a site, including the review status and topic category used to select relevant ads. This controls GitBook's monetization feature for sites opted into the ads program.

**POST** `/orgs/{organizationId}/sites/{siteId}/ads`

**Parameters**

<ParamField header="Authorization" param-type="string" />

<ParamField path="organizationId" param-type="string" required={true}>
  The unique id of the organization
</ParamField>

<ParamField path="siteId" param-type="string" required={true}>
  The unique id of the site
</ParamField>

**Request body**

<ParamField body="status" param-type="string" enum="in-review,disabled" />

<ParamField body="topic" param-type="string" enum="webdev,crypto">
  Topic of the content
</ParamField>

**Responses**

`204` OK
