The custom hostname will continue to point to the content or organization unless it is used for another one.

**DELETE** `/custom-hostnames/{hostname}`

**Parameters**

<ParamField header="Authorization" param-type="string" required={true} />

<ParamField path="hostname" param-type="string" required={true}>
  The custom hostname, for example "docs.gitbook.com"
</ParamField>

**Responses**

`204` Custom hostname did not exist

`205` Custom hostname has been removed
