Triggers an import from provided Git repository into the space, updating the space's content to match the repository (if not standalone). This is an async operation — it runs in the background after the request returns 204.

**POST** `/spaces/{spaceId}/git/import`

**Parameters**

<ParamField header="Authorization" param-type="string" />

<ParamField path="spaceId" param-type="string" required={true}>
  The unique id of the space
</ParamField>

**Request body**

<ParamField body="url" param-type="string" required={true}>
  URL of the Git repository to import. It can contain basic auth credentials.
</ParamField>

<ParamField body="ref" param-type="string" required={true}>
  Git ref to import in the format "refs/heads/main"
</ParamField>

<ParamField body="repoCacheID" param-type="string" deprecated={true}>
  Unique identifier to use to cache the Git repository across multiple operations.
</ParamField>

<ParamField body="repoTreeURL" param-type="string">
  URL to use as a prefix for external file references.
</ParamField>

<ParamField body="repoCommitURL" param-type="string">
  URL to use as a prefix for the commit URL.
</ParamField>

<ParamField body="repoProjectDirectory" param-type="string">
  Path to a root directory for the project in the repository.
</ParamField>

<ParamField body="timestamp" param-type="string" />

<ParamField body="force" param-type="boolean" />

<ParamField body="standalone" param-type="boolean">
  If true, the import will generate a revision without updating the space primary content.
</ParamField>

<ParamField body="gitInfo" param-type="object">
  Update metadata about the Git provider on the space

  <Expandable title="Object Properties">
    <ParamField body="provider" param-type="string" enum="github,gitlab">
      The git provider
    </ParamField>

    <ParamField body="url" param-type="string">
      The repository's tree URL
    </ParamField>
  </Expandable>
</ParamField>

**Responses**

`204` Operation to import the repository has been queued.
