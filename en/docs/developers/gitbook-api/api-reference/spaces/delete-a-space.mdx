Deleted spaces will be permanently removed after 7 days.

**DELETE** `/spaces/{spaceId}`

**Parameters**

<ParamField header="Authorization" param-type="string" />

<ParamField path="spaceId" param-type="string" required={true}>
  The unique id of the space
</ParamField>

**Responses**

`204` Space did not exist

`205` Space has been deleted
