**DELETE** `/spaces/{spaceId}/permissions/teams/{teamId}`

**Parameters**

<ParamField header="Authorization" param-type="string" />

<ParamField path="spaceId" param-type="string" required={true}>
  The unique id of the space
</ParamField>

<ParamField path="teamId" param-type="string" required={true}>
  The unique ID of the Team
</ParamField>

**Responses**

`204` The team was not found in the space

`205` The team has been removed from the space
