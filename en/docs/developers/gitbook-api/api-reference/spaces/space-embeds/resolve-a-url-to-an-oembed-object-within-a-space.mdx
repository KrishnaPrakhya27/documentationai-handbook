Resolves an external URL to an oEmbed representation (title, thumbnail, HTML snippet) within the context of a space. Use this to preview or embed third-party content referenced in a space's pages. Requires the URL as a query parameter.

**GET** `/spaces/{spaceId}/embed`

**Parameters**

<ParamField header="Authorization" param-type="string" />

<ParamField path="spaceId" param-type="string" required={true}>
  The unique id of the space
</ParamField>

<ParamField query="url" param-type="string" required={true}>
  URL to resolve
</ParamField>

**Responses**

`200` OK

<ResponseField name="title" field-type="string" required={true} />

<ResponseField name="site" field-type="string" required={true} />

<ResponseField name="icon" field-type="string" />
