Updates the content of an existing reply to a comment in a space. Only the reply author or a space admin can update the reply. To update the parent comment, use the space comment update endpoint.

**PUT** `/spaces/{spaceId}/comments/{commentId}/replies/{commentReplyId}`

**Parameters**

<ParamField header="Authorization" param-type="string" />

<ParamField path="spaceId" param-type="string" required={true}>
  The unique id of the space
</ParamField>

<ParamField path="commentId" param-type="string" required={true}>
  The unique id of the comment
</ParamField>

<ParamField path="commentReplyId" param-type="string" required={true}>
  The unique id of the comment reply
</ParamField>

**Request body**

<ParamField body="body" param-type="string" />

<ParamField body="addedReactions" param-type="string[]">
  Reactions to add to the comment.
</ParamField>

<ParamField body="removedReactions" param-type="string[]">
  Reactions to remove from the comment.
</ParamField>
