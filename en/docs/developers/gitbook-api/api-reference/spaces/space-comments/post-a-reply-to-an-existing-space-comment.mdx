Creates a reply to an existing comment on a space. Use this to continue a discussion thread started by a top-level comment. To start a new thread, use the space comment creation endpoint instead.

**POST** `/spaces/{spaceId}/comments/{commentId}/replies`

**Parameters**

<ParamField header="Authorization" param-type="string" />

<ParamField path="spaceId" param-type="string" required={true}>
  The unique id of the space
</ParamField>

<ParamField path="commentId" param-type="string" required={true}>
  The unique id of the comment
</ParamField>

**Request body**

<ParamField body="body" param-type="string" required={true} />

**Responses**

`200` The reply was posted.
