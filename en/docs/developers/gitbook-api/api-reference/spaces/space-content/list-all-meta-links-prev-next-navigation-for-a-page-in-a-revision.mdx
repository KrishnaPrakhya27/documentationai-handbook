Returns the meta navigation links for a specific page within a historical revision, including the previous and next page in the space's reading order. Use this to implement sequential navigation across historical content or to build a reading flow for a specific revision.

**GET** `/spaces/{spaceId}/revisions/{revisionId}/page/{pageId}/meta-links`

**Parameters**

<ParamField header="Authorization" param-type="string" />

<ParamField path="spaceId" param-type="string" required={true}>
  The unique id of the space
</ParamField>

<ParamField path="revisionId" param-type="string" required={true}>
  The unique id of the revision
</ParamField>

<ParamField path="pageId" param-type="string" required={true}>
  The unique id of the page
</ParamField>

**Responses**

`200` OK

<ResponseField name="canonical" field-type="string" />

<ResponseField name="alternates" field-type="string[]" />
