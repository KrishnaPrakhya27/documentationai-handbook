Returns a paginated list of all files (images, attachments, and other assets) uploaded to a space's current revision. Use this to discover available assets or audit file usage across a space.

**GET** `/spaces/{spaceId}/content/files`

**Parameters**

<ParamField header="Authorization" param-type="string" />

<ParamField path="spaceId" param-type="string" required={true}>
  The unique id of the space
</ParamField>

<ParamField query="page" param-type="string">
  Identifier of the page results to fetch.
</ParamField>

<ParamField query="limit" param-type="number">
  The number of results per page
</ParamField>

<ParamField query="metadata" param-type="boolean">
  If `false` is passed, "git" mutable metadata will not returned. Passing `false` can optimize performances of the lookup.
</ParamField>

<ParamField query="computed" param-type="boolean">
  If `false` is passed, content will not be computed
</ParamField>

**Responses**

`200` OK

    <ResponseField name="page" field-type="string" required={true}>
      Unique identifier to query the next results page
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="count" field-type="number">
  Total count of objects in the list
</ResponseField>
