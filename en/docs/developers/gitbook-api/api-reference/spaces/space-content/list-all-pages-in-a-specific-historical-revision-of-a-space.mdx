Returns the full flat list of all pages (document pages and group pages) in a specific historical revision of a space. Use this to inspect the complete page tree of a past snapshot. For the current live content pages, use the space content pages endpoint.

**GET** `/spaces/{spaceId}/revisions/{revisionId}/pages`

**Parameters**

<ParamField header="Authorization" param-type="string" />

<ParamField path="spaceId" param-type="string" required={true}>
  The unique id of the space
</ParamField>

<ParamField path="revisionId" param-type="string" required={true}>
  The unique id of the revision
</ParamField>

<ParamField query="metadata" param-type="boolean">
  If `false` is passed, "git" mutable metadata will not returned. Passing `false` can optimize performances of the lookup.
</ParamField>

<ParamField query="computed" param-type="boolean">
  If `false` is passed, content will not be computed
</ParamField>

**Responses**

`200` OK

<ResponseField name="pages" field-type="string[]" required={true} />
