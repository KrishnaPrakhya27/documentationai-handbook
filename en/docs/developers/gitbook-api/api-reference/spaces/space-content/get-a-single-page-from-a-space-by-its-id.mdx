Retrieves a page's metadata, content, and document structure from a space's current revision by its page ID. Use this when you know the exact page ID and need its content or path. For lookup by URL path, use the content/path endpoint instead.

**GET** `/spaces/{spaceId}/content/page/{pageId}`

**Parameters**

<ParamField header="Authorization" param-type="string" />

<ParamField path="spaceId" param-type="string" required={true}>
  The unique id of the space
</ParamField>

<ParamField path="pageId" param-type="string" required={true}>
  The unique id of the page
</ParamField>

<ParamField query="format" param-type="string" enum="document,markdown">
  Output format for the content.
</ParamField>

<ParamField query="format.markdown.refs" param-type="string" enum="relative,stable">
  Controls how content references are formatted in markdown output. Ignored unless `format=markdown`.

  - `relative`: Format page references as relative links from the current page. Other references might not be handled.
  - `stable`: Format content references as stable idempotent refs containing their identifiers.
</ParamField>

<ParamField query="evaluated" param-type="string">
  Controls whether the document should be evaluated.

  - When set to `true`, the entire document will be evaluated.
  - When set to `deterministic-only`, only expressions that depend
    exclusively on deterministic inputs will be evaluated.
</ParamField>

<ParamField query="dereferenced" param-type="string">
  Controls whether the document should be deferenced (eference to other content will be resolved and expanded).

  - When set to `true`, the entire document will be deferenced
  - When set to `reusable-contents`, only reusable contents will be deferenced.
</ParamField>

<ParamField query="metadata" param-type="boolean">
  If `false` is passed, "git" mutable metadata will not returned. Passing `false` can optimize performances of the lookup.
</ParamField>

<ParamField query="computed" param-type="boolean">
  If `false` is passed, content will not be computed
</ParamField>

**Responses**

`200` OK
