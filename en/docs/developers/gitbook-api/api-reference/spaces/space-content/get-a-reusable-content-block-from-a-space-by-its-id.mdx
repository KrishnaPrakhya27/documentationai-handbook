Retrieves a reusable content block (a shared snippet that can be embedded across multiple pages) from a space's current revision by its ID. Use this to read the content of a reusable block when you have its ID.

**GET** `/spaces/{spaceId}/content/reusable-contents/{reusableContentId}`

**Parameters**

<ParamField header="Authorization" param-type="string" />

<ParamField path="spaceId" param-type="string" required={true}>
  The unique id of the space
</ParamField>

<ParamField path="reusableContentId" param-type="string" required={true}>
  The unique id of the reusable content
</ParamField>

<ParamField query="metadata" param-type="boolean">
  If `false` is passed, "git" mutable metadata will not returned. Passing `false` can optimize performances of the lookup.
</ParamField>

<ParamField query="computed" param-type="boolean">
  If `false` is passed, content will not be computed
</ParamField>

**Responses**

`200` OK

<ResponseField name="id" field-type="string" required={true} />

<ResponseField name="title" field-type="string" required={true} />

<ResponseField name="git" field-type="object">
  <Expandable title="Object Properties">
    <ResponseField name="oid" field-type="string" required={true}>
      SHA for the blob
    </ResponseField>

    <ResponseField name="path" field-type="string" required={true}>
      Path of the blob in the Git tree
    </ResponseField>
  </Expandable>
</ResponseField>
