GitBook uses conventional HTTP response codes to indicate the success or failure of an API request. As a general rule:

- Codes in the <strong>`2xx`</strong> range indicate success.
- Codes in the <strong>`4xx`</strong> range indicate incorrect or incomplete parameters (e.g. a required parameter was omitted, or an operation failed with a 3rd party, etc.).
- Codes in the <strong>`5xx`</strong> range indicate an error with GitBook's servers.

GitBook also outputs an error message and an error code formatted in JSON:

```json
{
    "error": {
        "code": 404,
        "message": "Page not found in this space"
    }
}
```
