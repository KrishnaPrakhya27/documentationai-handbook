GitBook’s **Configure** tab gives you control over advanced site behavior, user interactions, and integrations with AI tools.

This video and guide will take you through editing your site’s configuration, covering:

- Where to find[ configuration settings](/en/docs/manage-your-site/customization/extra-configuration)
- [Localizing the user interface](/en/docs/manage-your-site/customization/extra-configuration#localize-user-interface)
- Changing how links behave when clicked
- Enabling page feedback and ratings for [Insights](/en/docs/analytics/insights)
- [Configuring AI page](/en/docs/manage-your-site/customization/extra-configuration#open-in-ai-providers) actions
- [Configuring Git Sync](/en/docs/manage-your-site/customization/extra-configuration#edit-on-github-gitlab) actions
- [Adding a privacy policy](/en/docs/manage-your-site/customization/extra-configuration#privacy-policy)
- and more!

<Steps>
  <Step title="Open the Configure tab" titleType="h3">
    From your **Docs site overview**, open [**Customization**](/en/docs/manage-your-site/customization). Then select **Configure**.
  </Step>

  <Step title="Localize the user interface" titleType="h3">
    Set the **default language** for GitBook’s built-in UI text.

    This updates default interface elements like the search placeholder and button labels.
  </Step>

  <Step title="Control external link behavior" titleType="h3">
    Choose how **external links** should open for readers:

    - In the same tab (default)
    - In a new tab
  </Step>

  <Step title="Enable page ratings" titleType="h3">
    Turn on **page ratings** if you want lightweight feedback on your docs. Ratings appear directly on pages.

    You can review the collected feedback in [**Insights**](/en/docs/analytics/insights).
  </Step>

  <Step title="Configure page actions" titleType="h3">
    Page actions show at the top of documentation pages. Enable only the actions you want readers to see.

    Common options include:

    - Launching the **GitBook Assistant**
    - Copying the page
    - Viewing the page source
    - Copying content as [**Markdown**](/en/docs/create-content/formatting/markdown)
    - Opening the page in external AI tools (like ChatGPT or Claude)
    - Connecting to the site’s [**auto-generated MCP server**](/en/docs/ai-for-your-readers/mcp-servers-for-published-docs)
    - Exporting pages as **PDF**
  </Step>

  <Step title="Enable ‘Edit on Git’ (optional)" titleType="h3">
    If **Git Sync** is enabled, you can add an **Edit on Git** action. This lets readers (and your team) jump to your Git repo to propose changes in Markdown.

    If you haven’t set it up yet, start with [Git Sync](/en/docs/docs-as-code/git-sync).
  </Step>

  <Step title="Add a privacy policy" titleType="h3">
    Add a **Privacy Policy URL** to display it on relevant pages.

    This also enables a cookie consent banner in the lower-right corner of your site.
  </Step>

  <Step title="Save and publish" titleType="h3">
    Review your configuration changes, then click **Save** to make them live.
  </Step>
</Steps>

<Callout kind="info">
  Make sure you hit **Save** before you navigate away from the Customization screen. Your changes won’t appear on your docs site until you save them.
</Callout>
