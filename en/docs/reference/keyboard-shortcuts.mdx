Shortcut keys allow easy and quick methods for navigating or editing content.

## In published documentation

| Description | Mac | Windows |
| --- | --- | --- |
| Open the **Ask or search** panel | <kbd>⌘</kbd>+<kbd>K</kbd> | <kbd>Ctrl</kbd>+<kbd>K</kbd> |
| Open the **GitBook Assistant** chat window | <kbd>⌘</kbd>+<kbd>I</kbd> | <kbd>Ctrl</kbd>+<kbd>I</kbd> |
| Close the **Ask or search** or **GitBook Assistant** panels | <kbd>Esc</kbd> | <kbd>Esc</kbd> |

### Block-specific shortcuts

#### Paragraph & heading blocks

| Description | Mac | Windows |
| --- | --- | --- |
| Insert a soft line break in a paragraph | <kbd>Shift</kbd> \+ <kbd>Enter</kbd> | <kbd>Shift</kbd> \+ <kbd>Enter</kbd> |
| Turn into a paragraph | <kbd>⌘</kbd> \+ <kbd>⌥</kbd> \+ <kbd>0</kbd> | <kbd>Ctrl</kbd> \+ <kbd>Alt</kbd> \+ <kbd>0</kbd> |
| Turn into a heading 1 | <kbd>⌘</kbd> \+ <kbd>⌥</kbd> \+ <kbd>1</kbd> | <kbd>Ctrl</kbd> \+ <kbd>Alt</kbd> \+ <kbd>1</kbd> |
| Turn into a heading 2 | <kbd>⌘</kbd> \+ <kbd>⌥</kbd> \+ <kbd>2</kbd> | <kbd>Ctrl</kbd> \+ <kbd>Alt</kbd> \+ <kbd>2</kbd> |
| Turn into a heading 3 | <kbd>⌘</kbd> \+ <kbd>⌥</kbd> \+ <kbd>3</kbd> | <kbd>Ctrl</kbd> \+ <kbd>Alt</kbd> \+ <kbd>3</kbd> |

#### Table blocks

| Description | Mac | Windows |
| --- | --- | --- |

| Insert a row above | <kbd>⌥</kbd> \+ <kbd>Enter</kbd> | <kbd>Alt</kbd> \+ <kbd>Enter</kbd> |
| Move to next row | <kbd>Enter</kbd> | <kbd>Enter</kbd> |
| Insert a new line in a text cell | <kbd>Shift</kbd> \+ <kbd>Enter</kbd> | <kbd>Shift</kbd> \+ <kbd>Enter</kbd> |
| Delete row | <kbd>⌘</kbd> \+ <kbd>-</kbd> | <kbd>Ctrl</kbd> \+ <kbd>-</kbd> |
