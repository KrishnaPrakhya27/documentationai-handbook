## "Edit this page" with Fern Editor

<span className="dai-mig-badge">customization</span>

The "Edit this page" button can now open Fern Editor in addition to linking to GitHub. [When you set the launch mode to `dashboard`](/learn/docs/configuration/site-level-settings#edit-this-page-configuration), clicking the button gives users the choice between editing the page in Fern Editor or viewing the source on GitHub. This is especially useful for internal docs sites where most viewers are also editors.
