## Role-based access control in local preview

<span className="dai-mig-badge">security, developer-tools</span>

`fern docs dev` now applies role-based access control the same way a preview link does. Use the role selector to view the site as a specific viewer and check which pages and navigation items each role sees. Password protection also works locally when you set `FERN_AUTH_TYPE=password` and `FERN_AUTH_SECRET` before starting the server.

[Read the docs](/learn/docs/preview-publish/preview-changes#local-development)
