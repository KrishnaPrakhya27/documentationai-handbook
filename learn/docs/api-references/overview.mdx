---
title: Overview of API References
description: Understand how to generate, customize, and enhance API Reference documentation with Fern.
---

Fern generates interactive API Reference documentation from an [OpenAPI specification](https://buildwithfern.com/learn/api-definitions/openapi/overview) or other API formats. Endpoints, type schemas, code snippets, and [AI-generated examples](/learn/docs/ai-features/ai-examples) are all populated automatically. Users can try requests directly from the docs with the [API Explorer](/learn/docs/api-references/api-explorer), and AI agents and crawlers can discover your APIs via the [API catalog](/learn/docs/ai-features/api-catalog) endpoint.
